# Morrowgearサーバー運用メモ

## 起動前チェック

1. `java -version`が25以上
2. `mods`内にMorrowgearとFabric APIが各1個だけ
3. 前回停止時のエラーやクラッシュレポートがない
4. ワールドの定期バックアップがある
5. 更新時は参加者へ同じMOD一式を配布済み

## 起動後チェック

1. コンソールに`Done`が表示される
2. FabricのMod解決エラーがない
3. `list`で接続中プレイヤーを確認できる
4. 新規参加者はホワイトリストへ登録済み
5. 参加者1名で、Dock配置、ドローン展開、コントローラーUI表示を確認する

## 推奨設定

| 設定 | 既定値 | 理由 |
| --- | --- | --- |
| `online-mode` | `true` | 正規アカウント認証を維持する |
| `white-list` | `true` | 招待したメンバーだけ参加させる |
| `enforce-whitelist` | `true` | 許可解除を即時反映する |
| `view-distance` | `12` | 視界と通信量のバランス |
| `simulation-distance` | `10` | 遠隔ドローン処理とTPSのバランス |
| `max-players` | `8` | 友人向け小規模運用 |
| `allow-flight` | `true` | 誤検知切断を避ける |

## 障害調査で受け取るもの

- 発生時刻と実施していた操作
- 参加人数
- 機体、Dock、母艦のおおよその数
- `logs/latest.log`
- `crash-reports/`の最新ファイル
- サーバーと参加者双方のMODファイル名
- 再現する場合は、発生前からの短い動画またはスクリーンショット

ワールドを直接編集する前にコピーを作成してください。問題が起きたワールドは、修復できるまで上書きしないで保管します。
