# Morrowgear: Drone Command 0.20.5 マルチプレイ試験リリース

## 対応環境

| 項目 | バージョン |
| --- | --- |
| Minecraft: Java Edition | 26.2 |
| Java | 25以上（64 bit） |
| Fabric Loader | 0.19.3 |
| Fabric API | 0.156.0+26.2 |
| Morrowgear: Drone Command | 0.20.5 |

サーバーと参加者全員で、Minecraft、Fabric API、MorrowgearのJARを一致させてください。Morrowgearはサーバー側だけでなく、機体モデル、HMI、HUD、エフェクト、サウンドを表示する全参加者のクライアントにも必要です。

## この配布版の主な内容

- 母艦のコンテナ荷役画面を、地上コンテナと搭載済みコンテナの縦リストへ再構成しました。
- コンテナの種類、距離、座標、予約状態、搭載位置、ミサイル残弾を一覧から確認できます。
- 荷下ろし時は照準指定を要求せず、母艦が機体右側の安全な地面を探索します。
- 母艦の攻撃命令をレーザーとミサイルに分離し、準備、実行、進捗、資源表示を個別化しました。
- レーザー命令が物理ミサイルを消費せず、ミサイル命令がレーザーダメージを発生させないようサーバー処理も分離しました。
- バンカーバスターはOverworldのY=-64までロックできます。
- ミサイルの地表・地下判定を実際の地表高に基づく計算へ修正しました。
- 高速ミサイルが近距離目標の周囲を旋回し続けないよう、終末誘導時だけ推力偏向補正を強めました。
- 母艦の戦略採掘は、岩盤、保護タグ、プレイヤー設置履歴、Block Entity、他Modの破壊不能ブロックを採掘拒否理由にせず、指定範囲のOperation下限まで破砕します。
- 完全蒸発に分類されたブロックとBlock Entityの内容物は回収されません。選択範囲内の建築・収納を復元する機能はないため、採掘前に範囲を必ず確認してください。
- 未読み込みチャンク、ワールド境界、指定範囲外は破壊せず、救助・サルベージ用Engineerの保護判定も従来どおり維持します。

## 検証結果

- 自動回帰試験: 2,835件実行、失敗0、エラー0、スキップ0
- Minecraft 26.2実ゲーム試験: PASS
  - 母艦の展開と移動
  - 掘削用プラズマ処理
  - レーザー攻撃と地形非破壊
  - 貨物コンテナの設置、積載、搭載、荷下ろし、内容・識別情報の保持
  - ミサイルコンテナの積載、ロック、発射、着弾、物理弾の消費、残弾を保持した荷下ろし
  - 小型機4機の母艦補給ベイ利用と元任務への復帰
- 配布前ビルド: PASS
- 配布物だけを使用したFabric専用サーバー試験: 新規ワールド生成、Morrowgear読込、`Done`到達、保存付き正常停止を確認
- 配布JARのSHA-256は、ZIP内の`SHA256SUMS.txt`で確認できます。

最新の絶対破砕仕様は、岩盤・バリア・コマンドブロック・ポータル枠・チェスト・スポナー・設置履歴・保護イベント回避を自動境界試験で確認しています。実ワールドでは不可逆な破壊になるため、最初の確認はバックアップ済みワールドで行ってください。

## マルチプレイ上の所有権

- ドローン、Dock、母艦、任務、補給状態はサーバーを正とします。
- 各機体と設備は所有者単位で管理され、別プレイヤーの機体やDockへ通常操作が混在しない設計です。
- 管理者権限を持つプレイヤーはMinecraft本来の管理機能を使用できるため、信頼できる担当者だけをOPにしてください。

## 導入前の注意

1. 既存ワールドを停止し、`world`フォルダーをバックアップします。
2. 古いMorrowgearとFabric APIをサーバー・クライアント双方から取り除きます。
3. `SERVER/mods`と`CLIENT/mods`のファイルをそれぞれ配置します。
4. Windowsでは配布ZIP直下で`VERIFY_PACKAGE.ps1`を実行し、破損がないことを確認します。
5. 最初はバックアップ済みワールドか新規ワールドで、所有権、Dock帰還、補給、戦闘を少数機で確認します。

詳細な導入方法は`MORROWGEAR_MULTIPLAYER_SETUP_JA.md`、運用方法は`MORROWGEAR_SERVER_OPERATIONS_JA.md`を参照してください。
