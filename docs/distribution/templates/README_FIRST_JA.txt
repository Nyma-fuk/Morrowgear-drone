Morrowgear: Drone Command 0.20.6 / Minecraft 26.2
==================================================

サーバーを立てる人:
  1. DOCUMENTS/MORROWGEAR_MULTIPLAYER_SETUP_JA.md を読む
  2. Java 25以上を確認する
  3. SERVER/start-server.bat を実行する
  4. EULAを読み、同意する場合だけSERVER/eula.txtをeula=trueへ変更する
  5. 再度start-server.batを実行する
  6. コンソールで whitelist add <ユーザー名> を実行する

参加する人:
  CLIENT/mods内の2ファイルを、Minecraft 26.2 Fabric環境のmodsへ入れる。

重要:
  サーバーと全参加者で、Minecraft、Fabric API、Morrowgearの版を一致させる。
  サーバーを閉じるときは、コンソールで stop を実行する。
  この配布物は指定メンバー向けのテスト版です。公開・再配布前に正式なライセンスを確認してください。
