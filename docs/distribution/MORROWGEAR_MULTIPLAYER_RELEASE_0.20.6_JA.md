# Morrowgear: Drone Command 0.20.6 マルチプレイ試験リリース

## 対応環境

| 項目 | バージョン |
| --- | --- |
| Minecraft: Java Edition | 26.2 |
| Java | 25以上（64 bit） |
| Fabric Loader | 0.19.3 |
| Fabric API | 0.156.0+26.2 |
| Morrowgear: Drone Command | 0.20.6 |

サーバーと参加者全員で、Minecraft、Fabric API、MorrowgearのJARを一致させてください。Morrowgearはサーバー側だけでなく、機体モデル、HMI、HUD、エフェクト、サウンドを表示する全参加者のクライアントにも必要です。

## この配布版の主な内容

- FIELD機による動的データリンクメッシュを追加し、配置、固定展開、撤収、Dock帰還、通信範囲を一つの運用系として整理しました。
- バイザーの3D空域表示を軽量化し、表示切替、メッシュ範囲、接続ノード、空域内機体を確認できるようにしました。
- 強襲ビーコンランチャーと専用弾を追加しました。最大3地点へ独立して戦力を配分し、通信リレー経由でも攻撃部隊を招集できます。
- Cargo補給、補給元の再選定、Dock要求の重複抑制、任務後の次行動を修正し、同一物資を運び続ける循環を防ぎました。
- 動的Dock割当、Dock消失後の再予約、満床時の待機、補給後の任務復帰を整理しました。
- レーザー、機関砲、ミサイルが編隊完成だけを待たず、各機の射線と進入経路に基づいて攻撃できるようにしました。
- CAS進入軸、飛行加速度、障害物回避、Rejoin、サルベージ牽引、カーゴ荷役の停止・低速化を修正しました。
- コントローラー、Dock、補給網、母艦、バイザーのHMI表示を更新し、命令状態と実行不能理由を追跡しやすくしました。
- 実ゲーム試験の地形生成後にカーゴ荷役が待ち続ける問題を修正しました。一時光源を着地点障害物として扱わず、試験用コンテナの占有範囲を確実に撤去します。

## マルチプレイ上の所有権

- ドローン、Dock、母艦、任務、補給状態、通信メッシュはサーバーを正とします。
- 各機体と設備は所有者単位で管理され、別プレイヤーの機体やDockへ通常操作が混在しない設計です。
- 管理者権限を持つプレイヤーはMinecraft本来の管理機能を使用できるため、信頼できる担当者だけをOPにしてください。

## 導入前の注意

1. 既存ワールドを停止し、`world`フォルダーをバックアップします。
2. 古いMorrowgearとFabric APIをサーバー・クライアント双方から取り除きます。
3. `SERVER/mods`と`CLIENT/mods`のファイルをそれぞれ配置します。
4. Windowsでは配布ZIP直下で`VERIFY_PACKAGE.ps1`を実行し、破損がないことを確認します。
5. 最初はバックアップ済みワールドか新規ワールドで、所有権、Dock帰還、補給、通信メッシュ、戦闘を少数機で確認します。

詳細な導入方法は`MORROWGEAR_MULTIPLAYER_SETUP_JA.md`、運用方法は`MORROWGEAR_SERVER_OPERATIONS_JA.md`を参照してください。
