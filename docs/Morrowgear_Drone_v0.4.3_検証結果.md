# Morrowgear: Drone Command v0.4.3 検証結果

## 実装結果

- Minecraft標準の飛行経路探索を導入し、障害物越しの追従を3次元経路へ変更した。
- 直進経路は0.45ブロック間隔で機体当たり判定と流体を検査する。
- 水・水際、溶岩、火炎、ダメージ地形、葉に経路コストを設定した。
- 衝突、流体接触、30tick相当の停滞時に上昇・左右・後退の安全候補へ退避する。
- 空間開放度、天井、水・溶岩、昼夜、プレイヤー速度、機数から追従半径・高度・間隔・旋回速度を算出する。
- 狭所では立体旋回を停止してコンパクトな縦列へ縮退する。

## 自動検証

35件すべて成功。追加した検証は、低天井での縦列化、水辺・高速移動時の安全高度上昇、狭所スロットの3次元分離、大編成半径の上限制御である。

## Minecraft確認

- Minecraft Java Edition 26.2 / Fabricで`morrowgear_drone 0.4.3`を読み込んだ。
- v0.4.2の既存ワールド、既存7機、Dock、所有権、任務情報を保持した。
- ロード後のクライアント・サーバーログに例外またはModエラーはない。
- 開発JARと導入JARのSHA-256は一致した。
