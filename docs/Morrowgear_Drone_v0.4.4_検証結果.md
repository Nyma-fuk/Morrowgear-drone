# Morrowgear: Drone Command v0.4.4 検証結果

## 対象

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3
- Fabric API 0.156.0+26.2
- Morrowgear: Drone Command v0.4.4
- 検証日: 2026年8月18日

## 修正目的

追跡対象や目的地点まで障害物回避経路を使う場合、機体が最終目的地ではなく直近の経路ノードまでの短い距離を基準に速度を決めていた。このため、遠距離任務でも各ノード直前の低速制御が連続し、地形によって到達が著しく遅くなっていた。

v0.4.4では、経路上の操舵先と速度算出用の最終目的地距離を分離した。さらに、安全に直行できる経路ノードを先読みして不要な小旋回を省き、移動する追跡対象への再探索頻度を安定化した。

## Minecraft実機確認

1. 配布用v0.4.4 JARを通常のModフォルダーへ導入した。
2. 起動ログで`morrowgear_drone 0.4.4`の読込みと、初期化例外がないことを確認した。
3. 既存の`Morrowgear Drone Test`ワールドを読み込み、保存済みの所有ドローン7機が維持されていることを確認した。
4. 統合戦術管理画面から全7機へ、海岸を挟む遠方の陸地点を指定した。
5. 指示後、編隊が低速の小刻み移動にならず、地図上を巡航速度で横断して目的地点へ接近することを確認した。
6. 続けて地図の反対側にいる生物を全7機の追跡対象へ指定した。
7. 海岸・水上を含む経路を約5秒で横断し、対象付近で減速して追跡隊列へ復帰することを確認した。
8. 飛行中の機体消失、任務停止、Minecraftログ上の例外は確認されなかった。

## 判定

合格。地形回避が必要な遠距離の地点移動と生物追跡で、直近ノード距離に起因する過剰な低速化は解消した。近距離制御、対象付近の減速、Dock接近・着艦速度は従来の制御を維持している。

## 残る確認観点

未読込チャンクをまたぐ長距離追跡、極端に狭い洞窟、頻繁にDimensionを移動する対象については、別条件の耐久試験として継続評価する。
