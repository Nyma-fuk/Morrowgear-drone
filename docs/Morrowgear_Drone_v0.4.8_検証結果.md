# Morrowgear: Drone Command v0.4.8 検証結果

## 検証環境

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3
- Fabric API 0.156.0+26.2
- Morrowgear: Drone Command v0.4.8
- 検証日: 2026年8月18日

## 目的

分散収束が隊形移動を実質的に上書きし、機体が通常隊列を組まずに高速で目的地へ到達する問題を解消したことを確認する。

## 修正仕様

1. 分散収束先を目的地そのものではなく、機体群の重心から目的地方向へ進む移動式合流点とした。
2. 期待機数の60%以上かつ最低2機が凝集した時点で、その機体群を隊形移動へ昇格させる。
3. 遅延機は分散収束を継続し、先行隊の隊形移動を妨げない。
4. 分散収束中の速度上限を0.48 block/tickとした。

## 自動テスト

- `clean test build` 成功
- 48テスト成功、失敗0
- 7機中6機が凝集した場合に1機の遅延機を除外してクォーラムを形成できることを確認
- 移動式合流点が機体群の前方かつ目的地の手前に置かれることを確認
- 分散収束速度が0.48 block/tickを超えないことを確認

## ゲーム内検証

1. 所有ドローン10機を展開した。
2. `/spreadplayers`で機体を平均9.11ブロック間隔へ分散配置した。この強制配置で1機が地形内部へ置かれて窒息したため、通常航法の評価対象から除外した。
3. 統合戦術管理画面で残る9機を全選択した。
4. 機体カードを地図上の遠方地点へドラッグし、共通地点任務を設定した。
5. UIの機体一覧、指揮パネル、進行中の任務一覧で状態遷移を監視した。

## 結果

| 確認項目 | 結果 |
|---|---|
| v0.4.8の読み込み | 成功 |
| 9機への共通地点任務 | 成功 |
| 指示直後の分散収束 | 成功 |
| 凝集機の隊形移動への昇格 | 成功 |
| 遅延機だけの分散収束継続 | 成功 |
| 数秒後の全表示機の隊形移動 | 成功 |
| 到着後の地点哨戒 | 成功 |
| テレポート | 使用なし |

強制分散で発生した1機の窒息は、通常の地点移動や障害物回避ではなく、Minecraft標準コマンドによる瞬間配置が原因である。今回の航法評価は、その影響を受けていない9機を対象とした。

## 判定

`分散収束 → 隊形移動 → 地点哨戒`の3段階をゲーム内UIで確認した。分散収束は巡航隊列の代替ではなく前処理として機能し、凝集した機体は目的地到着前に隊形移動へ移行する。遅延機は先行隊を停止させず、自律的に後着合流できる。
