# Morrowgear: Drone Command v0.4.2 検証結果

## 結論

低体力防御機の交代は実機で動作した。`THREAT CRITICAL`時に防御枠を表示し、`MG-DRN-803247`へ18ダメージを与えた後、同機から`DEF-4`表示が外れて健全な別機へ防御枠が移った。

## 実機確認済み

- Minecraft Java Edition 26.2 / Fabric上で`morrowgear_drone 0.4.2`を読み込み
- v0.4.1の既存ワールドを更新し、既存7機、Dock、所有権、任務状態を保持
- 周辺脅威に対して`THREAT CRITICAL 66`を表示
- 防御投入機へ`DEF-n`を表示
- 体力25%となった防御機を防御枠から外し、健全な機体へ交代
- プレイヤー、ドローン、敵Mobが存在する状態でクラッシュとログエラーなし
- 配布JARと導入JARのSHA-256一致

## 自動検証

31件すべて成功。対象はモード、飛行制御、隊列間隔、任務リーダー交代、重力弾道、3次元防御壁、近接押し戻し方向、防御リソース配分、Dock進入段階を含む。

## 実装した修正

- 矢を含む飛来物を、重力・空気抵抗込みで最大40tick先まで予測
- プレイヤーの足元から視点までを衝突候補として評価
- 3機防御を中央上段・左右下段の三角壁へ変更
- プレイヤーを狙う近接敵を無ダメージで外側へ押し戻す
- ドローンとプレイヤーの物理押し合いを無効化
- 任務IDごとに隊列リーダーを交代
- 全機飛行中の地点任務ではプレイヤー上空集合を省略
- Dock側面進入を外側待機点、入口ゲート、着艦点の3段階へ変更

## 未完了の実機確認

弓の足元弾道、通常の単独ゾンビ、側面進入Dockは、自動操作中にユーザー操作が検出されたため入力を中止した。実装と自動テストは完了しているが、これら3項目については実ゲーム上の最終目視を未完了とする。
