# Morrowgear: Drone Command v0.4.5 検証結果

## 対象

- Minecraft Java Edition 26.2
- Morrowgear: Drone Command v0.4.5
- 検証日: 2026年8月18日

## 修正内容

単機を先行させた後に全機へ任務を再割り当てすると、新しい任務で選出されたリーダーの隊列スロットが先行機より後方に生成され、先行機が引き返す場合があった。またDock発進機が混在すると、1機でも集合段階にいることを理由に飛行中の全機を集合段階へ巻き戻していた。

v0.4.5では、後方スロットへ直接戻らず、目的地へ前進しながら横方向と高度を補正する非後退合流制御を追加した。集合段階はDock発進機だけに適用し、飛行中の機体は現在位置から任務を継続する。

  - 後方の隊列スロットを与えても先行機の目標距離が増えないこと
  - 前方に使用可能な隊列スロットは変更しないこと

## Minecraft実機確認

1. v0.4.5を通常のModフォルダーへ導入し、ログで`morrowgear_drone 0.4.5`を確認した。
2. 保存済みの7機を読み込み、機体Aだけへ北東の遠方地点を指示した。
3. Aが他の6機より十分先行した状態で全7機を選択し、南東の別地点へ再指示した。
4. Aは後方の6機へ戻らず、現在位置から南東へ旋回して新しい目的地への距離を縮め続けた。
5. 後続6機は移動しながら先行側へ収束し、同じ進行方向の隊列へ合流した。
6. 任務停止、機体消失、ログ上の例外は確認されなかった。

## 判定

合格。任務再割り当て時の不要な後戻りを解消し、編隊の整列より目的地への前進を優先する自然な合流挙動になった。全機がDock上にいる場合の発進集合は従来どおり維持する。
