# Morrowgear Drone v0.5.9 検証結果

## 高速合流

- 通常巡航速度を0.44 block/tickへ変更した。
- 長距離追いつき速度を0.96 block/tickへ変更した。
- 分散収束機は予約スロットまで16ブロック以上ある場合、最大1.08 block/tickで接近する。
- 8ブロック以内から制動し、7ブロック以内ではリーダー速度と接近速度を合成する。
- 3ブロック以内ではリーダー速度への同期を強め、スロット通過後の反転を抑える。

## 地下・深水対象の追跡

- 地下対象は直上地表から2.4ブロック上を安全観測点とする。
- 水中・溶岩中の対象は`WORLD_SURFACE`から求めた液面上2.4ブロックを安全観測点とする。
- 対象そのものではなく到達可能な観測点を到着判定と旋回中心に使用する。
- 対象のX/Z移動には引き続き毎tick追従する。
- 安全観測点への到着後は`MISSION_ORBIT_ENTRY`を経て`TARGET WATCH`へ遷移する。

## 自動検証

- 通常巡航・長距離追いつき速度
- 遠距離収束の1.08 block/tick上限
- 中距離収束の段階的な制動
- 近距離でのリーダー速度同期
- 地表・液面から2.4ブロック上の観測高度
- 既存の群制御、追従、Recovery、防御、Dockを含む全74件

結果: 失敗0、エラー0、ビルド成功。

## ゲーム内確認項目

1. 離れた機体を含む編隊へ地点指示し、合流機が高速で予約スロットへ接近する。
2. スロット直前で減速し、リーダーと同じ速度で隊形へ入る。
3. 地下の生物を指定し、直上地表で旋回して`TARGET WATCH`になる。
4. 深水中の生物を指定し、水面上で旋回して`TARGET WATCH`になる。
5. 対象が地下または水中を移動した場合も、観測円の中心がX/Z方向へ追従する。
