# Morrowgear Drone v0.6.3 検証結果

## 対象

- 8機ウイング同士が同一点へ集まり、全機が重なる問題
- 分散収束と隊列形成が短時間で切り替わる問題
- 8機ウイング内部の隊形が崩れて見える問題

## 実装結果

- ウイング同士は結合せず、データリンクされた独立コホートとして同一任務を遂行する。
- 移動中は共通航路軸に対して水平8.5ブロック、高度3.4ブロック間隔のウイングアンカーを使う。
- 地点哨戒ではウイングごとに3.8ブロック離れた独立旋回層を使う。
- 追従の多重リングを3.2ブロックずつ高度分離する。
- 8機以下のウイング内部隊形をデルタ隊形とした。
- 合流後100tickの猶予時間と、6回連続の分断確認を追加した。
- 一時的な距離変化だけでは`MISSION_MOVING`から`MISSION_CONVERGING`へ戻らない。

## 自動検証

- 全86テスト成功
- 失敗0、エラー0
- ウイング間3次元分離、4ウイングの到着半径、遷移猶予、連続分断判定、安定復帰を追加検証
- Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2向けビルド成功

## 実機確認項目

- 30機規模の地点指示で4ウイングが別アンカーを維持すること
- 地点哨戒時に4つの高度層へ分かれること
- 合流直後にリーダーが再び分散収束へ戻らないこと
- 一時的な障害物回避では隊形状態が切り替わらないこと
