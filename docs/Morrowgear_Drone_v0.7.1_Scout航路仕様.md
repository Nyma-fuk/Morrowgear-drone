# Morrowgear Drone v0.7.1 Scout航路仕様

## 目的

Scoutを単なる高速機ではなく、後続ウイングの航行判断に必要な情報を先行取得する役割として成立させる。役割モジュールは移動目標を直接上書きせず、既存の群制御へ制約情報を提供する。

## 観測と共有

Scoutは地点任務中、自機周辺の開放度、頭上クリアランス、空の可視性、周辺脅威、目的地までの距離を10tickごとに観測する。報告は所有者、ディメンション、任務IDで分離され、別プレイヤーや別任務へ混入しない。

| 報告状態 | 航行への反映 |
|---|---|
| `CLEAR` | 現行の巡航高度と速度を維持 |
| `PROBING` | 高度余裕を2ブロック追加、リーダー速度上限0.78 |
| `HAZARDOUS` | 高度余裕を5ブロック追加、リーダー速度上限0.66 |
| `BLOCKED` | 高度余裕を9ブロック追加、リーダー速度上限0.52 |

## 優先順位

信頼度0.45未満、最終観測から100tickを超えた情報は航行へ使わない。速度制限は通常の地点任務における編隊リーダーだけへ適用し、合流機の追いつき処理と直接脅威への防御行動には適用しない。

この段階では航路の完全な再探索や役割別の機体性能差を導入しない。まずデータリンクが既存隊形を乱さずに航行へ作用することを確認し、その後にScout先行距離、迂回候補、目的地監視へ広げる。
