# Morrowgear Drone v0.6.4 検証結果

## 対象

- 隊列移動中に`MISSION_MOVING`と`MISSION_CONVERGING`が反復する問題
- 後続との距離に応じてリーダーが加減速を繰り返す問題

## 根本原因

- 任務フェーズと、個体が隊形スロットへ追いつくための速度状態を同じ`MISSION_STAGE`で表現していた。
- 巡航中の距離変化を編隊分断と解釈し、個体を`MISSION_CONVERGING`へ戻していた。
- 後続が11ブロック以上遅れると、リーダーの航行目標を近距離待機点へ切り替えていた。

## 実装結果

- `MISSION_CONVERGING`を初回集合専用とした。
- 巡航開始後は全機が`MISSION_MOVING`を維持する。
- 遅れた僚機だけに一時的な`CATCH-UP`速度制御を適用する。
- 7.0ブロックで開始、3.5ブロック以内で解除するヒステリシスを追加した。
- CATCH-UP機は最大1.08、リーダーと通常編隊は最大0.96 block/tickで航行する。
- リーダーの後続待ち減速処理を撤去した。
- 戦術UIに`CATCH-UP`を表示する。

## 自動検証

- 全85テスト成功
- 失敗0、エラー0
- CATCH-UPの開始・維持・解除、リーダーと非移動機が対象外であることを追加検証
- Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2向けビルド成功

## 実機確認項目

- 初回集合後に全機が`MISSION_MOVING`を維持すること
- 遅れた僚機だけに`CATCH-UP`が表示されること
- リーダーが後続距離に応じて減速しないこと
- 僚機が3.5ブロック以内へ復帰すると`CATCH-UP`表示が消えること
