# Morrowgear Drone v0.5.5 検証結果

## 修正した問題

プレイヤー追従コホートのリーダーが長時間スタックしても、健全な僚機へリーダー権限が移譲されず、Recovery機がリーダーとして残り続けていた。

## 権限移譲規則

- 短時間のRecoveryではリーダー権限を維持する。
- Recovery開始から100tick以上経過した`RECOVERY-3`、または240tick継続したRecoveryで権限を失効する。
- 健全機のうちプレイヤーまでの距離、バッテリー残量、機体IDの優先順で後継機を決める。
- コホート全体のリーダーIDと参加順位を一括更新する。
- 旧リーダーは降格後に復旧しても自動復権しない。
- リーダー機が未ロード・消失している場合は、健全機が存在すれば即時移譲する。

## 永続性

- `RecoverySince`を機体保存データへ追加した。
- 既存ワールドでは未設定値`-1`として読み込み、次のRecovery検出から計時を開始する。

## 自動検証

- 短時間Recoveryで権限を維持することを検証
- `RECOVERY-3`の100tick、通常Recoveryの240tickで失効することを検証
- Recovery機を候補から除外することを検証
- 同距離時にバッテリー残量と機体IDで決定することを検証
