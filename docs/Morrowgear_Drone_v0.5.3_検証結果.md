# Morrowgear Drone v0.5.3 検証結果

## 修正した問題

複数機へプレイヤー追従を指示した際、追従命令が機体ごとの独立命令として処理され、過去のコホート情報も残るため、全機がリーダー表示のまま旋回していた。

## 修正内容

- 一度の追従操作で選択された機体へ共通の追従任務IDを送信する。
- プレイヤーに最も近い選択機を唯一のリーダーにする。
- 全選択機へ同じコホートIDとリーダーIDを設定し、距離順の固定ランクを割り当てる。
- 追従以外の即時モードも含め、地点任務から離脱する際は古い任務・コホート情報を消去する。
- 追従時の隊形計算は所有全機ではなく、同じ追従コホートに属する機体だけを対象とする。
