# 後部推進部の局所改修 V16

未承認の比較用試作。後部の開口と奥行きは改善したが、機体全体の比率が悪いとの指摘を受けたため、この案を最終案として扱わない。
後続の[全体比率再検討 V17](../reference-balance-v17/README.md)を現在の提案とする。

元データはV15。元のファンとノーズを保持したまま、前向きの吸気口、曲がった内部ダクト、後向きの扁平な排気口、翼から排気口への接続面を作成した。
下面の浮いた平面パネルは胴体に沿う形へ変更した。

検査を口の中央だけから面内の複数点へ増やすと、カウルの後端面が排気口内部の一部を塞いでいることを検出した。該当面を切除してV17の基礎とした。
排気口の端の検査では、狭まる内壁への接触を閉塞と誤認しないよう、中央と端で要求奥行きを分けている。変更前の局所的な通過チェックだけでは十分でなかった。

ゲームや配布ファイルは変更していない。画像は正本メッシュの実レンダリング。航空性能の検証は実施していない。
