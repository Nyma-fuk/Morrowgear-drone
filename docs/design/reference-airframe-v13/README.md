# X-47系の造形と飛行機構の整合レビュー

## 結論

**現在の機体は、飛行機らしい造形を持つゲーム用コンセプトであり、航空力学的な成立を確認済みの航空機ではない。**

今回は、前回モデルの平板に近い翼断面と厚い後端を見直した比較候補 V13 を作成した。
左右の平面輪郭とローター位置は V11 から維持し、前後断面、胴体と翼の接続、曲面を構成する面の分割を修正した。
この候補も未承認であり、元画像への一致、実機の飛行性能、ゲーム内への採用を確定していない。

## X-47から何を引き継ぐか

ここでは主に X-47B を比較対象とする。X-47A と X-47B の形状・設計目的を混同しない。
X-47B は無尾翼の自律航空機で、空母に適合する構造・着陸装置を備え、カタパルト発艦や着艦などを段階的に試験した実証機である。[NAVAIRの一次資料](https://www.navair.navy.mil/node/20006)

このまとまりのある形は良いデザインの参考になる。ただし「航空力学の唯一の最適形」「この平面輪郭を使えばどの寸法・速度でも飛べる」という意味ではない。
今回引き継ぐのは、胴体と翼が連続する量感、後退翼、突出物の整理、薄く収束する後部、機構を胴体内部へ統合する考え方である。
X-47B の内部翼型や制御則を再現したとは主張しない。

## 流線形だけでは判定できない理由

揚力は `L = 0.5 * rho * V^2 * S * CL` で表される。形だけでなく速度・密度・翼面積・迎角などの条件が必要で、実際の揚力係数も求めなければならない。[NASA: Lift Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/lift-equation/)

小型化すれば同じ輪郭でも流れの条件が変わる。実機と模型の比較にはレイノルズ数などの相似条件が関係する。[NASA: Similarity Parameters](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/similarity-parameters/)

丸い前縁、薄い後縁、なめらかな接続は断面を整理する方向ではあるが、それだけで低抵抗・高揚力・失速しにくさ・安定性を保証しない。
迎角の変化や剥離も考慮する必要がある。[NASA: Inclination Effects on Drag](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/inclination-effects-on-drag/)

今回の断面関数は `sqrt(u) * (1-u)` を基に、機器収納のための厚みを加えた造形用の仮説である。
NACA等の検証済み翼型をそのまま適用したものでも、X-47B の翼型を取得したものでもない。

## 今回のモデルで分かったこと

| 観点 | V11での状態 | V13での対応・残課題 |
| --- | --- | --- |
| 前縁と後縁 | 翼面に平坦部が多く、前後端も厚い | 外翼を丸い前縁と細い後縁へ変更。低抵抗を測定したわけではない |
| 胴体後部 | 後端まで大きな厚みが残る | 後部断面を徐々に絞った。推進・冷却装置の収納は別途確認が必要 |
| 中央胴体と翼 | 幾何的な折れが目立つ | 共通断面を補間して接続。吸気口周辺とダクト肩部はなお調整余地がある |
| タービン開口 | 大きな貫通穴がある | 開口を保持。周囲の厚みは機器収納に必要だが、前進飛行での損失・流入は未評価 |
| ノーズ | バイザーとセンサーのため鈍い面がある | 厚みを縮小したが、完全な丸い前縁にはしていない。参照画像の特徴との折り合いが必要 |
| 操縦面 | 機能の区分が明確でない | 後縁へ候補のヒンジ線を追加。作動機構・操舵量・制御性能は未実装 |
| 曲面の分割 | 新しい曲面を適用すると長い三角形辺で凹凸が出た | 制約辺を細分化して再生成。断面だけでなく実メッシュも確認 |

V13の平面輪郭は V11 と同一である。前回の V12 六面図の全寸法を正解として取り込んだわけではない。
V12には未確定な寸法仮説があるため、今回は輪郭の変更と断面の変更を混ぜず、断面変更だけの影響を比較した。

## ホバリングと巡航を分ける

### ホバリング

静止した空気に対して翼を停止させただけでは、通常の前進飛行と同じ翼揚力は得られない。機体重量を支える主役はローターになる。

現行画像の「左右に並ぶ2基のローター」が垂直推力の強弱だけを独立に変更する場合、独立入力は2つしかない。
合計推力と左右差による傾きは調節できるが、前後傾きとヨーを含めた姿勢全てを、それだけで独立制御できるとは言えない。
重心を2基の推力線に合わせても、この制御自由度の不足が自動的に解消するわけではない。
これは固定方向・固定配置・独立可変推力2入力という仮定からの設計上の推論であり、実機の制御試験結果ではない。

見た目の説明を成立させる候補は、ダクト出口の可動案内翼、ローターまたはノズルの推力偏向、前後の補助推力機構など。
単に固定の支持ステーを置くことと、操縦可能な案内翼を設けることは別である。
V13に見えるダクト内の支持部材は操舵機能を検証したものではない。新しい機構は、承認画像にないため今回勝手に追加していない。

### 前進・巡航

ローターで持ち上げながら機体を傾けて前進する方式と、翼が主に重量を支え、別の推進装置で前進する方式は異なる。
前者は今のゲーム内運用イメージを保ちやすい。一方、後者を採るなら推進装置、ダクト開口の扱い、遷移時の姿勢制御まで一緒に決める必要がある。

巡航時にファン穴を閉じる案を採る場合も、「蓋を閉めるだけで抵抗が解決する」としない。
ローターの停止・継続運転、推進手段、重量を支える能力の引継ぎが未定義な状態で、そのアニメーションだけを実装しない。

当面の世界観上の位置付けは、**X-47系の胴翼一体形状を持つ、ローター揚力主体の飛行作業機**という検討案。
「X-47Bと同じ空力性能を持つ垂直離着陸機」ではない。

## 機体バランス

左右対称は形状として保証できるが、それは左右の実質量が等しいことを意味しない。
電池・荷物・アーム・センサー・脚の質量と搭載位置を定義し、各役割・収納状態・荷物残量で重心を検討する必要がある。

`mechanics.json` の重心相当値は、密閉した本体形状を均一密度で満たした場合の体積重心である。
薄い外殻と内部機器からなる実機の重心ではない。推力線との差を示しても、実際の釣り合いが成立すると解釈しない。
翼の力が作用する位置、ピッチングモーメント、操舵余裕についても未検証。

## 結果と判定範囲

- 本体の密閉性、左右対称、ダクトの収容など7項目の幾何チェックはPASS。
- 別途12件の形状・出力回帰テストはPASS。実飛行試験でも、Minecraftの動作試験でもない。
- 同じメッシュから六面・斜視・下面斜視・無彩色のPNGを生成し、比較図を目視確認した。
- 実メッシュ三角形の中心で、定義した上面からの偏差を検査した。これは標本点での検査であり、全ての位置での誤差上限証明ではない。
- 曲面分割を修正する前は、検査で約0.121モデル単位の偏差を検出。修正後の最大標本誤差は約0.020。単位はメートルではない。
- 同じ比較カメラでの外形IoUは V11の約0.907に対し、V13は約0.886。**断面を整理した一方、元画像への輪郭一致は改善していない。** この指標は外形領域の重なりであり、「画像を88.6%再現した」という意味ではない。

したがってV13を最終形として採用せず、**断面構成を検討する比較候補**として保存する。
輪郭誤差は、厚み変更とノーズ・翼端の対応点、視点解釈を分けて再検討する。形を無理に歪めて数値だけを上げない。
元画像への忠実度と航空機としての機構整合が競合する場合、画像の変更箇所と理由を明示してから採用する。

## 実機に進めるなら必要な情報

実寸、離陸重量、役割別搭載質量、重心範囲、ローター性能、必要推力・電力、ホバリング時間、巡航速度域を先に定義する。
その上で操縦系の自由度と故障時の挙動を確認し、断面・機体・回転翼を含む解析と実験を段階的に行う。
CFDだけで完了とせず、解析モデルの妥当性、メッシュ依存性、風洞・推進系試験との照合、管理された飛行試験が必要になる。
この作業ではそれらを実施しておらず、抗力係数・揚抗比・最大速度・失速速度などを推測値で確定していない。

## 再生成

1. Blenderで `tools/drone-design/blender/build_reference_airframe_v13.py` を実行する。
2. Pythonで `tools/check_reference_airframe_v13.py` を実行する。
3. `tools/review_reference_airframe_v13.py` で比較PNGを作る。
4. `tools/test_reference_airframe_v13.py` で形状回帰テストを実行する。
5. 比較画像と全方向画像を目視確認する。数値PASSだけで外観や飛行の成立を承認しない。
