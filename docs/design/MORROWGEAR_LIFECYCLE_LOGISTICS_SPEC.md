# Morrowgear 機体ライフサイクル・物流仕様

## 1. 目的

本仕様は、機体の製造、配備、任務、補給、整備、回収を一つのゲームループとして定義する。既存のWing群制御、任務復帰、通常Dock、空中サービスステーション、サルベージ、安定したアイテムIDを維持する。

## 2. Dockと電力網

通常Dockは1機1Dockの母基地であり、飛行電力、兵装電力、弾薬、修理、モジュール交換、回収物保管を担当する。空中サービスステーションは飛行電力だけを補う中継設備であり、兵装補給と整備のための通常Dock帰還を代替しない。

Dockインベントリは27枠とする。

| 枠 | 用途 |
|---|---|
| 0-8 | 従来互換枠。機体、電池、ロール、兵装、電力入力、補修材、弾薬、回収出力、蓄電池 |
| 9-17 | サルベージ回収バッファ。満杯時は回収対象を消去せず、搬送機が保持する |
| 18-26 | 共通補給バッファ。電力入力、補修材、機関砲弾、ミサイルを必要時に検索する |

電力源はPower Cell、標準・強化・高密度バッテリー、石炭、木炭とする。石炭と木炭はDock内蔵発電機で消費される。蓄電容量は未装着4,000、標準6,000、強化10,000、高密度18,000とする。

## 3. 損耗と整備

各機体は0-1,000の3系統状態値を持つ。

| 系統 | 劣化時の影響 |
|---|---|
| 推進 | 速度と隊形制御は維持し、20tickごとの飛行電力消費だけが増える |
| センサー | Scoutの実効走査範囲が75%、重大劣化では55%になる |
| 作業系 | Engineerの作業間隔が長くなり、実効処理能力が75%、重大劣化では50%になる |

ダメージを受けた際は1系統を主損傷、残る2系統を副損傷として劣化させる。状態値420以下で定期整備対象、220以下で重大劣化とする。

整備優先度は、致命損傷、飛行電力不足、定期整備・兵装補給の順とする。軽微な劣化だけで任務とDockを往復し続けない。Dockでは銅、鉄、Morrow Alloyの順に高い回復量を持ち、最も劣化した系統から修復する。

機体のEntity保存と格納アイテムの双方に3系統を保存する。旧形式の機体・格納アイテムに値がない場合は1,000として読み込み、既存機体を消失させない。

## 4. ロール定義

| ロール | 主任務 | 複合任務での役割 | 整備値との関係 |
|---|---|---|---|
| FIELD | 無装備の標準機、指揮中継 | データリンク維持、緊急電力分配 | 推進状態のみが任務効率へ直接影響 |
| SCOUT | 広域走査、脅威通報 | Engineerへ全領域データを共有し、作業中は上空監視 | センサー状態が走査範囲へ影響 |
| ENGINEER | 採掘、伐採、植林、近接修理 | Scout台帳の対象を順序処理する | 作業系状態が処理間隔へ影響 |
| CARGO | 9スタック輸送、現場回収 | 作業完了まで待機し、回収物を指定または自動選択コンテナへ搬入 | 推進状態が航続効率へ影響 |
| SECURITY | 脅威迎撃、作業・搬送護衛 | 作業護衛からCargo護衛へ引き継ぐ | 推進状態と既存兵装資源を使用 |
| SALVAGE | POWER LOST機の吊り上げ回収 | データリンク上の対象を出発Dockへ搬送する | 推進状態が長距離搬送効率へ影響 |

CargoはDockもContainerとして扱えるため、通常コンテナとDock間の補給経路を同じ搬送契約で処理する。1つのコンテナは既存のFIFOリースで調停し、複数Cargoが同時に内容を書き換えない。

## 5. 進行とレシピ

| 段階 | 解禁内容 |
|---|---|
| Overworld序盤 | Morrow Alloy、Controller、Dock、標準電池、標準機、Scout、Engineer、Cargo、Salvage |
| Nether | Security、機関砲、強化電池 |
| Trial Chambers | レーザー、高密度電池 |
| End | ミサイル |

Morrow Alloyは鉄、銅、Redstone、木炭から未焼結材を作り、かまどまたは溶鉱炉で精錬する。標準の生産・物流系はNether到達前に使える一方、戦闘能力は進行段階に応じて解禁する。

## 6. 不変条件

1. 既存の機体ID、アイテムID、Wing、Dock割当、任務、積荷を維持する。
2. 電池の重量で速度やWing隊形を変えない。
3. 空中サービスステーションは飛行電力専用とし、通常Dockの整備・弾薬補給を奪わない。
4. サルベージ出力が満杯なら、回収対象を消去したり地上へ投棄したりしない。
5. 状態劣化はゲーム性を作るが、急な速度差によって群制御を破壊しない。
6. 新しい視覚アイテムが必要になった場合は、デザイン案の承認後に追加する。
