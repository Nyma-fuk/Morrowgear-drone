# 武器音 V2：燃焼・破裂・圧力の試聴案

追記: 機関砲とレーザーは再検討となり、[機関砲・レーザー音 V3](ROTARY_LASER_AUDIO_PROPOSAL.md)に次の試聴案を用意した。V2のミサイルは変更していない。本ページの機関砲・レーザーを承認済み仕様と扱わない。

## 状態と変更範囲

2026-09-22。飛行音は承認されたハイブリッド案を維持する。機銃、レーザー、ミサイルの試聴音だけを再制作した。Minecraft の音源、音量、発砲周期、飛行・戦闘・補給処理、インストール済み JAR は変更しない。起動・再起動・差し替えも実施しない。

本案は実装済み音の完成報告ではなく、聴感の承認を得るためのオフライン試聴である。ゲーム内の距離減衰、同時発音、遮蔽物、視覚との一致は未検証。

## なぜ作り方を変えるか

前案は減衰する正弦波で衝撃の低音を作り、細い持続音でレーザーを表現していた。これだけでは「何が燃え、破裂し、空気を押しているのか」の識別手掛かりが不足する。音量を増やしても、電子音や打楽器のような印象を強める危険がある。

今回は機銃の破裂、ロケットの噴流、爆発の不規則な成分に録音素材を使用する。合成は短い圧力パルス、散乱音、架空のレーザー機構を補うために使う。射撃や爆発の長い低音に、純音の発振器を主役として使わない。

## 聞き分ける情報

| 対象 | 時間的な構成 | 消したい印象 |
|---|---|---|
| 機銃 | 鋭い発砲、短い圧力、次弾へ続く燃焼の尾。射撃周期は既存の毎秒10発 | 金属が転がる音、着弾だけが大きい音、連続した電子ブザー |
| ミサイル射出 | 短い破裂と空気の押し出し | 発射時点で爆発したような長い重低音 |
| 点火・飛来 | 射出0.35秒後の点火、その後は燃焼する噴流 | 正体不明の短い電子音、モーター停止後も続く飛行音 |
| 接触・起爆 | 接触の短音、0.60秒の信管待ち、広帯域の爆発 | 着弾音と起爆音が同じ、音程を持つ低音が長く残る |
| 爆発後 | 爆発0.35秒後から細かい破片・砂礫の散乱 | カランコロンと規則的に鳴る金属音 |
| レーザー充填 | 圧力と内部振動が増す。充填だけは上昇を許す | 大きなサイレンや周期的な音程の上下 |
| レーザー射出・照射 | 一度の開放衝撃、安定した切断感、微細な不規則な放電 | 細い正弦波だけで作る笛音、連続する警報 |
| レーザー停止 | 回路の遮断、遅れて冷却・排気 | 照射中にも停止音が繰り返される |

レーザーが空気をプラズマ化するという音の表現は、ゲーム上の演出である。実機の物理条件、熱量、音圧を計算して再現したという意味ではない。持続するレーザー光が必ずこの音を出すとは主張しない。

## 試聴と再生成

生成先は `build/verification/weapon-pressure-v2/`。

- `missile-single.wav`：単発。射出0.45秒、点火0.80秒、接触2.00秒、爆発2.60秒、散乱2.95秒。
- `missile-salvo.wav`：4発。射出は0.10秒間隔。接触時刻は試聴用に0.19秒ずらす。実ゲームでは衝突時刻で決まる。
- `autocannon.wav`：発砲と控えめな着弾音。
- `laser.wav`：充填、開放、4.5秒の持続照射、冷却。4.5秒は試聴の長さであり、実装の照射上限ではない。
- `*-with-flight.wav`：承認済み飛行案との混合。同じ組内は共通の音量倍率。
- `*-v1-v2.wav`：前案、1秒の無音、新案の順。各区間の RMS を合わせるが、知覚上の同じ音量を保証しない。

```powershell
python tools/audio/propose_weapon_pressure.py
python -m unittest discover -s tools/audio -p 'test_*.py' -v
```

Python と numpy / soundfile が必要。前案の試聴ファイルがなければ比較音のみ省略する。生成時のネットワークアクセスは不要。出力は `build/verification` 内の別フォルダーに限定し、前案とゲームの音源の書き換えを拒否する。

## 検証と残る確認

自動検査は素材ハッシュ、再現性、波形・音量の上限、無音端、圧力の立ち上がり、持続音の継ぎ目、単音への偏り、3〜5発のイベント順、音割れ回避、飛行音とゲーム音源の不変を対象とする。爆発素材の67 Hz付近に強い共鳴があったため減衰させた。音量制限は音圧や聴覚安全性の保証ではない。

実施結果: 音声関連の自動テスト41件 PASS（既存29件、新規12件）。途中で見つかった低域共鳴と、単発音への周波数処理が先頭成分を末尾に回り込ませる問題を修正して再実行した。承認済み飛行試聴・ゲーム内音源のハッシュは生成前後で一致。インストール済み JAR の SHA-256 も作業前の記録と一致した。

合格判定にまだ必要なのは、人が聞いて、映像なしでもミサイル・射撃・レーザーの違いを識別できるか、持続音が不快でないか、飛行音に埋もれないかという確認。ファイル検査の PASS をこの確認の代用にしない。

承認後に必要な実装は、点火音を機体ではなく飛行するミサイルの位置から再生し、噴流をミサイルに追従させて接触時に止めること。爆発と破片音は着弾位置から発音する。離れた機体を同じ大きさで鳴らさず、多数機での同時発音上限と音量を確認する。追加の点火・モーター音はまだゲームに登録していない。
