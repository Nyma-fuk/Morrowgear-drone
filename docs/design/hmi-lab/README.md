## 開く

このディレクトリーの `index.html` をブラウザーで開く。サーバー・ビルド・外部サービスは不要。画像とアイコンはリポジトリー内の既存アセットを相対参照する。

Minecraftへの接続・命令送信・ワールド変更は行わない。操作状態はこのブラウザーのローカルストレージに保存する。

## 最初に試す流れ

1. 作戦地図でWing表示へ切替。ALPHAとBRAVOを選び、移動先を指定する。
2. 画面下の命令結果で、受付対象と拒否理由を見る。
3. ルートを選び、地図上に点を置く。座標入力、編集、順序変更も試す。
4. Dock・補給で東部Dockへ切替。飛行電力セルを2個投入し、接続機へ補給後、任務へ復帰させる。
5. 回収画面でMG-020を手配し、右上「進行」で回収から任務復帰まで進める。
6. 母艦の採掘で範囲確認後に開始。「進行」を4回実行し、貨物から丸石を取り出す。
7. シナリオから100機を読み込み、選択・Wing編成・任務一覧を確認する。変更済みの試作状態は初期化される。

命令受付は短い遅延後に自動反映。飛行・補給網配送・回収・母艦作業の段階進行は右上「進行」で実行する。実時間を自動で流さないため、操作途中に内容が入れ替わらない。

## 試作の制限

- 地形、敵、距離、機体位置、補給品の換算量は試作用データ。現行modの正確な数値・物理・装備仕様を保証しない。
- 母艦採掘は4段階で固定量を収納するモデル。実際の全高度掘削、ビーム、地形破壊、ドロップ算出はしない。
- 操作画面の検討用なので、船内への移動は状態変更。歩行できる3D船内はない。
- HUDは2D作戦領域上で情報量と操作を比較する。Minecraftの3Dカメラ投影・遮蔽・全距離ビーコンの実装を検証するものではない。
- 補給・貨物は数量指定で移す。Minecraftの27スロット、カーソル保持、Shiftクリックの完全再現はしていない。
- 補給網の倉庫は候補2か所。倉庫在庫は試作の所持補給品と共用する。任意のワールド容器を探索する機能ではない。
- 通信はローカル判定。所有権、専用サーバー、プロトコル互換性、実通信遅延の試験には使えない。
- サービス充電Dockの子機アニメーション、特殊エフェクト、音声、母艦消失後の船内回収はこのブラウザー版に未実装。
- 狭幅用CSSは実装済みだが、スマートフォンでの実操作と全画面の視認性は未検証。

## 試験

```powershell
node --test docs/design/hmi-lab/model.test.cjs docs/design/hmi-lab/app.test.cjs
```

モデル試験は機数境界、命令の部分拒否、状態変化、Wing8機上限、予約、資源保存、回収復帰、母艦収納、配送先消失を扱う。

画面側試験はNode上の簡易DOM代替によるテンプレート生成と操作ハンドラーの単体試験。実ブラウザーでクリック・描画した試験ではない。画像参照の実在も確認する。

ブラウザー操作ツールはローカルURLへのアクセスをセキュリティポリシーで拒否した。回避経路は使用していない。ユーザー提供の作戦地図画像で初期画面の表示を確認したが、その他の画面とレスポンシブ表示を目視PASSとはしていない。
