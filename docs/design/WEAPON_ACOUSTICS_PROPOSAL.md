# 武器音とガスタービン複合機体音の再設計

日付: 2026-09-22。状態: **試聴用提案、ゲーム未接続・未反映**。

追記: 本ページのハイブリッド飛行音はユーザー承認済み。武器音は再検討となり、
[武器音 V2：燃焼・破裂・圧力の試聴案](WEAPON_PRESSURE_AUDIO_PROPOSAL.md)で作り直した。
本ページとV1音源は比較用に保持する。V1武器音を承認済みの仕様として扱わない。

## 機体設定の訂正

「バッテリーで稼働する」というゲーム仕様から「ガスタービンがない」と推測してはいけない。
ユーザー指定は、ローター、インテーク、ガスタービンを持つ複合機体である。
したがって、前回案の電動ファンだけという前提を撤回する。

音響上は次の流れを想定する。

```text
インテーク -> 圧縮段 -> 燃焼器 -> タービン段 -> 排気
左右の揚力ファン + 機体構造の共振 + 電力系・各武器の負荷
```

現実のガスタービンは圧縮器・燃焼器・タービンを備える。
燃焼器はピストンエンジンのような間欠的な爆発音とは異なる設計として扱う。
構成の根拠: [NASA: Brayton Cycle](https://www.grc.nasa.gov/www/k-12/BGP/brayton.html)、
[DOE: Gas Turbine Combustion](https://netl.doe.gov/sites/default/files/gas-turbine-handbook/3-2-1-1.pdf)。

バッテリーとタービンの軸・発電機の接続、燃料種類、熱収支は現行Modで定義されていない。
今回の音響案はこれらを勝手に確定しない。燃料アイテム、電力消費、性能、POWER LOST条件も変更しない。

新しい飛行試作は、ファン、圧縮段、燃焼器、タービン段、排気、機体構造、吸気の7層。
燃焼器は低域の連続した圧力感を担い、タービン段は別の回転成分を担う。
前案の基本ファンと吸気は保持し、全層の音量を一律に上げない。
周波数・音量・共振はゲーム向けの仮定であり、実機測定や音響解析の結果ではない。

## 全体の音の役割

| 音 | 主に伝えるもの | 避けるもの |
|---|---|---|
| 飛行 | 大きな推力を持つ精密機械の存在と負荷 | 常時の白色ノイズ、無意味な周期的音程上下 |
| 機銃 | 高密度の発砲、圧力、送り機構 | 薬莢風のカランコロン、着弾だけが支配する混合 |
| レーザー | 装置内部の蓄積、照射開始、安定した高出力運転、冷却 | インベーダー風のビープ、サイレン、長時間の鋭すぎる純音 |
| ミサイル | 射出、点火、飛来、接触、信管、爆発、落下物という順序 | 発射と爆発の同一音、何でも同時に鳴る長い轟音 |

帯域を完全に分けるのではなく、時間形状も分ける。飛行は連続、機銃は強い立ち上がりの反復、
レーザーは充填後に安定する持続音、ミサイルは複数の独立した短いイベントで判別させる。
ノイズの全除去も全復活も避け、必要な気流と衝撃だけを残す。

## 機銃

想定動作: 送り機構の動作、発砲圧力、機体の取付部の短い共振、着弾。
A-10のような連続した圧力感を方向性として使うが、実録音の複製ではない。

現在の実弾判定は2 tickごと、通常20 TPSなら毎秒10発。音源内の発砲も0.1秒ごととし、
実弾数を変えずに毎秒58発の音だけ鳴らしていた旧音源とのずれをなくす。
短い破裂成分、低域の圧力、素早く減衰する取付部の響きを組み合わせる。
長く鳴る金属打音を加えない。試作には別音源の小さな着弾音も用意する。

現行の発音は成功発砲中でもtickの8周期条件に依存するため、最初の発砲と発音開始が
一致しない可能性がある。採用時は成功発砲イベントを起点にし、射撃が止まれば新たな発音を止める。
長いループが射撃終了後に残ることや、1発ごとに長いバーストが重なることを防ぐ必要がある。
この接続変更は今回未実装。0.4秒単位の試聴を、実ゲームの接続確認と混同しない。

## レーザー

試作は架空の高出力装置の音。光そのものが必ずこの音を発するという物理的主張ではない。
電力制御・回転冷却・射出口周辺・対象の熱反応という発音位置を分ける。

| 段階 | 想定と音 | 停止・継続条件の設計 |
|---|---|---|
| 充填 | 接続機構の短い動作音、低い電力系の唸り、ゆっくり上がる共振成分 | CHARGE開始時だけ。キャンセルや照射開始で充填を止める |
| 照射開始 | 蓄積が解放された短い圧力感と高域の鋭い立ち上がり | FIRE開始時の1回。各周期で再演しない |
| 持続照射 | 固定1160 Hz付近の細い輪郭と96 Hz系の低い負荷感。周辺成分で厚みを作る | FIRE中だけ。音程を上下させない。これは試聴用周波数であり可聴性は評価待ち |
| 着弾 | 小さな焼け・熱反応。射出口ではなく対象側で鳴る | 実命中にだけ追従。音量と発音数を抑える |
| 終了・冷却 | 遮断の短い動作音、バルブ、圧力解放、ポンプの減衰 | 照射停止で1回。再充填との重なりを管理する |

照射時間、威力、HEAT、武器電力、敵への照準は変更しない。
試聴の充填2.75秒・照射4.5秒は音色比較の固定長であり、実戦の照射時間制限ではない。
カートリッジ排出音は採用しない。現在の統合レンズ型機体の動作に合わせる。

## マイクロミサイル

現行実装は、射出時と7 tick目の点火時に同じ `MISSILE_LAUNCH_SOUND` を違う音程で使っている。
このため音源の差し替えだけでは、射出と点火の機構差・位置差が十分表現できない。

| 段階 | 新しい音の役割 | 現在との接続条件 |
|---|---|---|
| 射出 | 短い「パッ」。発射筒の圧力と解放 | 発射筒の位置、発射した1発ごと |
| 点火 | 空中での鋭い立ち上がりと噴流 | `motorIgnited`への遷移、ミサイルの現在位置で1回 |
| 飛翔 | 小さな推進音 | 生存・点火済み・未着弾の間のみ、ミサイル位置に追従。途中参加時に過去の点火を再演しない |
| 着弾 | 爆発より小さく硬い接触音 | 接触した位置。刺さった場合もまだ大爆発は鳴らさない |
| 信管 | 音を埋め尽くさない短い間 | 現行12 tickを維持。警告ビープは加えない |
| 爆発 | 高速な立ち上がり、圧力の胴鳴り、短い低域の尾 | 実爆発の位置。実際に破裂した個体の順に鳴る |
| 破片 | 遅れて落ちる粒と小石 | 現行の爆発7 tick後という予約を維持。消去だけで爆発・破片を鳴らさない |

通常20 TPS時の試聴では、4発を0.1秒間隔で射出し、各発射から0.35秒で点火、
接触から0.60秒で起爆、起爆から0.35秒で破片音。発射数3-5の全ケースを数値検証する。
飛行時間は試聴用固定値。実ゲームではイベントと同期し、音だけの固定タイマーで着弾を先取りしない。
TPS低下時は実際の状態遷移が基準であり、常に実時間0.35秒で点火する保証はしない。

発射後の点火・飛翔音を新しいイベント・ループに分ける接続は未実装。
本採用時には、着弾、死亡、消去、追跡終了、次元変更で必ず停止し、古い機体に残留しないことを確認する。

## 試聴ファイル

出力先: `build/verification/weapon-acoustics-proposal/`。すべて独自合成、mono 48 kHz。

| ファイル | 内容 |
|---|---|
| `hybrid-flight.wav` | ガスタービンを含む7層版のホバリング・巡航・減速、20秒 |
| `autocannon-candidate.wav` | 飛行音を背景にした掃射と小さな着弾、5秒 |
| `laser-candidate.wav` | 飛行音、充填、照射、着弾、冷却、11秒 |
| `missile-candidate.wav` | 飛行音、4発射出、点火、着弾、遅延爆発、破片、8秒 |
| `*-before-after.wav` | 前半が前回のソース音、無音1秒後に新案。RMSを合わせた音色比較 |
| `*.ogg` | 武器13種と飛行2種の素材候補。ゲームリソースとは別保存 |
| `report.json` | 音量等の測定値、試聴イベント、前回リソースハッシュ、未反映の記録 |

各候補の飛行音は比較用の一定ゲイン。距離・方向・遮蔽は再現しておらず、
「ゲーム内で機体から聞こえる」「戦闘中に埋もれない」と実証したものではない。
比較音はRMSを揃えるが、聴感上の等音量を保証しない。
旧ミサイルの音程変更までは再現せず、素材を共通の進行に置いた比較とする。
旧機銃の着弾はバニラ音のため、その録音を捏造せず、A/Bでは双方の着弾を除外する。

```text
python tools/audio/propose_weapon_acoustics.py
python -m unittest discover -s tools/audio -p "test_*.py" -v
```

ソースとインストール済みJARは変更しない。生成先がゲームリソースの場合は拒否する。
今回の音響案のためのJava変更、ビルド、ゲーム操作、起動、差し替えは行わない。

## 採用時の検証

自動試験は素材の形式、ピーク、RMS、DC、波形連続性、再現性、レーザーの固定音程、
機銃の発砲間隔、3-5発のミサイルのイベント順・位置区分・停止時点、既存音源保護を扱う。
既存飛行案と既存のゲーム向け音源試験も再実行する。

2026-09-22の実施結果は29件PASS: 既存ゲーム音源8件、前回飛行試作9件、今回武器・複合機体音12件。
武器13素材のVorbisデコード後ピーク最大は0.795、クリップなし。これはデジタル値であり実音圧ではない。
全既存Oggのハッシュは不変。インストール済みJARも作業前後のSHA-256が一致した。
実ゲームの聴感、定位、多数機での混合評価は未実施。

実ゲームでは、単機と複数機、機銃・レーザー・ミサイルの混在、近距離と遠距離、
頭上通過、屋外・床近傍・建物近傍、低TPS、途中追跡、死亡・着弾・チャンク離脱を確認する。
ループ終了と単発イベントの二重再生、8機以上での過大な音圧や高域の疲労も検証する。
音響Modがある場合は反響・遮蔽の二重処理を避ける。
気持ちよさ、迫力、定位、聞き疲れは数値PASSでは判定せず、試聴と実ゲームで受け入れ判定する。
