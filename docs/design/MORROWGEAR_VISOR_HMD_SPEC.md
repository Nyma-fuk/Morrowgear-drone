# Morrowgear バイザー HMD 情報設計

更新日: 2026-08-23  
状態: UI/UX検討案。アイテム名、外観、アイコン、最終配色は未承認。

## 1. 目的

Morrowgear バイザー（仮）は、装着中のプレイヤーへドローン群の状態を投影するHMDである。
統合戦術管理画面を常時表示するのではなく、移動・建築・戦闘を妨げない範囲で、現在必要な情報だけを提示する。

設計原則は次のとおり。

- 通常時は静かにする。
- 明示選択、異常、戦闘を優先する。
- 8機までは個体を扱え、100機規模ではウイング単位へ自動集約する。
- 色だけに依存せず、記号、形、文言を併用する。
- 画面中央、ホットバー、体力、空腹、ボスバーを覆わない。
- バイザーは状況把握を担い、複雑な任務編集は統合戦術管理画面へ委ねる。

## 2. 情報の3層

### Layer 1: 常時情報

画面上端へ1行だけ表示する。

- オンライン機数
- 任務中、Dock、帰還中、Recoveryの集計
- 現在のプレイヤー脅威度
- データリンク状態
- 選択中のウイングまたは個体

正常時は数値と短い状態だけにし、個々のドローン名は並べない。

### Layer 2: 状況情報

選択中または現在の行動に関係する情報を左右へ表示する。

左側はウイング・任務、右側はフォーカス対象の詳細とする。

左側:

- ウイングID、役割構成、リーダー
- 任務名、進捗、目的地、ETA
- 稼働機数、Recovery機数、帰還機数
- Scoutの検出、Cargoの回収、Engineerの作業状態

右側:

- 個体ID、役割、所属ウイング
- 機体HP
- 飛行用バッテリー
- 兵装電力
- 機関砲残弾、ミサイル残数、レーザー熱
- 現在の武器、戦闘状態、任務状態
- Dock、Dockまでの距離、帰還余力
- データリンク品質、Recovery、スタック状態

### Layer 3: 警報情報

警報は通常表示を押しのけて表示する。ただし同種警報は集約し、最大4件までとする。

- プレイヤーへの重大な脅威
- 機体喪失の危険
- 飛行用バッテリーの帰還限界
- 兵装継続不能とDock帰還
- Dock進入経路なし
- データリンク喪失
- スタックまたはRecovery長期化
- 機体破壊

警報が解消しても即座に表示を消さず、短い安定時間を設けて点滅や表示入替を防ぐ。

## 3. 表示優先度

| 優先度 | 対象 | 表示例 |
|---|---|---|
| P0 CRITICAL | プレイヤーまたは機体の即時危険 | 強敵の攻撃、墜落余力、Dock経路なし、機体破壊 |
| P1 ACTION | 対応中または対応が必要 | RTB、充電、代替機派遣、Recovery、兵装枯渇 |
| P2 MISSION | 現在の任務と選択対象 | 進捗、ETA、攻撃対象、作業ブロック、輸送経路 |
| P3 STATUS | 正常な背景情報 | 追従、哨戒、待機、Dock待機、正常な充電 |

同じ優先度では次の順で表示対象を決める。

1. プレイヤーが固定した個体またはウイング
2. プレイヤーを直接防御・支援している機体
3. 現在交戦中の機体
4. 異常のある機体
5. 現在選択中の任務に属する機体
6. 視線を向けている機体
7. プレイヤーに近い機体

固定対象はP0警報以外では勝手に切り替えない。

## 4. 個体表示と集約

### 1～8機

- 選択中ウイングの全個体を簡易ストリップで表示できる。
- 個体ごとにHP、飛行電力、兵装電力、状態記号を表示する。
- 詳細値はフォーカス中の1機だけに表示する。

### 9～32機

- デフォルトはウイングカードへ集約する。
- 異常機と選択機だけ個体表示へ展開する。
- 同一ウイング内の同じ警報は `LOW POWER x3` のようにまとめる。

### 33～100機以上

- 常時表示は集計と最大4ウイングに限定する。
- 個体表示は選択機、リーダー、Recovery機、P0/P1対象だけにする。
- 画面内の全ドローンへ名前やバーを表示しない。

## 5. 画面構成

```text
┌ FLEET 96 | ACTIVE 72 | RTB 5 | REC 2 ───── THREAT: ELEVATED ┐
│                                                              │
│ [WING / MISSION]                         [FOCUS UNIT]         │
│ ALPHA-03  EXCAVATE 68%                   MG-DRN-2041          │
│ 6/8 ACTIVE  1 RTB  1 REC                 HP 84  FLT 63        │
│                                           WPN 42  LASER HOT    │
│                         ◇ TARGET                             │
│                      3 GUARDS / 18m                          │
│                                                              │
│ [ALERT] MG-DRN-2041 RTB / WEAPON SERVICE                     │
└──────────────────────────────────────────────────────────────┘
```

- 上端: 全体状況
- 左上: 選択ウイングと任務
- 右上: フォーカス個体
- 中央周辺: 照準、選択対象、戦闘対象だけ
- 画面端: 画面外のP0/P1対象または固定対象の方向
- 下端: 警報1行。ホットバーと重ならない高さに置く

## 6. ワールド投影

### ドローン

選択中、警報対象、交戦中の機体だけをブラケットで囲む。

- 個体IDまたは短縮ID
- 役割アイコン
- 状態
- 飛行用バッテリーの簡易バー
- 距離

### 敵対対象

- 敵そのものの脅威度
- プレイヤーに対する危険度
- 割当済み迎撃機数と必要機数
- 使用中の攻撃方式

### Dock

Dockは帰還・充電が関係するときだけ表示する。

- 距離
- 使用中、空き、待機列
- 帰還機
- 充電進捗
- 進入経路異常

## 7. 状態表現

- シアン: 正常なデータリンク、選択、走査
- 白: 基本文字、非アクティブ情報
- 緑: 任務正常、補給完了
- アンバー: 注意、予備量接近、Recovery
- 赤: 交戦、重大警報、機体喪失危険
- マゼンタ: データ異常、リンク不整合など通常戦闘と区別すべき障害

バーは色だけでなく、残量数値と形状変化を併用する。点滅はP0に限定する。

## 8. 表示モード

### Compact

装着時の標準。全体状況、警報、選択対象だけを表示する。

### Focus

視線を向けたドローン、Dock、敵、作業地点の詳細を一時展開する。

### Wing

選択中ウイングの構成、任務、機体ストリップを表示する。

### Combat

交戦開始時に自動移行する一時レイアウト。敵の脅威度、迎撃割当、味方の兵装・帰還状態を優先し、Cargoや待機中機体を隠す。

## 9. 操作方針

- 1操作で表示ON/OFF
- 短押しでフォーカス候補を巡回
- 長押しで現在対象を固定・解除
- ウイング単位と個体単位を切替可能
- 任務発令やウイング再編成は統合戦術管理画面を開く

既存キーとの衝突を避けるため、具体的なキー割当は実装時に設定画面へ登録する。

## 10. 更新頻度と負荷

- サーバー側の完全スナップショットは毎tick送信しない。
- 通常テレメトリは5Hz、重要警報はイベント駆動で即時送信する。
- クライアント側でバーと位置を補間する。
- 画面外、非選択、正常な個体はウイング集計だけを送る。
- 地形マップは常時描画しない。地図は統合戦術管理画面の責務とする。

## 11. 設定項目

- HUDスケール
- 不透明度
- Compact表示量
- ワールド投影距離
- 個体ラベル表示数
- 警報音ON/OFF
- 画面揺れ・点滅の軽減
- 色覚補助パレット
- 戦闘時自動切替ON/OFF

初期設定では反復音を使用せず、正常状態の通知は表示しない。

## 12. 実装順序

1. テレメトリDTOと優先順位エンジン
2. 1機、1ウイング、100機を対象にした優先順位テスト
3. Compact HUDの仮表示
4. Focusとワールド投影
5. Combatレイアウト
6. バイザーアイテム、装着条件、レシピ
7. 承認済みデザインによるアイコンと装着モデル
8. 解像度、GUIスケール、他HUDとの重なりを実機確認

## 13. 承認が必要な事項

- アイテム正式名
- 頭装備として置き換えるか、外部スロットを導入するか
- HMDの外観、アイコン、装着モデル
- Compact HUDの情報量
- 操作キー
- 警報音の有無
- 最終配色と透明度
