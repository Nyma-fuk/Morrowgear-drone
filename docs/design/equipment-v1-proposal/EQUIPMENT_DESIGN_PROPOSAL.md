# Morrowgear 装備デザイン案 V1

**状態:** 承認済み  
**ゲーム反映:** 実施済み

## 共通意匠

- Family Aと同じ暗色装甲、摩耗した合金、シアンの埋込表示、オレンジの整備ラッチを使用する。
- 役割差は色ではなく、輪郭と前面機構で識別できるようにする。
- 高精細レンダーだけでなく32px縮小時の判別性を確認する。
- アイコン、手持ちモデル、配置モデルは可能な限り同じ立体正本から派生させる。

## アイテム

| アイテム | 識別形状 |
|---|---|
| Field Drone Unit | 折り畳まれたFamily A機体、左右ダクト、前面バイザー |
| Scout Module | 上部アンテナ、縦長センサーレンズ |
| Cargo Module | 左右バンパー、前面3セル、中央オレンジセル |
| Engineer Module | 大型円形作業エミッター、下部工具ジョー |
| Security Module | 閉鎖装甲、横長脅威センサー、Aegis側面装甲 |
| Dock Item | 小型化した低床Dock、中央充電接点、4整備ラッチ |
| Controller | 画面、入力ホイール、物理キー、アンテナ、一手グリップ |

## Dock

- 3x3の低床プラットフォームとし、支柱は設けない。
- 四辺に開放アプローチを持ち、上面・側面からの進入を塞がない。
- 中央は低い八角形クレードルと十字充電接点で構成する。
- 四辺のガイドは低く、機体脚と干渉しない高さに抑える。
- シアンの周縁表示とオレンジの機械式ロックを分離する。

## Controller

- 右手一手保持を基準とする。
- 画面がプレイヤー側を向き、操作面を手や腕で隠さない。
- 右側に入力ホイールと4物理キー、下面にグリップとトリガーを配置する。
- インベントリアイコンと手持ちモデルを同じ立体正本から派生させる。

## 承認後

1. 承認済みランディングギアを4機の最終モデルへ統合する。
2. 各アイコンをMinecraft用解像度へ最終調整する。
3. Dockを9ブロックの位置別モデルとテクスチャへ変換する。
4. Controllerをアイテムモデルへ変換し、一人称・三人称表示Transformを調整する。
5. Java Modをビルドし、Launcher用JARへ同期する。
6. インベントリ、手持ち、Dock配置、着艦、アイテム保持をMinecraft内で確認する。
