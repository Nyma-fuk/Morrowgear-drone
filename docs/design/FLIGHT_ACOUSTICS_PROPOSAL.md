# 飛行音の機構別再設計案

日付: 2026-09-22。状態: **試聴用提案。ゲーム未接続・未反映**。

追記: ユーザーから「バッテリー駆動だが、ローター・インテークに続くガスタービンを搭載する」
との指定があったため、電動系だけを想定した初版の前提を修正した。
最新案は [武器音とガスタービン複合機体音](WEAPON_ACOUSTICS_PROPOSAL.md)。
本ページの5層版と試聴物は比較用として残す。最新試作は燃焼器・タービン段を加えた7層版で、
既存バッテリー仕様に新しい燃料消費を追加したものではない。

## 目的と判断

クリアさを維持しつつ、空気を動かす圧力、回転体、機体構造が感じられる音にする。
前回の広帯域成分削減では、48/96/144 Hz と184/368/736 Hzの一定音が支配的になった。
実装上も速度だけで二つの音源の比率を決めている。これは無線のような濁りを除くには
有効だったが、揚力を維持する負荷や排気の変化まで減らす結果になった。

今回の試作は、全帯域のノイズを戻したり音量だけを上げたりせず、発音理由がある成分を
分けて構成する。現行音源・Javaコード・JARは変更しない。レーザー音も今回の対象外。

## 事実・仮定・演出の区別

| 区分 | 内容 | 扱い |
|---|---|---|
| 実装で確認 | 飛行用バッテリーで稼働し、着艦・電源喪失で飛行ループを停止する | 維持 |
| 実装で確認 | 左右ファン、後部吸気・排気形状。参照ファン生成は12枚羽根 | 音の構成を考える手掛かり |
| 実装で確認 | 音源はmonoで機体位置に追従。速度依存のidle/cruise比率とピッチ補間がある | 位置追従は維持。負荷の表現は再設計候補 |
| 実装で確認 | このModの音声コントローラーに壁材・反射経路・温度場の計算はない | 反響が実装済みと扱わない。他Modや音声機器の処理は別 |
| 旧仮定 | 電動の左右ダクテッドファン、高速圧縮段、後方への推進気流という音響上の装置構成 | 電動系のみという前提は撤回。最新案はガスタービンの燃焼器・回転段を含む |
| 仮定 | 回転40 Hz=2400 rpm、12枚羽根の通過480 Hz | 試聴用値。実機推力・騒音測定・CFDから導出した値ではない |
| 演出 | 78/156/312 Hz付近の外板・ダクトの響き、1280 Hz付近の高速回転感 | 共振解析の結果ではなく、機構を想定した音色設計 |

外見だけで推力、回転数、音圧、共振周波数は確定できない。モデルの表示用ローター角速度は
視認性を目的に調整されているため、そのまま音響周波数の根拠にはしない。

## 機構と音の対応

| 音の層 | 発生を想定する場所と原因 | 狙い・避けるもの |
|---|---|---|
| 揚力ファン | 羽根通過による周期的な圧力変動と流れの乱れ | 「ヴルルル」に相当する回転感。ホバリングでも残す。大型ヘリの遅い打撃音にはしない |
| 高速回転段 | 圧縮段・回転機構の狭帯域成分とその周辺 | 細い「ヒューン」は控えめ。サイレンの周期的な上下や耳を刺す純音を主役にしない |
| 推進排気 | 噴流と周辺空気の混合・圧力変動 | 中低域の「ゴォー」。加速時に厚くする。常時の広帯域のザー音を避ける |
| 構造共振 | 上記振動がダクト・フレーム・外板を励振する | 別の発振器を足さず、ファンと排気の信号を減衰共振系に通す。壊れた部品のガタつきにしない |
| 吸気・表面気流 | 吸気口や外皮の周辺を流れる空気 | 機体近傍の空気感。速度が増すと少し加えるが、主音を覆わない |

試作ではこの5層を個別に取り出せる。外板の響きだけを無関係に強めるのではなく、
加振源との関係を保持する。比較時の平均レベルは揃えるが、RMS一致は聴感上の等音量を保証しない。

## 熱、反響、距離

「熱反射の音」を独立した発振音として追加するのは適切でない。
排気の温度差や流速差がある場では、乱れによる発音と、温度・風による音の伝わり方の変化を
分けて考える。温度勾配は音を屈折させ、地面・壁面は音を反射する。

発音と伝播の扱いは、[NASAのジェット騒音解説](https://www.nasa.gov/general/nasa-has-helped-hush-aircraft-engine-noise-for-decades/)、
[NASAのエンジン騒音予測資料](https://ntrs.nasa.gov/api/citations/20120012957/downloads/20120012957.pdf)、
[航空機騒音の生成・伝播・可聴化のレビュー](https://ntrs.nasa.gov/api/citations/20200002351/downloads/20200002351.pdf)を参照した。
これらは実在航空機の資料であり、モロウギアの形状・質量・性能を検証するものではない。

反響を基本ループに焼き込むと、開けた空中でも格納庫の響きになる。したがって次の扱いを提案する。

| 環境 | 提案する聴こえ方 |
|---|---|
| 開けた上空 | 直接音主体。長い残響なし |
| 硬いDockや地面の近く | 経路差に応じた短い反射。単なる低音ブーストではなく、干渉による周波数ごとの増減 |
| 建物・崖の近く | 調べた面の方向・距離に応じた少数の初期反射。どこでも同じエコーにしない |
| 草地・柔らかい地面 | 硬い面より反射を弱める。材質値はゲーム用近似として検証する |
| 接近・通過・遠ざかり | 位置、相対速度、吸排気の向きに応じて変化。遠くでは細かな高域より本体の存在感を残す |

試聴用の環境比較は、音源高さ8 m・聴取者高さ1.6 m・水平距離12 mの仮想平面と、
仮想の壁面反射を加えたもの。固定の簡易例であり、Minecraftの地形・遮蔽・温度を再現していない。
高温排気や超音速噴流は現在のModで物理計算していないため、熱による屈折や衝撃波音を
実在する挙動として追加しない。まず直接音と近傍反射までで十分と判断する。

## 飛行状態への接続案

速度は回転負荷そのものではない。静止ホバリングも揚力を必要とするため、
将来の接続では「揚力負荷」「前進推力」「気流」「回転応答」を分離する。
Minecraft内の速度・加速度を現実のSI値と同一視せず、既存飛行状態から正規化した制御値を得る。

| 状態 | 音の変化 |
|---|---|
| 電源を入れて離陸 | 回転段が先に立ち上がり、ファンの圧力音が増す。着艦判定が外れた瞬間に最大音量にしない |
| ホバリング・低速旋回 | ファンと低い構造音が主。速度ゼロでも消音しない |
| 加速・上昇・重量物牽引 | 推力負荷を増す。排気・圧力の変化に短い応答遅れを設ける |
| 定速巡航 | 前進気流と後方排気が安定。常時の無意味な音程上下を避ける |
| 強い旋回・姿勢補正 | 実際の推力要求に応じて短く負荷感が増す。描画上のロールだけで過剰に唸らせない |
| 減速・着艦 | 前進排気は減っても支持するファンの音は残し、接地後に減衰する |
| レーザー充填 | 共通電源・冷却の負荷感は別レイヤー候補。レーザーのビープ音を飛行基本音に混ぜない |
| POWER LOST・死亡・格納 | 既存の停止契約を守る。落下中の風切りが必要なら、稼働中ファンとは別音にする |

今回の20秒試聴は、ホバリング4秒、4秒で巡航側へ移行、巡航6秒、4秒で戻り、
ホバリング2秒という音色比較。回転加速、実機位置、距離減衰、地形判定、旋回負荷との接続は未実装。

## 多数機と互換性

- 5層は試作時の設計単位。全層を100機分の音源として常時再生する設計にしない。
- 本接続では近傍少数機を詳細にし、遠方は重要音を選別する。現行の飛行最大8機・機数補正を基準に検証する。
- 同一ループの重なりによる不自然なうなりを避ける。機体別微小ピッチ差だけで十分か、実ゲームの編隊で確認する。
- 反響・遮蔽Modと二重処理しない。将来の独自環境処理は独立したOFF設定と劣化時の直接音フォールバックが必要。
- 反射判定は読み込み済み範囲だけ、回数上限とキャッシュを設ける。音のためにチャンクを読み込まない。
- 音の変更で飛行AI、敵発見、電力消費、ドッキング判定は変えない。

## 検証と採用条件

自動試験は、発音周波数の関係、再現性、有限値、無音欠落、ピーク、過剰な持続高域、
状態間混合、反射の遅延、Oggデコード、既存リソース保護を対象とする。
自動PASSを「かっこよい」「耳に負担がない」「ゲーム内で正常」の根拠にしない。

2026-09-22の実施結果: 提案音源9件・既存音源8件、計17件PASS。
反射フィルターの試験で、初回は発音より前に微小な信号が出る問題を検出した。
反射用を時間方向に因果的なフィルターへ修正し、入力前は完全に無音であることを再確認した。
最終Oggのピークはホバリング0.445、巡航0.464、RMSは0.099/0.096。
3 kHz以上のエネルギー比は0.31%/0.81%。数値はデジタル信号の値であり、実音圧ではない。
前回の飛行音源2件とインストール済みJARは作業前後のSHA-256が一致した。
Java・ゲームリソース変更がないため、この提案のためのJAR再ビルドは行っていない。

採用前に確認する項目:

1. 比較音で、単に大音量・低音になっただけではなく機械としての厚みがあるか。
2. 小型スピーカーでも構造感が聞こえ、ヘッドホンでは低音・狭帯域音が過剰でないか。
3. 数分のホバリング、8機、32機、100機近傍で、耳障りなうなりや音量の跳ねがないか。
4. 地面・建物・上空で、余韻の長さと音源位置が一致するか。
5. 離着陸、急旋回、牽引、電源喪失、チャンク移動、画面切替で残留・途切れがないか。
6. 遮蔽・反響系Modとの併用時、二重の残響や性能低下がないか。

今回はゲームの操作を行わない指示に従い、実ゲーム確認・差し替え・再起動を実施しない。
