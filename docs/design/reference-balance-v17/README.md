# 主翼・浮上ファン・後部推進部の比率再検討 V17

## 状態

2026-09-21。デザイン確認用の未承認3D試作。ゲーム、配布JAR、設置済み機体は変更していない。
画像はすべて同一の `airframe.blend` の実レンダリングであり、画像生成による別形状の提示ではない。

## 見直した理由

V15の後部は小型の開口風パーツで、奥行きのある排気機構になっていなかった。
V16では吸気口と排気口を大型化したが、主翼と浮上ファンの比率を据え置いたため、後部だけが重い造形になった。
「主翼とローターとスラスターのバランスが悪い」という指摘に対し、部品を個別に拡大する方式をやめ、全体の比率を再配分した。

造形上の役割は、主翼＝巡航、双ファン＝浮上、後部の扁平開口＝前進推進とする。これはゲーム用の視覚的な設計意図であり、実在の動力系や飛行性能の検証ではない。

## 相対寸法

| 項目 | V16 | V17 | 判断理由 |
| --- | ---: | ---: | --- |
| 翼幅 | 9.673 | 8.900 | 外翼の空白面積を抑え、胴体・浮上ファンとの釣り合いを改善 |
| 浮上ファン公称直径 | 1.800 | 2.040 | 機体を浮かせる装置としての視覚的な存在感を増やす |
| ファン径／翼幅 | 18.6% | 22.9% | 外翼だけが大きく見える比率を是正 |
| 吸気口の幅・片側 | 0.640 | 0.547 | 幅を確保しつつ高い箱状の張り出しを抑える |
| 後部開口の幅 | 2.070 | 1.656 | 後部だけが過剰に大きくならないよう調整 |
| 後部開口の高さ | 0.314 | 0.239 | 薄い翼から連続する扁平な出口へ整理 |
| 後部開口幅／翼幅 | 21.4% | 18.6% | 主翼、浮上装置、推進口の優先順位を揃える |

数値は造形用の相対単位。メートル、推力比、流量比ではない。V15の吸気口風の黒い面の幅は0.260であり、V17はそこまで小さく戻したものではない。

## 形状の規則

- 前方を-Y、右を+X、上を+Zとする。中心面X=0を左右対称の基準とする。
- 部品ごとの拡縮ではなく、外装、開口、ダクト、ファン、パネル線に同じ連続した座標変換を適用する。付属部品だけを動かして隙間を生まないため。
- ファン周囲は公称半径0.90から1.02へ拡大する。ダクト壁、上下の縁、ハブ、ブレード、固定支持部も同じ比率で変更する。
- 外翼の張り出しを抑えるが、折れ上がった先端形状とアンバーの識別線は残す。
- 後部は主翼の後縁から中央の扁平開口へ連続させる。大きな円筒エンジンを外付けしない。
- 直前に修正したノーズは維持する。
- 吸気口は前向き、排気口は後ろ向き。黒い板を貼るだけでなく、開口、内壁、奥行き、内部部材を持つ。
- 内部部材の奥にある面と、入口直後を塞ぐ不具合を区別する。V16の検査拡充で発見したカウル後端の排気口への干渉は、V17の基礎モデルを作る前に切除した。

## 参照資料と限界

翼と胴体が後方へ絞られ、排気部へつながる見え方は、[NAVAIR掲載のX-47B実機写真](https://www.navair.navy.mil/node/20006)を参照した。同ページの `UCAS_Arrest_14.jpg` はNorthrop Grumman提供写真として掲載されている。

実機の寸法をそのまま縮小したモデルではない。X-47Bの機構を双ファン機へ移植できることも意味しない。
Morrowgearの元コンセプトは単一の前方斜視画像であり、後部の正確な形状は確認できない。今回の後部、内部ダクト、隠れた下面は設計上の補完である。
CFD、実機の吸排気流量、重心、推力線、構造強度、ローター出力、騒音は未評価。

## 検証結果

`validation.json` の12項目はPASS。

1. 左右対称の頂点位置。最大誤差約0.00000107。
2. 座標値が有限であること。
3. ノーズの形状保持。検査点の変位0。
4. 頂点溶接後の胴体の閉鎖性。非多様体辺0。
5. 胴体体積が正であること。
6. 翼幅が8.90であること。
7. ファン径が指定の比率で拡大されていること。
8. 後部の新規部品がファン領域へ侵入しないこと。最小半径方向余裕約0.402。
9. 吸気口に奥行きが残ること。
10. 排気口に奥行きが残ること。
11. 検査光線上でダクトが外装に塞がれていないこと。
12. 両側の12枚ずつのファンブレードが維持されていること。

`output-checks.json` の5項目もPASS。全体9方向の画像について、余白を含めて機体が収まること、生成の新しさ、元モデルの保持、出力モデルの存在を確認した。
上面・底面は後端が切れないようカメラ範囲を修正済み。比較画像の前方・後方俯瞰はV16と同じカメラ・縮尺を使う。

自動検査PASSは「格好良さ」「元画像との完全一致」「飛行可能」の証明ではない。
形状の承認、表面の陰影・パネル境界の最終仕上げ、ゲーム用マテリアルへの変換、動作・着艦との照合は別の工程。
GLBの出力は存在確認までであり、Blenderの手続き型マテリアルとの表示一致は未保証。
