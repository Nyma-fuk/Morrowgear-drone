# 低い胴体と水平な外翼への再設計 V19

## 状態

2026-09-21。デザイン確認用の未承認3D試作。配布MOD・ゲーム資産・ワールドは変更していない。
正本は `airframe.blend`。PNGは同一モデルの実レンダリングで、生成画像による形状の補完や画像上の変形は行っていない。

## 変更理由

V18は胴体寄りの後端と翼端を延長した案だったが、断面の厚さと翼端の立ち上がりが残り、丸く重たい印象を強めていた。
最新の依頼は「流線形、速さ、高性能、先進性を前面に出す」「X-47Bの正面を見直す」こと。
元コンセプトの斜視画像から推定した翼端の立ち上がりより、この明示的な指示を優先する。

次の一次資料の実機写真を画面上で確認した。

- [米海軍・正面寄りの発艦準備写真 / DVIDS 931918](https://www.dvidshub.net/image/931918/x-47b-ucas)。中央の厚い胴体から低い翼へつながる構成を参照。写真の両端では翼端全体が切れているため、翼端の正確な角度の計測には使用しない。
- [Edwards AFB・初飛行写真 / 110204-F-1162D-019](https://www.edwards.af.mil/News/Photos/igphoto/2000287706/)。飛行状態の外翼が薄く伸びる見え方を補助参照。

写真には姿勢・遠近の影響がある。水平度や翼厚の実機設計値を読み取れたとは扱わない。
今回の寸法はMorrowgear向けの造形上の判断であり、実機性能を保証する数値ではない。

## 形状の方針

- 胴体の厚みをV18比66%に抑える。ローターのダクト・ブレード・支持部も同じ空間変換で高さを調整し、部品だけが外装から浮かないようにする。
- 外翼は局所断面の厚さを30%へ絞り、翼端4基準点の上面高さを0.04へそろえる。反り上がった翼端を装飾として残さない。
- 胴体から外翼への高さの移行は連続させる。中心線から片側ずつ別の編集はせず、Xの絶対値に基づいて対称に処理する。
- V18で延長した胴体側の後端・翼端・浅くした後縁の切れ込みは維持する。XY平面上の輪郭、翼幅、ローター中心と円形断面は変更しない。
- 凸状のメタル縁取りは外し、実際の外装面を輪郭にする。三角形ごとの色分けで生じていた粗い境界を統一材へ戻し、既存のパネル線と埋め込みセンサーを残す。
- 変形後の外装法線を再計算する。開口の角は分離し、面積と角度による重みづけで細長い三角形の影響を抑える。

## 主要寸法

座標は右が+X、前が-Y、上が+Z。すべて造形用相対単位。

| 項目 | V18 | V19 |
| --- | ---: | ---: |
| 翼幅 | 8.900 | 8.900 |
| 中央胴体の高さ、X絶対値0.58未満 | 1.120 | 0.739 |
| 翼端4基準点の最大上面高さ | 0.512 | 0.040 |
| XY座標の最大変位 | - | 0.000 |
| 公称ローター直径 | 2.040 | 2.040 |

高さの0.04は機体座標系の基準値であり、地面との距離ではない。
ランディングギアを展開した役割別機体の着艦余裕は、この基礎機体の形状承認後に別途照合する。

## 部品と状態

| 部品 | 今回の扱い | 状態・接続 |
| --- | --- | --- |
| 胴体・主翼・中央後端 | 薄型化、外翼の反りを除去 | 固定外装、左右対称 |
| 2基の浮上ファン | 平面寸法を維持、高さを外装と共通変換 | 各12枚の回転ブレード、静止したダクト・支持部 |
| 後部吸気口・排気口 | 低背化、開口と奥行きを維持 | 固定部品、黒い板で入口を塞がない |
| 前方バイザー・センサー | XY位置と埋め込み関係を維持 | 固定、シアンの発光面 |
| 翼端の識別線・パネル線 | 翼面の変更に追随 | 固定、機構を突出させない |
| 外周の重複する金属帯 | 削除 | 機能部品ではなく、旧装飾用の別メッシュ |

## 検証

`validation.json` の16項目、`output-checks.json` の6項目を実行する。
左右対称、有限座標、XY輪郭の保持、機能部品・12対のブレード保持、胴体の閉鎖性と正の体積、向きを反転しない変形、翼端基準点の低さと同一平面、中央の薄型化、吸排気口の非閉塞を確認する。
現出力では全項目PASS。左右の最大頂点位置誤差は約0.0000011。頂点溶接後の胴体非多様体辺は0。

前後・左右・上下・前方俯瞰・後方俯瞰・下面斜視の9方向を目視確認した。
比較PNGはV18と同一のカメラ・縮尺・照明条件。正面と側面は同じ固定範囲で切り出し、個別に拡大率を合わせ直していない。

検査のPASSは外観の承認や航空性能の証明ではない。機能部品の保持はゲーム内の回転・着艦動作の実証でもない。
前縁の局所的な陰影の細かなうねりは残っており、最終ゲーム用メッシュの面構成・法線仕上げは未完了。
CFD、揚力・推力・重心・構造強度、役割別装備の収納、ゲーム内LOD・描画負荷・アニメーションは未検証。
GLBは交換用の出力存在までを確認。Blenderの手続き型材質と別ビューアの表示一致は未保証。

## 再生成

V18の正本を入力に、Blenderバックグラウンド実行で `tools/drone-design/blender/build_low_profile_v19.py` を実行する。
`-- --preview` は正面・側面・前方俯瞰だけの確認用。正式な画像一式はオプションなしで生成する。
続けて `tools/review_low_profile_v19.py` を実行し、比較PNGと出力検査を更新する。

今後の判断ではV19を現在の提案とし、V18は延長処理の経緯を確認する比較元として保持する。
