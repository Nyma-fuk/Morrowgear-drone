# 母艦UI V24: REJECTED

2026-09-22。母艦モデル案とともに提示した母艦UIの2枚は、ユーザーにより明確に却下された。画像は判断履歴として元の内容のまま保存し、再生成・上書き・runtimeへの採用を行わない。

対象は`carrier-layout.png`と`carrier-compact-layout.png`。ユーザーの理由は「細かすぎ、どこで何ができるか直感的ではない。チャンクの指定方法不明、ワーディング謎の中国商品みたいで意味不明」。座標試験11件の成功は、この使いやすさ・見た目の却下を取り消さない。

小型機controller・Dock・HUDの提案は今回の却下対象ではなく、そのまま維持する。母艦の改訂は[carrier-v25](../carrier-v25/SPEC_JA.md)へ分離する。V24の母艦仕様も不採用履歴であり、新規実装の指示として扱わない。
