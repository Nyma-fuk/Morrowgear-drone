# Morrowgear Tactical Visor 近距離機体表示仕様

更新日: 2026-08-24  
状態: 承認用。実装前。

## 1. 目的

プレイヤーの周囲にいるドローンの方向、距離、高度、状態を、視界や照準を妨げずに把握できるようにする。全機へ名前とバーを表示する方式は採用しない。

機能名は仮に`Proximity Constellation`とする。

## 2. 表示範囲

- 標準検出距離: 48ブロック
- 設定: OFF / 24 / 48 / 96ブロック
- 固定対象、P0/P1対象、選択中WingのLeaderは距離上限外でも方向を表示できる
- 通常機の距離外表示は行わない

## 3. 位置別の表示

### 3.1 画面内かつ見通せる機体

- 機体の投影位置へ4～6pxのシンボルを表示
- 通常機はシアンの短い横線
- Wing Leaderは小さな菱形
- RTB、Recoveryはアンバー
- 交戦中は赤ではなく、赤橙の短い切れ込みを追加して通常警報と区別する
- 名前、HP、距離は標準状態では表示しない

視線を0.25秒合わせた場合だけ、短縮ID、役割、距離を1行表示する。固定するとInspection Contextへ詳細を展開する。

### 3.2 遮蔽物の向こう側

- 塗りつぶさない細い輪郭記号
- 不透明度35%
- 記号の下へ短い破線を1本追加
- 通常機は8ブロック以内の場合だけ表示
- 固定対象、P0/P1対象、選択中Wingは検出距離内で表示

これにより、壁越しに機体そのものが見えているようにはせず、データリンクによる推定位置であることを区別する。

### 3.3 画面外

- 画面端へ小さな方向シェブロンを表示
- 通常機は個別表示せず、近い角度の機体を`x6`のようにまとめる
- 上下方向はシェブロンの向きで示す
- 距離は固定対象または警報対象だけに表示する
- 通常時は最大4方向、Combat時は最大6方向

### 3.4 密集している機体

次の条件を満たす機体を1クラスタへまとめる。

- 画面上の角度差が4度以内
- ワールド距離が8ブロック以内
- 同じWingまたは同じ任務状態

クラスタはWing色の小さなシンボルと`x8`だけを表示する。Leaderだけ中央を菱形にする。クラスタへ視線を合わせた場合、個体配置を1.2秒だけ扇状に展開する。

クラスタ化開始は4度、解除は6度としてヒステリシスを設け、移動中に結合と分離を繰り返さないようにする。

## 4. 高度と移動方向

- プレイヤーより4ブロック以上高い: 上向きの小シェブロン
- 4ブロック以上低い: 下向きの小シェブロン
- 進行方向は1機ずつ矢印表示せず、選択中機またはLeaderだけ2～5pxの短いベクトルで示す
- 急旋回時もシンボル位置をクライアント側で補間し、画面上で跳ねないようにする

## 5. 中央視界の保護

- 照準中心から半径5%を`Reticle Safe Zone`とする
- 通常機のシンボルはSafe Zone内で不透明度20%へ下げる
- Focus、固定、P0/P1対象は消さないが、記号を外側へ最大12pxずらして細い誘導線で結ぶ
- 敵の照準、採掘ブロック、インタラクション対象を最優先し、ドローン記号を前面に出さない

## 6. サイズと占有率

1920x1080、GUIスケール標準時の初期値。

| 要素 | 初期値 | 上限 |
|---|---:|---:|
| Fleet Strip高さ | 24px | 画面高の2.8% |
| 左右パネル幅 | 300px | 画面幅の18% |
| 左右パネル高さ | 150px | 画面高の20% |
| 通常位置シンボル | 5px | 画面高の0.55% |
| Leader記号 | 8px | 画面高の0.8% |
| 画面外シェブロン | 10px | 画面高の1.0% |
| Action Rail | 28px | 画面高の3.4% |

通常時の不透明または半透明パネル総面積は画面の8%以下、Combat時でも14%以下とする。文字を読ませるために単純縮小するのではなく、表示量を減らして最小文字サイズを維持する。

## 7. 密度制御

- 通常の個体シンボル: 最大12
- 個体ラベル: 最大2
- Leader記号: 最大4
- 通常の画面外方向: 最大4
- 余剰機体: 角度とWingでクラスタ化
- P0対象は上限外。ただし同一方向の同種P0は集約する

表示対象の選択順は、固定対象、P0、選択中Wing、P1、視線対象、距離の近い通常機とする。

## 8. 表示の安定性

- 新規シンボル表示: 0.15秒フェード
- 消失: 0.35秒フェード
- 位置補間: 直近の速度を使い100～150ms先を予測
- 表示順の再評価: 0.5秒に1回
- クラスタ構成の再評価: 0.25秒に1回
- 短時間の遮蔽変化: 0.2秒未満なら表示形式を切り替えない

## 9. 設定

- 近距離機体表示 ON/OFF
- 表示距離 24 / 48 / 96
- 通常シンボル密度 低 / 標準 / 高
- 遮蔽機体表示 OFF / 固定対象のみ / 選択Wing / すべて
- 画面外方向表示 ON/OFF
- HUDスケール 70～120%
- 不透明度 40～100%
- 中央Safe Zone 4～10%

## 10. 必須試験

- 1、8、24、96、512機が48ブロック以内にいる状態
- 前後左右、真上、真下、画面外、遮蔽物の向こう、水中、地下
- 密集Wing同士が交差してもクラスタが点滅しないこと
- 照準中心をドローンが横切っても採掘・戦闘対象を隠さないこと
- GUIスケールと画面比率ごとのシンボルサイズ
- 低FPS、高速移動、テレポート、チャンク境界で位置が跳ねないこと
