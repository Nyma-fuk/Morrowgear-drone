## 造形の判断

参照画像 `../blended-wing-v5/family-equipment.png` を原寸で直接確認した。旧案の中央照射口、埋込推進部、深い機腹格納口は機能上の参考とし、今回の明示指示を最優先する。小型X47との共通点はV22/V23由来のグラファイト・銀色、控えめなシアンとアンバー、部品境界にとどめ、外周輪郭は分離する。

高さ12は中央船体の量感が控えめ、高さ16は上部の比重が強すぎると判断し、**48幅×32長さ×14高さ**を選択した。比較画像は初期の大形状検討であり、艦首くさび・切欠・整備細部の追加前の段階を保存している。14の選択は制作者の判断で、ユーザー承認を意味しない。

V24からの変更点：

1. 薄い全翼を廃し、幅25の荷重支持船体と厚い左右肩装甲を主構造にした。
2. 平たい前縁を中央へ絞った艦首に置き換え、傾斜した装甲くさびと左右の面切替を追加した。
3. 外周に前後の切欠を設け、肩上面の排熱井、側面排熱口、大型の縦補強枠を配置した。
4. 上部は有人艦橋ではなく、低い無人センサー部と機関甲板・熱交換器に分けた。
5. 肩部の整備ハッチ、実形状の留具、パネル目地、機腹の連続補強桁で構造の階層を付けた。
6. 4格納口を実際に深く掘り込み、内壁・縦枠・梁・受入接点・天井灯を設けた。

## 構成と寸法

| 部品 | 形状と用途 | 状態 | 対称性 |
| --- | --- | --- | --- |
| 中央船体 | 断面から構成した面取り船体、艦首くさび、下部桁 | 固定 | 編集用片側と共通X=0 Mirror |
| 肩装甲 | 厚い多角形外周、切欠、整備ハッチ、排熱井 | 固定 | 左右同形 |
| 推進部 | 肩内部の深いダクト、12枚羽根のファン | 造形確認用の静止状態 | 2基、計24枚 |
| 上部構造 | 無人センサー、機関甲板、熱交換器 | 固定 | 低い中央部と左右放熱部 |
| 格納口 | 前方4.6×5.8、後方4.2×4.6、独立した深い凹部 | frame 1閉鎖、40/80開放 | 前後各1組、合計4口 |
| シャッター | 開口を塞ぐ装甲板、上方の格納位置 | 終端状態の提案のみ | 左右連動 |
| 中央照射口 | 装甲ドラム、埋込レンズ、同心リング | 固定 | 機腹中央 |
| 格納見本 | V22 Field frame 40、格納脚を含む原寸モデル | 4機を受入点に配置 | 各列で左右対称 |

1 unit = 1ブロック。Blenderは前方-Y、上方+Z、右舷+X。原点は機腹最下面の水平中央。幅を1とした比率は1 : 0.667 : 0.292。母艦自体には着陸脚を追加していない。

小型機比較は母艦幅48に対してX47幅3の**16:1**。格納見本4機のほか、比較画像だけに同じ原寸形状を船体前方へ1機配置した。この外部見本は正本・GLB・外形検査には含めない。

## 検証の範囲

[validation.json](validation.json) は左右対称、48×32×14外形、4機の収まり、各格納口169本・計676本の上向きレイによる機体・固定具・開放シャッターの遮蔽を確認する。[export-roundtrip.json](export-roundtrip.json) はGLBの部品別外形とマーカー、[render-checks.json](render-checks.json) は10描画の非空白・端切れ、[state-envelope.json](state-envelope.json) は80フレームの外形を記録する。

連続した機構干渉、シャッターが実機として動作すること、任意姿勢の進入、飛行・衝突物理、実ゲーム性能は証明しない。シャッターの閉鎖・開放は外観の終端状態であり、途中の持ち上げ軌道は実用機構として未検証。静止GLBにゲーム用アニメーションは含めない。

[model-budget.json](model-budget.json) の容量は高詳細な設計用正本の値であり、ゲーム向け予算の承認ではない。承認後は4機の見本を別インスタンスに分離し、母艦LOD、材質、描画回数を整理する。ゲーム導入・Launcher起動・インストール・commitは行わない。
