# Morrowgear Tactical Visor 適応表示・3D追従実装仕様

更新日: 2026-08-24  
状態: 実装済み

## 1. 目的

バイザーは全テレメトリを常時表示する画面ではない。プレイヤーが現在判断すべき情報だけを、空間位置と運用上の影響範囲を保ったまま提示する。

## 2. 3D位置追従

- 機体の描画補間済み3D座標をアンカーとする。
- Minecraft本体のカメラ位置、姿勢、FOV、アスペクト比を含むView/Projection行列を使用する。
- 画面座標を後追い補間しない。視点移動時は機体モデルとマーカーを同じフレームで動かす。
- Leaderまたは固定機だけ、3D速度ベクトルを再投影した短い進行方向線を表示する。
- 距離に応じてマーカーを3段階で縮小する。
- 遮蔽はプレイヤー視点ではなく実カメラ位置から機体アンカーまでRaycastして判定する。
- 遮蔽中は中抜き記号と破線へ切り替える。壁越しに機体そのものが見える表現にはしない。

専用シェーダーは位置追従には使用しない。シェーダーの採用範囲は、将来の走査波、発光残像、輪郭発光など、ワールド空間に存在する演出に限定する。HUDアンカーはMinecraft本体のカメラ行列を正とする。

## 3. 情報の優先順位

1. 固定中の対象
2. プレイヤーまたは任務継続に関わるP0
3. 戦闘、Recovery、RTB、飛行/兵装電力不足のP1
4. 選択中WingのLeaderと例外機
5. 注視が安定した対象
6. 距離の近い正常機

正常機は表示予算を超えたら集約する。P0/P1は通常予算から除外し、同一方向・同一Wing・同一状態をクラスタとして表示する。

## 4. 自動集約

| 所有機数 | 標準粒度 | 中央表示 |
|---:|---|---|
| 1～8 | Unit | 全機を表示可能 |
| 9～32 | Wing | Leader、例外機、固定機 |
| 33～128 | Operation | 各Wing代表、例外クラスタ |
| 129以上 | Fleet | 選択文脈、異常クラスタ、P0 |

狭い画面ではマーカー8件、ラベル1件、警報1行へ収縮する。通常画面では状況に応じて最大14マーカー、2～3ラベル、3警報行まで展開する。複数Wingの交戦は`Wing数 / Unit数 / Target数`へ集約する。

## 5. 固定領域

### Fleet Strip

所有機数、稼働、Dock、RTB、Operation数、Recovery、Alert数、最大脅威度、現在の集約粒度を表示する。個体名は出さない。

### Command Context

ユーザーが選択したWingを維持する。戦闘やRTBで一時離脱した機体は`DETACHED`として集計し、パネル対象を自動変更しない。

### Inspection Context

固定機または注視が安定した機体がある時だけ開く。飛行電力、兵装電力、機体強度を共通表示し、追加行は状態で変える。

- 戦闘: 兵装、Combat State、Heat
- Field: 作業種別、進捗
- Cargo: Cargo State
- Engineer: Engineer State
- Security: Security State
- 通常飛行: Operational State

### Spatial Overlay

正しい3D投影位置へ記号を置く。画面外は8方向のセクターへ集約し、交戦・異常セクターを優先する。

### Action Rail

同種の状態を高速で切り替えず、最大3行へ集約する。現在は脅威、飛行電力、Recovery、戦闘中の兵装電力を対象とする。

### Engagement Overlay

複数地点の戦闘は敵ごとに独立した`ENG-01`～`ENG-06`として扱う。敵の3D位置へ赤いブラケットを置き、参加機から細い破線のデータリンクを引く。

- 1～2機: 参加機の短縮IDを表示
- 同一Wingの3機以上: `WING-ID x機数`を表示
- 複数Wing: `Wing数 / Unit数`を表示
- 共通表示: 敵名と残存HP
- 画面外: 交戦ラベル付き方向表示
- 遮蔽中: 推定位置として低不透明度表示

Fleet粒度では同時4交戦、その他は同時6交戦を空間表示する。上限を超えた交戦もFleet StripとAction Railの交戦数・対象数には残す。

## 6. 拡張規則

新しい機体、兵装、任務状態を追加する場合は、次の順に登録する。

1. P0～P3の重要度を定義する。
2. 個体表示が必要か、Wing/Operation集約で十分かを定義する。
3. Command、Inspection、Spatial、Actionのうち表示責任を持つ領域を1つ決める。
4. 最低表示時間と解除ヒステリシスを定義する。
5. 1、8、32、96、129、512機で表示予算を試験する。

同じ値を複数領域へ常時重複表示しない。
