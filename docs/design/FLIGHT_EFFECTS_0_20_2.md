# 0.20.2 音・粘着ミサイル・協調旋回

更新日: 2026-09-21。0.20.1の飛行音を基に、ノイズを減らして機械の周期音を明確にする。
音量を上げることと高出力感の改善を区別する。全機の任務・Wing・経路探索の意味は変更しない。

## 音の変更

- 飛行: ローターの周期成分、固定音程のタービン、控えめな排気を重ねる。広帯域ノイズと歪みを削減。
- 充填: 低音から滑らかに上昇。持続照射と別の音源とし、充填終了後に上下する音程を持ち込まない。
- 照射: 低域の電力負荷に720/1440/2160 Hzの固定倍音を重ねる。帯域ノイズを抑えて連続したエネルギー音にする。
- 冷却: 排気ノイズを減らし、ポンプ音を残す。カートリッジ音は復活させない。
- ミサイル: 発射音の立ち上がりを短くし、ジェットの尾音を抑えて連射を聞き分けやすくする。
- 音源は48 kHz・mono。距離減衰、同時発音制限、着艦時停止は維持。機関砲とレーザーヒットの旧音源は変更対象外。

## ミサイル

| 項目 | 仕様 |
|---|---|
| バースト | 3〜5発、残弾数が上限 |
| 発射間隔 | 2 tick、通常20 TPSで0.10秒 |
| 着弾後 | 各弾に独立した12 tick、通常0.60秒の信管 |
| 飛翔表示 | 小型の赤い本体、赤い発光核、短い推進尾光 |
| 着弾表示 | 本体と点滅を残し、推進尾光を停止 |
| 点滅 | 約6.4 tick周期。周辺を赤く照らす色付きブロック光ではなく、局所的な発光描画 |
| 敵への命中 | 敵の位置・ヨーに対する局所座標で付着し、移動・回転に追従 |
| ブロックへの命中 | 命中地点で固定 |
| 敵消失・死亡 | 最後の位置で信管を継続 |
| 敵の瞬間移動 | 1更新で8ブロックを超える追従はせず、その位置に残る |
| 保存 | 対象UUIDと局所座標を保存。セッション固有のEntity IDは永続化しない |

着弾時刻が異なれば信管満了順に爆発する。同じtickに満了した弾を見た目だけのために遅延させない。
クライアントは敵の補間済み座標を使い、付着中の弾だけが更新間隔で引きずられないようにする。
弱い終端誘導、爆発威力、味方保護、ブロック保護、未読込チャンクを強制ロードしない制約は維持。

## 旋回

通常飛行では速度と最大バンク約37度から要求速度の方向変更量を制限する。
ゲーム用の横加速度基準0.10を用い、ヨー上限と横加速度上限の小さい方を適用する。
実航空機の認証済み空力モデルではなく、表示姿勢と軌道の不自然な乖離を減らす近似である。

旋回制限は加速度・加加速度の平滑化より前に適用する。後段に適用すると速度が急変し、
既存の滑らかさの試験を破壊するため、この順序を回帰試験で固定した。
低速ホバリング・制動は可能。衝突回避等の既存の緊急制御は優先し、旋回半径のために衝突させない。

## 検証

| 層 | 結果・限界 |
|---|---|
| Java | 1,885件PASS、ビルド成功 |
| 音源 | 5件PASS。デコード、ピーク/RMS、高域、ループ境界、再現性等。聴感の合格判定ではない |
| 新規回帰 | 付着座標の往復変換・回転・瞬間移動抑止、UUID保存/不正入力、独立信管、速度別旋回上限、低速制動 |
| 実ゲーム・通常速度ミサイル | 2回、各8発の発射・着弾を観測。各弾の着弾から消失まで12 tick。対象のダメージと通常帰還、Dock接触1/1を確認 |
| 実ゲーム・6機ルート | 4点周回、2機途中参加、Salvage離脱→着艦→再合流、上昇下降。経由点更新10/10/10/10/10/8回、最後にDock接触6/6 |
| ルート運動ログ | 2,398 tick、記録欠落0。最大1 tick速度差0.0764、最大移動0.8970 block。テレポート不使用 |

消失ログだけでは爆発を断定しない。爆発の視覚、ダメージ、信管ロジック試験を別の証拠として扱う。
定点の標的に対するゲーム内試験と、移動・回転追従の数値試験を混同しない。
最終的な音質・快適さはユーザーの通常音量での試聴を必要とする。
