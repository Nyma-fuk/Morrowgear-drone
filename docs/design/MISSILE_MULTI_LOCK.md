# ミサイルのマルチロック

## 要求と境界

1回の攻撃で複数の敵をロックし、敵の脅威度と優先度に応じて対象と射撃数を決める。最大5発は対象ごとの上限ではなく、1機の1回の攻撃における合計上限とする。残弾と武器電力が少なければ、それ以下になる。

ロック確定後に高優先度の敵が現れても、その攻撃回の対象と射撃数を変更しない。次回のロックで最新の敵情報を評価する。これは新しい敵を永続的に予約するという意味ではなく、次回にも生存・敵性・射撃可能性を確認する。

既存の敵性判定とデータリンク情報を使用し、ロック機能のために索敵範囲や攻撃許可を無条件に拡大しない。ミサイルの威力、搭載上限、補給品、発射間隔、誘導や着弾演出は今回の変更対象外。

## 配分規則

同じUUIDの通報は最も優先度の高いものにまとめる。優先順は、プレイヤー保護の通報、プレイヤーへの危険度、通報スコア、敵そのものの脅威度、機体からの近さ、同点時のUUIDとする。危険度・スコア・脅威度は0〜100へ正規化する。

予算は`min(5, 残弾, 武器電力 / 15)`。予算内の上位対象に1発ずつ割り当てた後、残予算を優先順に追加する。対象ごとの希望弾数は`min(5, 1 + floor(max(敵脅威度, プレイヤー危険度) / 25))`。低脅威の単体に無条件で5発撃つ仕様ではない。

- 脅威0〜24の単体: 1発。
- 脅威50〜74の単体: 3発。
- 脅威100の単体: 最大5発。
- 脅威100の敵と低脅威の敵1体: 予算5なら4発と1発。
- 候補5体以上: 上位5体へ1発ずつ。高脅威の敵がいても合計5発を超えない。

発射順は選択対象の1発目を優先順に発射し、その後に固定した追加分を順番に発射する。弾数は理論ダメージによる撃破保証ではなく、調整可能な脅威ベースの配分である。

## 中断と無効化

- ロック済みの対象が死亡・消失・友好化した場合、その対象への未発射分を中止する。同じ攻撃回で別の敵へ振り替えない。
- 射撃できない対象があっても残りの対象を処理し、発射待ちで永続停止しない。
- 明示的な帰還・任務変更・武器電力不足・飛行不能は安全上の中断として扱う。ロック固定を理由に強制発射しない。
- 発射済みミサイルの目標は、発射前のロック更新と分離する。

## 検証する条件

| 条件 | 必要な結果 |
| --- | --- |
| 敵1体、敵2〜5体、敵6体以上 | 合計最大5発。複数対象への配分が可能 |
| 同じ敵を複数の機体が通報 | 同一UUIDを重複候補として水増ししない |
| 脅威・優先度が異なる | 定義した優先順と射数配分になる |
| 同点、入力順の入れ替え | 結果が不必要に揺れない |
| 確定後に高優先対象を追加 | 現在のロックは不変。次回は新情報を評価 |
| 残弾0〜5、武器電力不足 | 保有量を超えず、失敗した生成で消費しない |
| 先頭の対象が死亡、別の対象が存命 | 生存する残りのロックを処理 |
| 全対象死亡・消失 | 発射せず攻撃回を終了し、次の判断へ移行 |
| 敵が友好化、範囲外、遮蔽あり | 安全条件を満たさない発射をしない |
| 生成失敗、全対象スキップ | 永久待機や無限の攻撃回再生成をしない |
| 新しい迎撃割当、元対象の割当解除 | 確定した攻撃回を不用意に書き換えない |
| 帰還・任務変更・電力喪失 | 確定済みの未発射分を安全に中止 |
| 保存・再読込 | 古い一時ロックから重複射撃しない |
| 機銃・レーザー、Wing、補給 | 既存の動作契約を維持 |

実装・自動試験・実ゲーム確認の結果は区別して記録する。現時点で、この表そのものを実施済み試験結果として扱わない。

## 接続と実行結果（2026-09-22）

`MissileLockPolicy`が変更不能な発射予定と進捗を保持し、`DroneEntity.tickMissileAttack`から実際の`MorrowgearMissileEntity.launch`へ予定UUIDを渡す。候補は同じ所有者・ディメンションの既存通報から最大128件と現在の主対象。通報の既存有効期間は60tick。生存、敵性、射程、発射高度条件、遮蔽を再確認する。

ロック確定はハッチ待ちと射撃条件を満たした時点。照準候補を探して接近しているだけの段階とは区別する。攻撃回の機体の位置取り基準を保持し、発射先ごとに`COMBAT_TARGET`を切り替えない。これにより既存の空域割当と主対象単位の集計を不用意に動かさない。HUDは依然として代表対象表示であり、複数ロックの一覧表示は今回追加していない。

ロック前の進入は最大240tickで打ち切り、離脱後に次回の優先度を評価する。制限時間直前にロックが確定した場合、残りの最大5発の処理にはこの接近期限を適用しない。ロック対象の無効化は当該UUIDの未発射枠を取り消す。ミサイル生成失敗はその発射機会を終了し、弾薬・電力は消費しない。保存・再読込では未発射ロックを中止し、新しい通報で途中の発射予定を再生成しない。残弾を復元する処理も追加しない。

- 通常の全体ビルド成功。133スイート、2,137テスト、失敗0・エラー0・スキップ0。
