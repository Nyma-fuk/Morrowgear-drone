- 導入先: `%APPDATA%/.minecraft/morrowgear/mods/morrowgear-drone-latest.jar`。
- 両ファイルのSHA-256: `42A5B0D685A2A58C37207B9B7A5BBF306C856B139730FE1BEE7991D2E5745542`。
- 最終再起動後のログで `morrowgear_drone 0.20.0` を確認。確認区間でERROR・例外ログなし。

## 実画面で発見して修正した問題

1. コントローラーのLCDが黒い面で覆われた。メッシュ簡略化で一部頂点が元の部品範囲外へ飛び出していたため、元の境界を超える簡略化結果を棄却する。LCDは色一色の発光と区別して、テクスチャを保った全輝度描画にした。
2. 手持ちコントローラーが大きすぎた。保持寸法・傾きを調整し、LCD側が見えて画面を過度に覆わないことを確認した。
3. GUIの分数倍率で文字の画素列が欠けた。文字描画を物理ピクセルの整数倍率へ合わせ、実画面の読取りを確認した。
4. 複数選択時の役割名、通信状態、モジュール欄が単機用の表記になった。実際の選択集合から集計し、複数値として表示する。
5. 地図操作の案内が機器一覧にも重なった。地図用表示と一時通知の表示条件を分離した。
6. 新Dockの翻訳キーがそのまま表示された。日本語・英語の名称を追加した。
7. NEW WINGはドロップ専用で、クリックが無反応だった。選択1～8機からの作成を追加し、従来D&Dも残した。

## 未確認事項・実装境界

- 新資産による100機以上の描画性能、他Mod・シェーダーパック・専用サーバー・全解像度の組合せは今回未計測。
- 戦闘、採掘、伐採、サルベージ牽引、浮遊充電の全状態と、拡大した機体の狭所通過を実ゲームで網羅再試験していない。既存自動回帰試験の合格と分けて扱う。
- 通常Dock破壊は空Dock・クリエイティブで確認した。満載Dock、サバイバルのドロップ数、全25位置からの破壊を実操作で網羅した結果ではない。
- 材質色のベイクはBlenderの金属反射・粗さ・照明を完全に再現するものではない。元画像との画素完全一致・全三角形の自己交差検証でもない。
- 機体には飛行/着艦/作業の姿勢があるが、脚や作業装備の全遷移を時間軸で滑らかに補間する作りではない。兵器ごとの装備開閉・発射口位置の精密な再調整は残る。
- バイザーの新モデルは手持ち用。プレイヤー頭部への新しい立体装着描画は今回含めない。
- 95記号は同梱したが、既存HUDの全描画箇所を新記号へ置換してはいない。HUDは共通配色の適用を中心とした変更。
- ブラウザー試作の全ダイアログ、ACK管理、ルート点の並替え・数値編集、詳細なHUD設定を、そのままJava画面へ移植したわけではない。
- 役割絞込・4種の並替え・ページ操作のすべての組合せ、満員Wingへの連続D&D、全任務に対する指示権限を今回の実操作で網羅していない。

上記を未確認のまま「デザイン全体がゲームでも完全実装・全試験PASS」と表現しない。次の品質確認は、機体寸法変更の影響が大きい狭所航行・作業装備と大規模描画を優先する。
