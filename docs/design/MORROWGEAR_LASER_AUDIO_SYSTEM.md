# Morrowgear 高出力レーザー音響設計

## 目的

レーザー音を単純な電子音として作らず、機体内部で実際に起きている機械・電気・熱の変化から再構成する。プレイヤーには、充填、照射、停止、排熱が一続きの兵器動作として聞こえることを目標とする。

## 想定する兵器構造

Morrowgearのレーザー機は、次の機構を持つ高出力固体レーザーとして扱う。

| 機構 | 役割 | 主な音 |
|---|---|---|
| 主接触器 | 武器電池とDCリンクを接続する | 低い打撃音と短い金属クリック |
| コンデンサ群 | 照射用の瞬間電力を蓄える | 46～94 Hzを中心とした重い脈動 |
| インバータ | 電力をレーザー励起系へ供給する | 210～650 Hzの粗いスイッチング振動 |
| 冷却ポンプ | 発振器と光学ベンチを冷却する | 低い回転音と液体の乱流音 |
| 発振器・光学系 | 高出力光線を形成・指向する | 高周波共鳴と微細な機械変調 |
| 熱交換カートリッジ | 照射中のピーク熱を相変化材へ退避する | 排出時の金属共鳴 |
| パージバルブ | 照射後に冷媒を再循環させる | 遅れて始まる圧縮ガス状の冷却音 |

熱交換カートリッジは弾薬ではない。照射で蓄積した熱を受け持つ交換式ヒートシンクであり、使用後に排出することで次の照射サイクルへ移れる。この定義により、レーザー兵器でも排莢に似た演出を機能上の必然として扱える。

## 動作と音の時系列

### 1. 充填

1. 主接触器が閉じ、機体に短い低音と金属クリックが発生する。
2. コンデンサ電圧の上昇に伴い、46～94 Hzを中心とした低域脈動の密度が増す。
3. インバータの粗い振動が210 Hz付近から650 Hz付近へ上がる。
4. 冷却ポンプと冷媒乱流が加わり、純粋なサイン波ではない重い充填音になる。
5. 最後の約0.7秒だけ光学ロック音が920 Hzから約2.2 kHzへ締まり、照射へ遷移する。

聴感上は、低い「ドゥゥ」から内部機構の密度が増し、最後だけ高域へ締まる「ズゥゥゥン」を狙う。上昇音を主役にすると古典的なゲーム効果音になるため、低域の電力振動と冷媒ノイズを最後まで残す。

### 2. 照射

レーザー光自体は音源ではない。機体側ではインバータ、発振器、冷却系が連続負荷を受け、大気側では光路と着弾点周辺の急激な加熱が音を生む。

- 持続音の中心は1.4 kHz付近とし、1.9 kHz、2.4 kHz付近に非整数倍の成分を重ねる。
- 低域には96 Hz、192 Hz、640 Hzの電力系振動を残す。
- 空気振動は520 Hz～4.2 kHzの広帯域成分とし、細い高音へ集中させない。
- 3.3 kHz付近の高域は照射開始直後だけ鳴り、約0.3秒以内に減衰する。
- 照射中の各周波数は固定し、周期的な音程変化を入れない。質感の変化は広帯域の空気振動だけで表現する。

聴感上は「キィン」という識別性を残しつつ、長時間聞いても耳へ刺さらない中域主体の音とする。高出力感は高音量ではなく、低域の電力負荷と広帯域の空気振動で表現する。

### 3. 停止・カートリッジ排出・冷却

1. 照射停止と同時に主回路を遮断する。
2. 75 ms後に熱交換カートリッジのラッチを解除する。
3. 1.7～6.2 kHzの複数の金属共鳴で「カキィン」を形成する。
4. 230 ms後にパージバルブを開く。
5. 高域の冷媒噴流と低域の圧力音を重ね、約2.4秒かけて減衰させる。
6. 冷却ポンプの回転数を下げ、次の充填または通常飛行へ戻る。

カートリッジ音と冷却音を同時に開始しない。金属排出を認識できる短い間を置いてから「シュゥゥゥ」を開始する。

## ゲーム内での対応

| 戦闘状態 | 音源 | 再生方法 |
|---|---|---|
| `LASER_CHARGE`へ遷移 | `laser_charge.ogg` | 各機体の座標から1回再生。36ブロックで減衰し、同時機数に応じて音量を正規化 |
| `LASER_FIRE`へ遷移 | `laser_fire.ogg` | 各機体で開始し、30 tickごとに継続。48ブロックで減衰し、同時機数に応じて音量を正規化 |
| `LASER_FIRE`から離脱 | `laser_shutdown.ogg` | 排出と冷却を一つの時系列として1回再生。40ブロックで減衰 |
| 有効打撃 | `laser_hit.ogg` | 同一目標の代表機のみ再生。40ブロックで減衰 |

## 調整原則

- 複数機では音程をわずかにずらすが、和音のように広げすぎない。
- 照射音は着弾音より前面に置く。
- 3～6 kHzの細い持続成分を避け、照射が長引いても聴覚疲労を起こしにくくする。
- 持続照射へ周期的な周波数変調や機体ごとのピッチ差を加えない。
- 充填音の上昇だけを強調せず、低域の電力負荷を維持する。
- 冷却音は次の戦闘判断を邪魔しない長さと音量に抑える。
- 既存兵器の録音は使用せず、全要素を合成する。

`tools/audio/generate_laser_sounds.py`を使用する。必要なPythonパッケージは`numpy`、`scipy`、`soundfile`である。生成結果は`src/main/resources/assets/morrowgear_drone/sounds`へ直接保存される。
