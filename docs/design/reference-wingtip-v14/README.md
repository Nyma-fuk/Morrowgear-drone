# 翼端・後部形状の全方向レビュー V14

## 位置付け

承認された斜め前方の画像と V13 の実モデルを比較し、主翼先端と後部の相違を修正した候補。
**未承認の比較用モデルであり、ゲーム内のモデルは変更していない。**
同一の Blender メッシュから上面・底面・正面・後方・左右側面・前方俯瞰・後方俯瞰・下面斜視を描画した。
画像生成で別々の向きの絵を作ったものではない。

元画像は単一の斜視画像である。底面や隠れた後端が元画像と一致するとは判定できない。
左右の対応点にも解釈の余地があるため、可視部分の再現と、不可視部分の推定設計を分ける。

## 見つかった相違と対応

| 部位 | V13の相違 | V14の対応 | 判定上の限界 |
| --- | --- | --- | --- |
| 主翼先端 | 幅広い面が三角のフィンに見える。内部の対角線が強い折れとして出る | 左右共通の四隅から幅広い面を再構築。不要な対角の折れを除去 | 元画像上の四隅の対応は仮説。実物の翼端角度を取得したわけではない |
| 翼端の色ライン | 外周の高い辺に沿っている | 元画像で見える前方側の辺へ移動 | 元画像の擦れ・塗装幅までは一致していない |
| 翼端の縁 | 面への食い込みや幅の不足がある | 輪郭の内側方向に沿う帯へ変更 | 光源条件が異なるため反射の明暗は別評価 |
| 尾翼に見える後部左右の突起 | 薄い板状で、厚みと前側の暗い開口が不足 | 低い立体カバー、前面の暗い開口、側部の接続面を追加 | 元画像だけでは機能を断定できず、名称は「後部カバー」とする |
| 後部の胴体 | 断面を薄くした結果、後部カバーが独立した板に見える | カバー下の後部形状を延長し、胴体側の接続を作る | 見えない後端の閉じ方は推定 |
| 前縁の面分割 | 輪郭変更後、旧断面の境界が残り、細かい凹凸が出る | 新輪郭から断面を再計算。誤差の大きい面だけ追加分割 | 高密度の検討用メッシュ。ゲーム向け最適化とは別 |

## 方向別の確認

| 方向 | 確認した内容 | 元画像との比較可否 |
| --- | --- | --- |
| 前方俯瞰 | 翼端の面積、縁、色ライン、後部カバーの厚みと配置 | 固定した比較カメラで直接比較 |
| 上面 | 後退形状、左右の切り欠き、翼端の前後幅、後部の左右配置 | 元画像から解釈した構造の確認。正解の上面図は存在しない |
| 底面 | 翼端の下面厚み、ダクト開口、胴体との接続、下面の整備面 | 不可視面の推定設計を確認 |
| 正面・後方 | 高さの左右対称、翼端の厚み、後部の接続 | 対称性・接続の確認。正解の正投影図ではない |
| 左右側面 | 翼端が薄いフィンや浮いた板になっていないか、後部の段差 | 左右共通形状を確認。光源による明暗は左右で異なる |
| 後方俯瞰・下面斜視 | 一方向だけでは隠れる接続、カバー後端、ローター下面 | 推定部分の整合性確認 |
| 無彩色 | 材質で隠れた折れ、厚み、面の乱れ | 形状確認用。元画像の材質を比較する画像ではない |

## 形状・部品の定義

座標系は `+X = 右、-Y = 前、+Z = 上`。単位は造形用であり、実機のメートル寸法ではない。
全幅は約 `9.673`、前後長は `5.04`。翼端の右半分の制御点を左へ鏡映する。
正確な断面・輪郭パラメーターは [design-parameters.json](design-parameters.json) を参照。

| 部品 | 状態 | 接続・役割 | 対称性 |
| --- | --- | --- | --- |
| 主翼・翼端面 | 固定 | 本体メッシュの連続した面。上下面を持つ | X=0面で鏡映 |
| 翼端の縁・色ライン | 固定、非発光 | 外板上の縁と識別塗装。推進器ではない | 共通形状を鏡映 |
| 後部カバー | 固定 | 胴体上の低い張り出し。前側に暗い開口、側部に接続面 | 共通形状を鏡映 |
| 後端の整備口 | 固定 | 後端面に追従して配置。機能の追加実装はしていない | 共通形状を鏡映 |
| ダクト・ローター | 既存の検討モデルを継承 | 今回は回転や飛行挙動を変更しない | 左右共通 |

後部カバーを可動尾翼として扱ったり、この造形だけで操舵能力が成立すると主張したりしない。
航空力学の未検証事項は [V13のレビュー](../reference-airframe-v13/README.md) を引き継ぐ。

## 比較の方法と根拠

1. 元画像と旧モデルの翼端左右・後部を同じ画像座標で拡大した。
2. 外形の端、縁の内側、面の折れ目を区別して見直した。
3. 可視コーナーの左右対応を仮置きし、既存の比較カメラを固定したまま、共通の3D座標を求めた。
4. 独立して左と右を変形させず、左右対称の面として構成した。
5. 同一モデルを全方向から描画し、接続・厚み・対角の折れ・面分割を確認した。
6. 元画像・V13・V14の拡大比較と、外形マスクの比較を保存した。

元画像上のコーナー仮置きは次のとおり。原点は画像の左上、単位はpx。
縁のどちら側を採るかで数px以上変わるため、実測された3D寸法や確定した正解ではない。

| 対応点 | 画像左側 | 画像右側 |
| --- | --- | --- |
| 外周前側 | (43,142) | (1630,520) |
| 外周後側 | (211,62) | (1577,402) |
| 根元前側 | (65,211) | (1455,553) |
| 根元後側 | (180,119) | (1510,441) |

全体および各切り出し範囲の輪郭比較は [comparison.json](comparison.json) に保存。
このIoUは「画像上で輪郭領域がどれだけ重なるか」であり、「デザインの再現率」ではない。
材質、内部の輪郭、陰影、面の向き、機構まで同じと保証する数値ではない。
`sourceAnnotationReviewed=false` は、この比較用マスク・対応点の正しさがユーザー確認済みではないことを表す。

## 自動検査

[geometry-tests.json](geometry-tests.json) と [mechanics.json](mechanics.json) に結果を保存する。
検査対象は左右対称、有限座標と正の厚み、翼端根元の連続性、本体の閉じたメッシュ、曲面分割誤差、
固定比較カメラ、全方向PNGと書き出しの更新、輪郭比較の回帰である。
**PASSは外観の承認、実機飛行、ゲーム内動作を意味しない。**

分割誤差は、曲面上の三角形の重心と定義した曲面とのZ差を確認する。
閾値 `0.02` は比較カメラで数px相当の造形用許容差であり、物理的な製造公差ではない。
閾値を超えた際は基準を緩めず、面の追加分割と輪郭・断面の不整合を修正した。

## 残っている差

- 胴体肩の面構成、パネルの分割密度、金属の質感と明暗はまだ元画像と異なる。
- 右翼端は元画像の縁と折れ目に残差がある。左右別々の形にして一致させることはしていない。
- 後部カバーは厚み・位置を改善したが、周囲の外板との馴染みや細かな段差はなお調整対象。
- 元画像にない底面・後方・内部構造は復元ではなく推定。
- 高密度の検討用モデルであり、ゲーム用LOD・描画負荷・可動部との整合は未検証。
- GLBを書き出したが、Blenderの手続き型材質との完全な見た目の一致は未検証。
