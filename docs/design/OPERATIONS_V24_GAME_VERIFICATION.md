# 作戦通信・補給網・母艦の実ゲーム確認

## 現在の位置づけ

2026-09-22。この文書は実行手順であり、実ゲーム試験の合格記録ではない。今回の作業ではMinecraftの起動、操作、ランチャーへの差し替えを行っていない。音声・画面・モデルの提案承認とクライアント接続を終えた後、以下を実施する。

自動試験の件数はJUnitのテストメソッド数であり、全プレイ操作の網羅率ではない。ソース上の接続検査、計算規則の単体試験、実際のItemStackの移動、ゲーム中の確認を区別する。

## 実施前の条件

1. 既存ワールドを複製し、バックアップ元では破壊試験を行わない。プレイヤー、設置Dock、機体UUID、Wing、元任務、コンテナ内容を記録する。
2. 承認済みモデル・アイコン・画面・音声だけを組み込む。通常のビルドでは検証完了を確認してから差し替える。作業途中は `-x syncLauncherMod` を付ける。
3. 起動許可を得てからゲームを起動し、ログのModバージョンと導入JARのハッシュを照合する。古いバージョンなら操作試験を始めない。
4. 既存の試験機とDockを使う。母艦の新規生成は試験用コピーに1隻から始め、別室分離の試験だけ2隻にする。無関係な機体や敵を増やさない。
5. ブロック破壊を伴う母艦試験は、地上から岩盤までの対象1チャンクを明示する。倉庫、Dock、建築、第三者の領域を含めない。

## 開発用Dock検査の位置づけ

`/morrowgear_dock_verify <x> <y> <z>` はクリエイティブの権限保有者が、近くの既存所有Dockに対して明示実行する。実際のメニュー入力を通し、独立したfinally復元の後に持ち物・装備・クラフト枠・カーソル・Dock保存情報を照合する。別画面の操作中、他者がDockを開いている場合は拒否する。

この検査は描画、文字の読みやすさ、D&D中の見え方、実際のクリック感を検証しない。U01～U03および通常のD01/D05を省略する根拠にはしない。

## 保存する証拠

各ケースに実施バージョン、ワールド、操作、実測値、合否、失敗時のログと画像を残す。音声は実際の聴取結果、飛行は動画または連続フレームで確認する。未実施は「未実施」とし、自動試験のPASSで置き換えない。

既知の保証範囲外: 導入以前の天然石とプレイヤー設置石の完全識別、他Modが保護イベントを迂回した直接変更、複数チャンクとSavedDataをまたぐ強制終了時の原子的保存。正常系試験が通っても、この制限は解消済みと扱わない。
