# 母艦 V28 前方機腹インテーク案

状態: **形状提案・ユーザー承認待ち**。revision は `V28_INTAKE_PROPOSAL_01` です。承認済みの V27 正本を読み込み、前方機腹だけを派生モデルとして変更しました。承認済み `.blend` / `.glb`、ゲーム用 MGM4・atlas・アイコンは上書きしていません。

## 変更内容

前方機腹に横長の吸気口を設け、中央隔壁で左右 2 ダクトに分けました。船体の下部を Boolean で切り込み、艦首下面から口周囲へ連続する断面、厚いリップ、奥の整流フィン、閉じた後端隔壁を実ポリゴンで構成しています。旧機腹の整備パネルは、開口と重なる前方部分のみ取り除きました。

| 部位 | 形状・接続 | 状態 |
| --- | --- | --- |
| 船首下部の切り込み | 既存船体を内側へ削り、前方から開口へ続く空間を確保 | 固定 |
| 一体型リップ | 中央で分断しない横長の面取り輪郭、船腹外板へ接続 | 固定・非発光 |
| 中央隔壁 | X=0、薄い前縁から後方へ厚くなる断面 | 固定・左右共通 |
| ダクト内面 | 奥へ絞る断面、左右各 3 枚の整流フィン、後端の横桟 | 固定・非発光 |
| 補給室との隔壁 | 後端 `Z=-10.30` で閉じ、前方補給室より手前で終了 | 固定 |
| 4 補給口・中央照射口・後部搭乗受入口 | V27 の位置、空間、照射口形状を維持 | 既存の静的状態 |

幅・高さ・長さの基準は **26 × 11 × 50 ブロック**。既存の尖った艦首、中央装甲、左右甲板、双発後部の構成を維持し、下面の前方空白を大型開口へ置き換えています。船体全体の一様な拡縮は行っていません。

## 寸法と空間

ゲーム座標は `+X=右、+Y=上、-Z=前、+Z=後`、原点は機腹下端です。Blender は `+Z=上、-Y=前` で、対応は `(x,y,z) → (x,z,y)`。この案のゲーム用エクスポートは未実施です。

| 項目 | 値 |
| --- | --- |
| 全体 AABB・ゲーム軸 | `[-13,0,-25] .. [13,11,25]` |
| 吸気部の外周 AABB・ゲーム軸 | `[-7.15,1.05,-17.35] .. [7.15,4.37,-10.30]` |
| 開口前面の外接幅・高さ | 13.65 × 2.75。中央隔壁と面取り角を含む外接寸法で、全域が矩形の通過空間ではない |
| 奥行き確認 | 開口内の 6 点から後端部品まで各約 5.015 |
| 吸気部と前方補給口部品全体の最短前後離隔 | 約 1.99 |
| 吸気部と前方補給室の外接空間の前後離隔 | 2.20 |

船体の切り込みは吸気部前縁よりさらに前の `Z=-23.6` から連続させています。上表の吸気部 AABB は追加した部品の範囲で、削除した船体領域の範囲ではありません。

| slot | 補給中心 XYZ | 維持する空間 |
| --- | --- | --- |
| 0 | `(-7.15,2.4,-5.2)` | XZ 3×3、高さ `Y=2.4..3.35` |
| 1 | `(7.15,2.4,-5.2)` | 同上 |
| 2 | `(-3.6,2.4,7.8)` | 同上 |
| 3 | `(3.6,2.4,7.8)` | 同上 |

中央照射基準 `(0,-0.1,0)` と後部搭乗位置の地表投影 `(0,0,18)` を維持しています。搭乗口は XZ 3×3、上端 `Y=4.4` まで遮蔽なしです。

## 検査と制約

正本は **393 メッシュ・24,704 三角形**。全体境界と左右鏡像を検査し、位置誤差は 0 です。既存の近距離 25,000 三角形予算内ですが、MGM4 / LOD の生成・描画検査は今回の提案範囲に含めません。

`validation.json` は正本に対する 4 補給口 676 本・搭乗口 169 本の進入 ray、吸気内部の奥行き 6 本、前方補給室との AABB 離隔、部品三角形の交差を記録します。中央照射口は全頂点位置、各接続基準は座標の一致を比較しています。

`verification.json` は GLB 読み戻しの境界・鏡像、静的 frame 1 / 40 / 80、確認画像の非空検査、保護対象ファイルの SHA-256 照合です。`clearance-readback.json` は GLB に対して補給・搭乗の 845 本を再検査した記録です。

これは静的な形状・配置の提案です。吸気流量、圧力損失、冷却性能、構造強度、気密性、異物吸入、飛行物理を保証するものではなく、流体解析は行っていません。補給動作中の機体姿勢や他 entity との動的干渉も対象外です。ゲーム操作、Gradle、起動、インストール、コミットは実行していません。

## 再生成

リポジトリ直下で実行します。出力先はこの提案フォルダのみです。

```powershell
& '../work/blender-portable/blender-5.2.0-windows-x64/blender.exe' --background --python-exit-code 1 --python tools/drone-design/blender/build_carrier_v28_intake_proposal.py
```

正本と通常画像の生成済み状態から配置検査・GLB 進入検査だけを行う場合は、末尾に `-- --inspection-only` を指定します。既存の V27 / V23 / V22 描画・ポリゴン helpers は読み取りで再利用し、画像は Blender で描画しています。Python による画像加工は行っていません。
