# ノーズを尖らせる局所修正案 V15

V14の実モデルを基にしたデザイン変更案。参照画像の復元精度向上とは別の提案であり、未承認・ゲーム未反映。

## 変更内容

- ノーズ中央を造形単位で `0.28` 前方へ延長。元の本体長 `5.04` に対して約 `5.6%`。
- 先端の幅と厚みを少し絞り、中央へ収束する形にした。針状の別部品は追加していない。
- バイザーの光学面とその下地にも同じ左右対称の変形を適用し、緩いV字につなげた。
- 下部センサーは形を潰さず、全体を前方へ `0.20`、上へ `0.015` 移動。ノーズ先端より突き出しすぎない配置とした。
- 翼端、ローター、後部部品、機体の全幅は維持。

形状の変更範囲は `Y < -1.60` かつ `|X| < 1.15`。座標は `-Y=前、+Z=上`。
左右の形は独立編集せず、Xの符号に依存しない共通の変形量を使用する。
既存の `.blend` を読み込み、変更した部品のみ変形後のメッシュとして保存した。
元のV14モデルは上書きしていない。

## 確認

前方俯瞰、上、下、正面、後方、左、右、後方俯瞰、下面斜視を同じモデルから出力。
比較画像は前後で同じカメラ、照明、切り出し範囲。画像を部分変形して合わせていない。

[形状検査](validation.json) は左右対称、閉じた本体、正の体積、有限座標、
変更範囲外の保持、ローター・翼端・後部の保持、延長量、全幅の10項目。
[出力検査](output-checks.json) は元モデル保持、9方向の非空画像・解像度・鮮度、書き出しの5項目。
これは外観承認、空力性能、ゲーム内確認を意味しない。

前案に残っている翼肩・縁の陰影や材質の差は、このノーズ変更だけでは解消していない。
不可視面の推定設計と、ゲーム向け最適化・材質の互換性確認が別工程であることも引き継ぐ。
