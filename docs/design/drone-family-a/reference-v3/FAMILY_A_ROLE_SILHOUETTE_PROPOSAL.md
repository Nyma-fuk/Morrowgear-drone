# Morrowgear Drone Family A 役割識別強化案 V3

**状態:** デザイン承認待ち  
**対象:** Engineer / Field / Guard  
**共通正本:** Scout V2

## 設計目標

- 色、発光、マーキングを消しても、正面・側面・上面のシルエットだけで役割を識別できる。
- Scoutの中央艇体、ラップアラウンド・バイザー、左右ダクトローターというファミリー性は残す。
- 役割装備を小物として貼り付けず、艇体外形を構成する一次形状として設計する。
- 3x3 Dockへの上面・側面進入、着艦、充電位置を妨げない。
- Guardの攻撃方式が確定するまで具体的な武器は露出させない。

## Engineer: Workframe

### 一目で分かる形

- 機首下から伸びる大型の多関節作業ブームを1基配置する。
- ブーム先端に交換式ツールヘッドと円形エミッターをまとめる。
- 胴体上面中央に高く盛り上がった電力・冷却カウルを設ける。
- 左右ダクト下に短い安定脚兼ツールガードを追加し、下面の縦方向シルエットを強める。

### 動作で分かる形

- 巡航時は作業ブームを機腹へ折り畳む。
- 採掘・伐採時はブームが対象へ向いて展開し、レーザーの射点と実作業位置を一致させる。
- 作業中はカウル側面の放熱ルーバーが開く。

### 識別語

`下向きアーム / 工具 / 背の高い電力カウル`

## Field: Carrier Frame

### 一目で分かる形

- 左右ダクトの外側ではなく、胴体左右に大型の着脱式ポッドを配置する。
- ポッドは前後に長く、胴体より一段低い位置に置いて横長・重量級の輪郭を作る。
- 機腹中央に奥行きのある交換式カーゴ／任務ベイを設ける。
- 後部を幅広の水平安定面として延長し、Scoutより運搬機らしい長い機体にする。

### 動作で分かる形

- Dockで左右ポッドと下面ベイを交換できる。
- Cargo構成ではポッド扉が開閉し、回収・搬入位置を視覚化する。
- 任務構成に応じ、ポッド後端の状態灯と識別帯のみを変更する。

### 識別語

`大型サイドポッド / 深い荷室 / 長い後部`

## Guard: Aegis Frame

### 一目で分かる形

- 機首左右から前方へ張り出す楔形の装甲ショルダーを設ける。
- 機首下面に連続した防弾チンプレートを追加し、正面投影を厚くする。
- ダクト前縁に装甲リムを追加し、前方から見た輪郭をEngineer／Fieldより重くする。
- 上面後方に低いセンサースパインを置き、側面からも警戒機と分かる形にする。
- 将来武装はショルダー内部の閉鎖ハードポイントへ収める。

### 動作で分かる形

- 通常時はセンサーを艇体内へ収めた低い輪郭とする。
- 警戒時はスパイン上のセンサーのみ展開し、武装は露出させない。
- 防護時は脅威方向の装甲面を向けるため、姿勢そのものでも役割を示す。

### 識別語

`前方装甲 / 厚い機首 / センサースパイン`

## 共通性と差別化

| 要素 | Scout | Engineer | Field | Guard |
|---|---|---|---|---|
| 主シルエット | 軽量・低背 | 下方向と上方向に高い | 横長・長胴 | 前方に厚い |
| 主装備 | センサー | 多関節作業ブーム | 大型任務ポッド | 楔形装甲 |
| 重心の見え方 | 中央 | 中央下寄り | 左右・後方 | 前方 |
| 主な可動部 | センサー | ブーム／ルーバー | ポッド扉 | 警戒センサー |
| 代表的な認識方向 | 上面 | 側面・下面 | 上面・側面 | 正面・側面 |

## 承認後の作成順

1. 低ディテールの黒一色ブロックアウトを4機横並びで作る。
2. 正面・側面・上面で役割識別を確認する。
3. 承認後にScout V2品質のパネル、埋込センサー、素材、可動部を追加する。
4. 7方向PNGと同縮尺比較画像を作成する。
5. Blenderモデルを検証し、再承認後にJava版へ変換する。

## 合格条件

- 4機を黒一色にしても、3秒以内に役割を判別できる。
- 25%縮小表示でもEngineerのブーム、Fieldのポッド、Guardの前方装甲が残る。
- 一方向だけでなく、正面・側面・上面のうち少なくとも2方向で識別できる。
- 可動部がローター、脚、Dock進入経路へ干渉しない。
- 共通バイザーとダクトローターにより同一製品ファミリーと認識できる。
