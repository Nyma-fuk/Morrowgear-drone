# Morrowgear Drone Family A 最終モデル仕様 V3

**モデル状態:** デザイン確認用最終モデル  
**ゲーム実装状態:** 未反映  
**共通正本:** Scout V2由来のFamily A機体

## 共通構造

- 前方軸は`-Y`、上方軸は`+Z`。
- 中央艇体、ラップアラウンド・バイザー、左右ダクトローター、脚、尾翼、後部整備面を共有する。
- 役割差は色ではなく一次シルエットと立体装備で表現する。
- 左右対称部品は世界原点を基準とするMirror Modifierで生成する。
- Guardの機関砲、レーザー、誘導ミサイルは閉鎖ハードポイントへ収容し、通常時はFamily Aの基本シルエットを維持する。

## Scout

- 軽量、低背、中央重心の偵察機。
- 上面と前方のセンサー、遮蔽物の少ない視界を優先する。
- Family Aの基準シルエットを担う。

## Engineer

- 機体上面の大型電力・冷却カウル。
- 機腹中央の折り畳み式多関節作業ブーム。
- 先端の回転ツール基部と作業エミッター。
- 左右の工具カートリッジと保護ガード。
- 採掘・伐採時はブームを展開し、レーザー射点と作業対象を一致させる。

## Field

- 胴体左右の長い着脱式任務ポッド。
- 機腹中央の深い交換式カーゴ／任務ベイ。
- 後方へ延びる安定化デッキ。
- ポッド扉、ベイ扉、固定ラッチをDock内で操作する。
- Cargoを含む任務モジュールの共通搭載機として扱う。

## Guard

- 機首左右から前方へ張り出す楔形Aegis装甲。
- 連続した機首下面装甲とダクト前縁装甲。
- 上面の低い警戒センサースパイン。
- 左右の閉鎖ハードポイント。機関砲と誘導ミサイルは発射時だけ内部から作動する。
- 機体下部中央の高出力レーザー射出口。
- 交戦時は発光部を赤橙へ切り替える。赤橙の飛行軌跡は戦闘移行フレア時だけ表示し、兵装航程中は消去する。
