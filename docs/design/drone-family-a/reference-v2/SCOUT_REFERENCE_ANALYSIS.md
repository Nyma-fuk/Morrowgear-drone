## 造形上の必須条件

1. ローター外周は円形リングではなく、翼端へ張り出す五角形系の外板で囲む。
2. 機首バイザーは貼り付けた棒ではなく、艇体外板を一段削った溝の内部に置く。
3. 中央艇体は箱を重ねず、断面が連続的に変化するロフトメッシュにする。
4. ローター翼上面は複数の独立装甲パネルに分割し、細い金属エッジを持たせる。
5. 側面では機首が低く、中央が高く、後端で再び絞られる曲線を維持する。
6. 尾翼は前傾させず、すべて後方へ傾ける。
7. 発光はバイザー、顎部レンズ、ローター内周、後方航法灯に限定する。
8. 摩耗はエッジと整備部周辺に限定し、左右形状の非対称には使わない。
9. 正面から見た脚は胴体よりわずかに外へ開くが、ローター翼の下まで広げない。
10. スキッドは機体前後方向へ伸ばす。正面で長い横棒や十字に見せない。
11. 垂直尾翼は胴体後部の左右2枚だけとし、翼端フェアリングを垂直に立てない。
12. バイザーは正面幅だけで完結させず、左右それぞれ機首長の約25%まで側面に沿わせる。
13. 後面は単一のグリル板にせず、外装、凹部、整備蓋、冷却スリットの奥行きを分ける。
14. 後方灯火は中央へ寄せず、左右の独立ポッドへ格納する。
