# Morrowgear Drone Family A 外観仕様

**状態:** Scoutポリゴンメッシュ確認用  
**対象:** Scout / Engineer / Field / Guard  
**基準日:** 2026-08-22

## 1. 目的

承認されたA系デザインを、Minecraft Java版のEntityモデル、テクスチャ、アイコンへ一貫して実装するための基準を定める。

初期の画像生成による全周図には、視点ごとの形状差と左右非対称が含まれていた。これらは実装基準に使用しない。実装時の優先順位は次の通りとする。

1. `blender-v1/morrowgear-family-a-scout.blend`
2. `blender-v1/morrowgear-family-a-scout.glb`
3. `tools/drone-design/blender/build_family_a_scout.py`
4. `blender-v1/scout-*.png`の同一メッシュ全周表示
5. 本書の外観条件
6. 初期コンセプト画像の雰囲気

画像間で矛盾する場合は、本書を正とする。

## 2. 検証済み全周デザイン

| 機種 | 参照画像 |
|---|---|
| Scout | `validated/family-a-scout-validated.png` |
| Engineer | `validated/family-a-engineer-validated.png` |
| Field | `validated/family-a-field-validated.png` |
| Guard | `validated/family-a-guard-validated.png` |

各画像は、単一の数値モデルを正投影カメラで斜め上、上面、底面、正面、後方、左側面、右側面から表示したものである。機首はシアンの横長センサーバイザーがある側とする。

同じフォルダー直下にある旧`*-turnaround.png`と`validated/family-a-*-validated.png`は、それぞれ画像生成案と簡易Three.jsブロックアウトであり、形状実装には使用しない。

## 3. 座標と縮尺

- モデル上の16 unitをMinecraftの1ブロックとする。
- 原点は機体の幾何中心、ローター回転面の高さとする。
- `+X`: 機体から見て右
- `+Y`: 上
- `-Z`: 前方
- `+Z`: 後方
- ヨー回転は機体中心、ピッチとロールはローター面中心を基準にする。
- 着陸時の接地点は左右スキッド底面でそろえる。

### 最大外形

| 機種 | 幅 X | 全長 Z | 全高 Y | Dock内幅余裕 | Minecraft換算幅 |
|---|---:|---:|---:|---:|---:|
| Scout | 41.804 unit | 25.550 unit | 14.757 unit | 6.196 unit | 2.613 block |
| Engineer | 41.804 unit | 25.550 unit | 15.557 unit | 6.196 unit | 2.613 block |
| Field | 41.804 unit | 25.550 unit | 14.757 unit | 6.196 unit | 2.613 block |
| Guard | 41.804 unit | 25.550 unit | 14.757 unit | 6.196 unit | 2.613 block |

全機種を3x3 Dockの内側へ収める。通常飛行時の当たり判定は外観全幅ではなく中央胴体を基準とし、ローターガードは経路探索用の安全余白へ反映する。

## 4. Family A 共通構造

### 4.1 シルエット

- 中央胴体は低いくさび形とし、前方へ向かって細く、後方へ向かって一段高くする。
- ローターは左右に1基ずつ、合計2基とする。
- 各ローターは完全な円環ではなく、外側と後方を守る角張った部分ダクトで囲う。
- 左右ローターの中心は `X = +/-12.5`、`Z = 0` を基準とする。
- ローター直径は14 unit、ガード込み外径は17 unitを上限とする。
- ローターガード先端は後方へ流し、前方視界を遮らない。
- 着陸脚は2本のスキッドとし、左右対称に配置する。

### 4.2 共通部品階層

```text
root
└─ frame
   ├─ fuselage_core
   │  ├─ nose
   │  ├─ sensor_visor
   │  ├─ upper_armor
   │  ├─ rear_service_hatch
   │  ├─ rear_cooling_vents
   │  └─ status_lights
   ├─ rotor_left
   │  ├─ hub
   │  ├─ blades
   │  └─ partial_guard
   ├─ rotor_right
   │  ├─ hub
   │  ├─ blades
   │  └─ partial_guard
   ├─ landing_left
   ├─ landing_right
   └─ module_bay
```

- 中央胴体は数値輪郭を3段に押し出し、前方へ連続的に絞る。
- ローターガードは円形開口を持つ7頂点の翼状メッシュとする。
- `frame`に現在の飛行ピッチとロールを適用する。
- ローターだけを独立回転させ、Dock着艦時は回転を停止する。
- ローターガード、センサー、着陸脚はローターと一緒に回転させない。
- 左右の共通部品は原点を挟んだミラー形状とし、部品数と高さを一致させる。

## 5. 面ごとの共通定義

### 上面

- 中央に細長い装甲パネルを3段配置する。
- オレンジの整備ラッチは最大4か所とし、面積を増やさない。
- シアンの発光面はセンサーバイザーとローター内周の一部に限定する。
- Scout以外に不要なアンテナを追加しない。

### 底面

- 中央線上へ幅6 x 長さ10 unitの標準モジュールベイを置く。
- 底面は暗い機構色とし、上面装甲より明度を一段下げる。
- 前方に下向きセンサー用の2 x 2 unit取付点を設ける。
- Engineer以外は展開式工具を持たない。

### 正面

- 横長のセンサーバイザーを最も強い機首識別要素とする。
- バイザー中央と機体中央線を一致させる。
- 着陸脚、ローター、センサーを左右対称に見せる。
- 進行方向を誤認させる強い発光を後方へ置かない。

### 後方

- 中央に整備ハッチ、その左右に冷却ベントを配置する。
- 小型のシアン航法灯を左右1灯ずつ置く。
- 後方発光は正面バイザーより暗くする。
- 排気管や武装に見える突起を追加しない。

### 左右側面

- 機首から後端までの上面線は、前方が低く後方へ緩やかに上がる。
- ローター回転面は胴体中心線とほぼ水平に保つ。
- 左右の外形は完全に対称とする。
- 役割差はモジュール形状で表し、片側だけ大きくしない。

## 6. 役割別仕様

### 6.1 Scout

- 4機種で最も細い胴体と最小の底面投影面積を持つ。
- センサーバイザーは機首幅の70%を占める横長形状とする。
- 後方上面に同形のアンテナフィンを2本配置する。
- 機首底面中央に2 x 2 x 2 unitの走査光学部を1基置く。
- サイドレール、工具筐体、ハードポイントは持たない。
- ローターガードは4機種で最も薄く、後方へのスイープを強くする。

### 6.2 Engineer

- Family Aの外形を維持し、底面だけを1段厚くする。
- 前寄りの中央線上に作業エミッターを1基配置する。
- エミッターは収納時3 x 3 x 4 unit、展開時最大8 unit下方まで伸長できる。
- エミッター左右へ同寸法の工具筐体を1基ずつ置く。
- 作業レーザーの射出口はシアンホワイトとし、脅威状態色の影響を受けない。
- カーゴ箱、武装、非対称アームは持たない。

### 6.3 Field

- 胴体とローターの比率はFamily Aの標準値を使用する。
- 胴体左右へ長さ9 x 高さ3 x 奥行2 unitのモジュールレールを置く。
- 左右レールには同じ位置へオレンジのロックラッチを1個ずつ置く。
- 底面モジュールベイは閉じた状態を標準外観とする。
- Scoutの長距離アンテナ、Engineerの工具、Guardの前面装甲は持たない。

### 6.4 Guard

- ローターはFamily Aの部分ダクト方式を維持する。
- 機首左右に幅4 x 長さ7 unit以内の保護ショルダーを追加する。
- 正面、左右斜め、底面前方へ合計4基の小型脅威センサーを配置する。
- 左右へ同寸法の閉鎖済みハードポイントカバーを設ける。
- 機関砲、レーザー、誘導ミサイルは閉鎖ハードポイント内へ収容し、通常時に露出した長い銃身やミサイルを表示しない。
- 機体下部中央を高出力レーザー射出口とし、充填・照射時だけ収束発光を表示する。
- 通常時はシアン、交戦中はバイザー端、ステータスライン、ローター内周を赤橙へ切り替える。赤橙の飛行軌跡は`FLARE_ENTRY`だけに表示し、兵装航程中は兵装固有エフェクトとの視覚的競合を避けるため消去する。

## 7. マテリアルとテクスチャ

### 7.1 解像度

- Entityテクスチャは機種ごとに128 x 128 pxとする。
- 補間は行わず、Minecraftのピクセル境界を維持する。
- 小部品でも最低2 x 2 pxを確保し、1 pxノイズを装飾として乱用しない。
- アイコンは32 x 32 pxで別途制作し、Entityテクスチャの縮小画像にはしない。

### 7.2 色

| 用途 | 基準色 |
|---|---|
| 主装甲 | `#202A30` |
| 暗部機構 | `#10171B` |
| 中間金属 | `#46525A` |
| エッジ金属 | `#AEBBC1` |
| 制御シアン | `#20D7DF` |
| 発光中心 | `#8EFFFF` |
| 深部シアン | `#087F8C` |
| 整備ラッチ | `#C96820` |
| 警戒アンバー | `#FFB000` |
| 交戦レッド | `#FF3B30` |

### 7.3 塗り分け

- 主装甲60%、暗部機構25%、金属エッジ8%、オレンジ4%、発光3%を目安とする。
- 摩耗は前縁、整備ハッチ、着陸脚へ限定する。
- 広い面へランダムな傷を散らさず、機体の面構成を読み取れる陰影を優先する。
- 固定光源を描き込んだ強い影は避け、ゲーム内ライティングと矛盾しないようにする。
- 発光部は通常テクスチャとemissive描画レイヤーを分離する。

## 8. 状態発光

- 通常航行、走査、作業: シアン
- 脅威上昇、警戒配置: アンバー
- 交戦移行、交戦中: レッドから赤橙
- 採掘・伐採レーザー: 常にシアンホワイト
- 機体全体は変色させず、バイザー端、ステータスライン、ローター内周の一部だけを切り替える。
- 交戦終了後は赤橙表示を解除し、通常任務色へ戻す。

## 9. 実装時の禁止事項

- 4ローターや完全な円形ダクトへ変更しない。
- A系とC系の形状を混在させない。
- 左右でローター径、脚高、ガード角度を変えない。
- 役割差を色替えだけで済ませない。
- 発光面を装甲面より大きくしない。
- 画像の視点差による偶発的な突起や部品欠落を再現しない。
- Guardの兵装は閉鎖ハードポイントと機体下部射出口から展開し、Family Aの基本シルエットを崩す常設銃身を追加しない。

## 10. 実装後の確認基準

- 正面、後方、上面、底面、左右側面をスクリーンショットで本資料と比較する。
- Scout / Engineer / Field / Guardを無発光状態でもシルエットだけで判別できること。
- 3x3 Dockへの着艦時にローターガードとDockが視覚的に干渉しないこと。
- 飛行ピッチ、ロール、ヨーを適用しても機首方向を誤認しないこと。
- 32 x 32アイコンとワールド内モデルが同じ機体に見えること。
- シアン、アンバー、レッドの状態色と作業レーザー色が混同されないこと。

| Scout | 42 | 14 | 0.08% | 0.03% | 0.04% | 0.01% |
| Engineer | 46 | 15 | 0.08% | 0.03% | 0.04% | 0.00% |
| Field | 43 | 15 | 0.07% | 0.04% | 0.04% | 0.00% |

反転差はアンチエイリアス境界を含む画像比較値である。モデル座標、寸法、材質、回転角は全鏡像ペアで完全一致している。

検証対象には、ID重複、正の寸法、対応形状、鏡像中心、鏡像寸法、鏡像回転、鏡像材質、2ローター限定、3段階の機首絞り、穴付き翼状ダクト、役割別部品、3x3 Dock内幅を含む。
