## 採掘・攻撃・補給

- 地図をクリックして区画を選ぶだけでは命令しない。別区画は「母艦をここへ移動」。到着後、範囲を再確認し、破壊への同意を経て開始する。
- 10tickごとのサーバー更新を受信する。1500ms以上更新がない場合は開始を拒否する。範囲、世代、モード、所有権、期限の変化で同意を破棄する。
- 攻撃は採掘と排他的。攻撃画面は地形を壊さない旨を表示し、採掘の破壊説明を流用しない。
- 停止は固定操作域に残す。待機中は無効、移動・採掘・攻撃・補給予約・確認要求中は操作可能。
- 小型機の補給は、所有する読み込み済み機体から選択する。4か所の位置番号と接近状態は `navigation().bays()` を使い、補給位置到達を推測しない。予約取消も同じ一覧に置く。
- 飛行電力と採掘・攻撃用電力を別表示する。専用補給5枠は飛行燃料、電力、機関砲弾、ミサイル、修理材の順。補給枠の用途は既存アイコンとホバー表示で識別する。
- 最低高度は固定値を使わず、サーバーの範囲を表示する。`LIQUID` は「液体を検知したため停止」と表示する。

## Dockの補給経路

1. 所有する対象Dockを明示的に選ぶ。開いているメニューの位置はAPIにないため、対象を推定しない。
2. 近くのチェスト・樽・シュルカーボックスを補給元として選ぶ。
3. 5種類の最低在庫0〜576個と優先度0〜100を編集する。弾薬の数は弾数ではなく補給品の個数。
4. 確認ページで対象・補給元・5種類の数値を見て保存する。無効化は登録済みの補給元と規則を保持する。

`SupplyNetworkClient.request()` は補給ページを開いている間だけ呼び、既存の1.2秒制限を使う。新しい所有者・次元限定のスナップショットが保存した設定と一致するまで保存成功と表示しない。5秒で確認できなければ未確認とする。入力中の規則を受信更新で上書きしない。不明な在庫値-1は「未確認」であり、0に置換しない。

候補の探索は周囲±8ブロックの読み込み済み領域だけで行い、チャンクをロードしない。対象Dockの所有権、倉庫の種類・施錠・近接条件、経路256ブロック以内を送信前にも確認する。サーバー側の検査はそのまま維持する。

**現行APIの制約:** Dockのネイティブ近接制限は解除しない。遠い倉庫のそばから新規経路を設定するには、今後コントローラー等にも設定入口が必要。対象候補は保存済み経路と周囲の所有Dockであり、未読込のDockは新たに探索しない。

## 攻撃・回収表示と貨物ページの追加

2026-09-22追記。承認済み中央口と既存の採掘色・攻撃色を維持し、モデル、画像、音声、深度設定を変更していない。

- `CarrierRenderer` / `CarrierRenderState` はサーバーの充填・照射・冷却を表示する。現行契約は60/480/60tick。クライアントで命中や次の段階を捏造しない。
- 充填光は中央開口内、照射の始点は `beamOrigin()`。外周半径1.15、内層0.62、中心0.27ブロック。既存の深度テストを保ち、壁越し・船体上側へ表示しない。
- 攻撃は成功した `beamAims()` の最大16本を個別表示する。半径96の点線円は敵を探す範囲であり、面ダメージではない。確認画面にも「円全体への攻撃ではありません」と記す。
- 採掘は実命中点への1本だけ。照射と回収光の全頂点を16×16区画内に切り取る。上向き、不正値、範囲外への射線は描画しない。
- 回収演出は実収納済み個数と連番の増加時だけ開始する。初回受信、再読込、空ドロップでは発生させない。連続採掘で同じ演出を毎フレーム再開せず、確定した位置から短い上向きの光を出す。アイテムの物理飛行や個別の数量を表すものではない。
- 地図は実命中線、充填・照射・冷却の進捗、回収済み個数を表示する。地形更新は作業中10tick、通常40tick。画像領域の寸法が同じならテクスチャを再利用する。
- 貨物は54枠×64ページ。表示・同期するネイティブ枠は従来の95枠で、補給5枠とプレイヤー36枠はページを共有しない。全体の使用枠数と収納個数は `navigation().storage()` の確定値を表示する。
- ページ変更は `CARGO_PAGE` に対象ページ、現在のメニュー状態番号、現在のページを渡す。持ったアイテムがある場合と応答待ち中は変更を禁止する。表示内容は先読みせず、同じ母艦の新しいメニュー番号で開き直された時に貨物タブと小画面の持ち物表示を復元する。3秒で確認できない場合は未確認とする。
- 停止・再起動後の保存目的地は、地図の目的地記号と「保存した目的地への移動を再開」から扱う。新しい区画を選択した場合は新規の移動先になる。停止中の航路にも停止操作を残し、距離128ブロックという旧クライアント制限は撤去した。
- 採掘と攻撃に共通の完了コードは「直前の作業が終わりました」。以前の採掘進捗が残っている場合でも、攻撃終了を採掘完了とは表示しない。
