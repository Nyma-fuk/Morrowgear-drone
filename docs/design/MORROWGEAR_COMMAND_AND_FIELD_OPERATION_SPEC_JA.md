# 命令トランザクション・範囲作業仕様

## 命令トランザクション

コントローラーから送る1回の操作には`commandId`を1つ割り当てる。複数機を選択した場合も同じIDを共有し、サーバーは機体ごとに結果を返す。

| 状態 | 意味 |
|---|---|
| `ACCEPTED` | サーバーが対象機と命令形式を検証し、受理した |
| `HELD` | 命令は保持しているが、Dock待ち、補給元枯渇、搬入先満杯、整備などで進めない |
| `REJECTED` | 所有権、対象消失、任務ロック、形式不正などにより開始していない |
| `EXECUTING` | 目的地への移動、作業、攻撃などを実行中 |
| `COMPLETED` | 命令で定義した完了条件を満たした |
| `FAILED` | 受理後に対象喪失、作業不能、期限超過などで継続不能になった |

画面には直近の`commandId`だけを集計し、完了、実行中、保留、要対応を機数で表示する。送信成功を実行成功とは扱わない。Cargoは次行動、補給元枯渇、搬入先満杯、アクセスポート待ちを理由として返す。Dock帰還は整備対象とQueue位置を返す。

ユーザーの強制介入を有効にした命令は、現在任務、充填、照射等を明示的に中断できる。通常命令は安全な保留を優先する。

## 4点範囲作業

`作業範囲マーカー`を異なる境界位置へ4回使用し、4点をすべて含むX/Y/Z直方体を作業範囲として登録する。各辺は最大128ブロック、合計は200万ブロック以下とする。

1. ScoutまたはEngineerが指定直方体だけを共有走査する。
2. Engineerが採掘対象を処理する。破壊ドロップは通常のドロップとして現地へ出す。
3. Cargoが現地ドロップを回収し、既存のCargo搬入先または作業地点付近の有効なコンテナへ運ぶ。
4. Fieldは作業全体の進行、Securityは周辺警戒、Salvageは復旧任務を担当する。

入力途中はスニーク使用で取り消せる。操作中でもコントローラーの強制介入は有効であり、帰還、待機、別任務などへ切り替えられる。中断された共有作業は別の適格機が継続できる。

## 母艦掘削

新規の母艦掘削は選択チャンク中央を衝突点とし、水平48×48ブロックの3×3チャンク包絡内を半径24ブロックの円形衝撃波として処理する。包絡の四隅は掘削しない。エネルギー球の下降に合わせ、各高度を中心から外周へ処理し、ワールド下限の岩盤層まで到達する。岩盤自体は保護して残す。

旧保存データの半径8操作は16×16正方形のまま復元し、進行中データの形状を変更しない。開始時には対象全チャンクの読込を確認し、保護ブロック、友軍、収納満杯、未読込、操作権喪失による停止を維持する。
