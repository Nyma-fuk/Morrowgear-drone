# 母艦 V29 ディテール改善提案

承認前の独立した Blender 提案です。既存の正本、ランタイム、サーバー、ゲームには反映しません。

## 形状と参照

ユーザー指定の [ILM / The Creator NOMAD 動画](https://www.youtube.com/watch?v=eLKZS3eE7Kk) と親タスクの観察記録を設計入力にしています。この作業では動画のフレームを再取得していません。寸法の復元や直接の複製ではありません。

`V29_REFINED_SWEEP_02`。初案の「充電ステーション／ドーナツに見える」というフィードバックを受け、厚い側部の塊と積層プレートを廃止しました。横幅50、全長約32ブロックの薄い後退翼へ変更し、翼端を段階的に絞っています。中央開口は内径11へ縮小し、低い構造リングとして船体へ統合。前方のV字ブリッジ、下面の整備機器、銅色の配管は継承します。色は本提案限りで、ブランド色の決定ではありません。

翼の面に沿う細いパネル継ぎ目、沈めた放熱器、下面の三角トラス、小窓、整備用ステンシルを追加。背面には8基の開口ノズル、内部流路、奥まった噴射面、偏向ベーン、アクチュエーターを造形しました。「機能的」は構造提案を指し、実ゲームの推力・動作実装ではありません。

## 座標と部品

Blender は前方 -Y、上方 +Z、左右 X。1単位を1ブロックとして設計。全構造が原点 X=0 を参照する Mirror Modifier を使用します。

| 部品 | 形状・接続 | 状態 |
|---|---|---|
| 横長船体 | 翼幅50の連続断面ロフト。翼根厚3.85、外端厚0.30。前後縁の傾斜と段付き翼端 | 固定、左右対称 |
| 中央リング | 内径11の実開口、高さ1.05。分割した放射状点検パネル | 固定、小さい状態灯 |
| V字ブリッジ | 先端Y=-16。小さい独立窓と点検ハッチで人間尺度を表現 | 固定、左右対称 |
| 小型機整備ベイ | X=±10、±15の4室。船体前下面を切削し、床・後壁・ドッキングレールを内部に配置 | 前下面開口、空室 |
| 下面サービス装置 | 翼下の三角トラス、カセット、放熱フィン、保護された配管 | 固定、左右対称 |
| 埋め込み放熱器 | 上面パネルの一部を下げ、薄いフィンを凹部に収容 | 固定、左右対称 |
| 後部ノズル | 左右4基ずつ。船体を貫く流路、奥の噴射面、偏向ベーン | 固定、弱い発光 |
| 中央エミッター | 支持梁、ジンバル、コイル、光学面 | 固定、中心軸上 |

`beamOrigin` は Blender `(0,0,-0.1)`、ゲームローカル `(0,-0.1,0)` を保持。座標変換は `(x,y,z) -> (x,z,-y)`。巨大な垂直ビームは `beam-state.png` の提示専用状態で、保存した母艦の `.blend` と `.glb` には含めません。16×16チャンクの処理範囲、ダメージ、照射先、エフェクト実装は変更しません。

ベイの設計空間は幅3.5、高さ2.3、奥行4.0。前方からの9本のレイを各室で検査します。薄型化に伴って初期案より小さくなっているため、採用前に実ドローンの寸法適合を確認してください。実ドローンの全姿勢・経路・当たり判定の適合試験ではありません。Gradle、サーバー、ゲーム内検証はこの提案の範囲外です。

### 実測と目視確認

改善版の実寸は50.00 × 31.9925 × 7.05、評価後24,970頂点・19,774ポリゴン。左右反転した頂点の最大誤差0、非多様体エッジ0。4室合計36本の進入レイ、8ノズル合計16本の流路レイは全て遮蔽物なし。

切削後に残る上下翼パネルは左右合計496枚。生成ログの512は切削前の配置枠数で、再読込検査後の `validation.json` は空になった16枚を除く実数へ修正しています。GLB再読込は成功し、インポート後82,820頂点（法線・材質境界による分割を含む）、元モデルの最近傍頂点との最大差0、外形の最大差0でした。これは位置・外形の検査であり、トポロジーや材質の完全同一性の証明ではありません。

最終レンダーのヒーロー、7方向一覧、背面下面、初期案との比較を目視確認済み。10枚の単独レンダーは全て有効画素があり、画像端で切れていません。生成・再読込とも終了コード0、Tracebackなしです。

初期案の全高10.47から約33%低くしています。幅／全高比は4.78から7.09へ変更。主翼断面に沿う継ぎ目を設け、独立した箱型ベイは撤去。後部中央の大きなハッチ列も、ほぼ面一の点検板と細い流線形の背骨へ置き換えました。

既存リソースとV28正本・交換モデルの計377ファイルは生成前後のSHA-256が一致しました。結果は `output-checks.json` に記録。既存ランタイムは未変更です。全パーツ間の自己交差、実ドローンのドッキング、ベーンの作動は未検証であり、承認後の実装工程で確認が必要です。
