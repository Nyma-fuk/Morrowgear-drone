# Morrowgear Tactical Visor 装着時UI案

更新日: 2026-08-24  
状態: 承認用。ゲーム実装前。

## 1. 基本方針

- 装着しただけではMinecraft標準HUDを覆わない。
- 通常時はCompact、注視時はFocus、編隊管理時はWing、交戦時はCombatへ段階的に展開する。
- 画面中央、体力、空腹、経験値、ホットバー、ボスバー、チャットを安全領域として避ける。
- 通常状態を反復音で通知しない。装着・接続時も短い視覚演出だけを標準とする。
- バイザーは状況把握と対象選択を担当し、複雑な任務編集は統合戦術管理画面へ渡す。

## 2. 装着から表示まで

1. 頭部スロットまたは専用装備スロットへ装着する。
2. 画面四隅の細いシアン線が0.35秒で展開する。
3. 所有機、Wing、Dockとのデータリンクを確認する。
4. 接続できた場合は上端に`VISOR LINK / ONLINE`を1.2秒表示する。
5. その後はCompact表示へ移行する。

装備を着脱するたびに長い起動演出は行わない。同じプレイセッション内では0.15秒のフェードだけにする。

## 3. 表示モード

### Compact

通常移動、建築、採掘時の標準表示。

- 上端: Online、Active、RTB、Recovery、脅威度、リンク状態
- 左上: 選択中Wingと任務を1行
- 右上: 固定中の個体がある場合だけHP・飛行電力・兵装電力
- 下端: P0/P1警報がある場合だけ1行
- ワールド投影: 固定対象、異常機、交戦対象だけ

### Focus

視線をドローン、敵、Dock、作業領域へ合わせたときの一時表示。

- 対象の周囲へブラケットを表示
- 右上へ詳細パネルを展開
- 視線が外れて0.8秒経過するとCompactへ戻る
- 対象固定中は視線が外れても表示を維持する

### Wing

選択中Wingの状態確認用。

- 左上をWingパネルへ拡張
- 最大8機の個体ストリップを表示
- Leader、Mission、Formation、Recovery、RTBを表示
- 9機以上はWingカードへ集約し、異常機だけ個体表示する

### Combat

敵対対象への迎撃開始時に自動移行できる。

- 敵の脅威度とプレイヤー危険度を分けて表示
- 必要迎撃数、割当数、増援、離脱、充電交代を表示
- Focus機体は現在兵装、兵装電力、弾薬、Heat、射撃状態を表示
- Cargo、待機機、正常なDock情報は隠す
- 交戦終了後3秒間安定してから元の表示へ戻す

## 4. 操作

具体的なキーはMinecraftのキー設定へ登録し、競合時に変更できるようにする。

| 操作 | 結果 |
|---|---|
| HUD切替 | OFF / Compactを切り替える |
| フォーカス切替 | 視線上の候補を順番に選ぶ |
| 固定 | 現在対象を固定または解除する |
| 表示階層切替 | Individual / Wingを切り替える |
| 管理画面 | 統合戦術管理画面を開く |

敵への攻撃命令やWing再編成を誤操作しないよう、HUD上の単押しだけでは任務を発令しない。

## 5. Minecraft標準画面との共存

- チャット入力中、インベントリ、設定、ポーズ画面ではHUDを非表示にする。
- コンテナ画面ではP0警報だけを小さく残す設定を選べる。
- F1のHUD非表示に従う。
- ボスバーがある場合は上端ストリップを下へ移動する。
- GUIスケールごとに安全余白を再計算し、固定ピクセル位置へ依存しない。
- 画面比率16:9、16:10、21:9、4:3を対象にする。

## 6. 情報優先度

1. P0: プレイヤー危険、墜落、Dock経路なし、機体破壊
2. P1: RTB、充電交代、Recovery、兵装継続不能
3. P2: 選択中の任務、交戦、作業進捗
4. P3: 正常な追従、哨戒、待機、Dock待機

同種の警報は`LOW FLIGHT POWER x3`のように集約し、同時表示は最大4件とする。表示対象が頻繁に切り替わらないよう、昇格と解除にヒステリシスを設ける。

## 7. 大規模編隊

- 1～8機: 個体ストリップを表示できる。
- 9～32機: Wing単位を標準とし、選択機と異常機だけ個体表示する。
- 33～100機以上: 上端は全体集計、左右は選択中最大4Wingに限定する。
- ワールド上のラベルは距離、優先度、画面占有率で間引く。

## 8. 通信と負荷

- 通常テレメトリは5Hz。
- P0/P1はイベント駆動で即時通知する。
- バー、距離、ワールド投影位置はクライアント側で補間する。
- 非選択かつ正常な個体はWing集計のみ送信する。
- データが古い場合は値を更新せず、`STALE`と経過時間を表示する。

## 9. 実装後の必須試験

- 未所有機0機、1機、8機、24機、100機
- Compact、Focus、Wing、Combat、P0警報の全遷移
- チャット、インベントリ、コンテナ、ポーズ、F1、ボスバーとの重なり
- 各GUIスケールと主要画面比率
- 飛行電力0付近、兵装電力0、Heat上限、Recovery、Dock経路なし
- 対象消失、チャンク未読込、データリンク切断、再接続
- 低FPS時の補間、100機時のフレーム時間とパケット量

## 10. 今回の承認対象

- Compactを装着時の標準とすること
- Combatへの自動切替と3秒の復帰待ち
- 左上をWing、右上をFocus、下端を警報とする配置
- 通常時は反復音を使用しないこと
- 複雑な命令は統合戦術管理画面へ分離すること
