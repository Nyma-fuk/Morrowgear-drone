# 機体・装備・着陸状態の整合設計

2026-09-20。承認前の設計提案。ゲーム資産と制御コードは未変更。

## 改訂: Security兵装を内蔵化

### 最新のレーザー外観指定

[黒色ドームの停止・充填・照射案](outline-study/security-dome-v7.png)。ユーザー指定のドーム型防犯カメラの黒い半球カバーを意匠の基準とする。以下の多角形開口・露出同心リング案は取り下げる。

機体下面の中心線上に、基部を外装へ埋め込んだスモークブラックの半球カバーを置く。台座の首や吊下げ砲塔は作らない。停止中は反射のある黒いガラス状外観、充填中は内部に集まる光だけが透け、照射中は内部集約点から下方の目標へ光線が出る。カバーは開かず、外へ向かう充填線や回転する外部リングは設けない。

これはゲーム内の架空光学カバーの表現であり、一般的な黒色ガラスが高出力レーザーを安全に透過するという技術的主張ではない。物理モデルではなく世界観内の材質として扱う。

ドーム最低面を着陸時の非接地部包絡に含める。内部照準軸とビーム原点を統一し、射線が自機外装へ入る角度では照射せず機体姿勢を調整する。画像は概念案で、内部光学系、脚との距離、全視点での対称性、実ゲーム描画は未検証。ミサイルの上面格納と機関砲の埋込配置は維持する。

ユーザー指示により兵器の交換モジュール化を取り下げる。以下の旧「Securityと装着情報」は現行コード調査の記録であり、新設計としては採用しない。役割モジュール全体の廃止を意味しない。

[統合兵装の概念案](outline-study/security-integrated-v6.png)。Securityの共通機体に前方の埋込銃口、後部上面のマイクロミサイル格納庫、前部下面の薄型レーザー照射口を配置する。外付け兵装ポッドと大型吊下げレーザーは廃止。吸気・タービン・脚格納庫を兵装で塞がない。

ミサイルは左右対称の上面扉を開き、左右セルを短い間隔で順次射出する。初期案は2ゲームtickごとに1発、1連射6-8発。ただし搭載数、弾薬消費、威力は未確定であり、この図のセル数をそのまま既存ゲームの弾数にしない。離脱、点火、扇状展開、目標へ誘導の順に動く。映画バトルシップの印象をユーザー説明から参照した案であり、映画の弾道や機構を検証して再現したものではない。

発射前に扉開放、上空離隔、友軍の進路を確認する。天井や近接友軍がある場合は射出を保留し、安全な位置へ移るか別兵器を選ぶ。母機の当たり判定を抜けるために弾を壁越しへ移動させない。発射後に対象が消えた場合の再捕捉・失効、チャンク離脱、同時斉射の負荷上限を実装時に定義・試験する。連射のために既存の威力や敵割当を暗黙に増幅しない。

レーザーは腹部外装内の浅い多角形開口と同心の光学部に収納する。出力感は大型化ではなく、内部に集まる光、白い芯の高密度ビーム、周辺の控えめな光で表す。描画色の最終決定は既存の戦闘色との整合を取る。照射口アンカー、射線、充填原点は共通にし、閉鎖カバーや他兵器から照射しない。着陸時の最低面は脚より上に保つ。

兵器解放と移行は別課題: 内蔵化によって序盤から全兵器を無条件解放しない。既存のネザー付近で機関砲、以後にレーザー・ミサイルという進行を維持する移行方式を定義する。既存武器モジュールのIDや保存データを削除して消失させず、変換または旧互換の方針を確定してからコードへ反映する。AUTO・武器指定は内蔵兵器の運用方針と装備実体を分離して扱う。

今回の成果は概念案と設計改訂。格納容積、脚との干渉、実ゲーム射出は未検証。

## 前提と未検証事項

従来の概念画では脚高、格納容積、可動部の掃引範囲、吸排気経路を検証していなかった。「着陸できる設計が完成済み」と扱わない。

現行コードのMorrowgearDrone.javaはドローンの当たり判定を幅1.45、高さ0.7で登録している。DroneEntity.javaのDOCK_LANDING_Yは0.29。これは新モデルの足裏高さや接地余裕を保証する数値ではない。描画変換、エンティティ原点、Dock表面の関係を確認して移行する。

[概念画](outline-study/landing-scout-loadouts-v5.png)は構造の説明用であり、寸法検証図ではない。SCAN CYCLEのT2が前方に戻っている点、GUN中央にレンズが残る点は仕様不一致で不採用。着陸図も全脚が同一メッシュから投影された図ではない。

## 接地基準

- 接地面を高さ0とし、展開した左右前後4脚の足裏をそこへ揃える。中心原点から脚を後付けで延ばして調整しない。
- 非接地部の最低点を含む全装備の包絡体を定義し、その下に接地余裕を確保する。仮の最低余裕は機体全長の5%。最終値は実ゲーム縮尺とDock表面で確定する。
- 装備が張り出すほど脚を無制限に長くするのではなく、原則として装備を格納する。収納容積不足は本体下面設計の修正理由とする。
- 脚の支持は胴体骨格へ接続し、吸気口、タービン流路、兵装扉、アームの収納経路と分離する。
- 左右の脚・収納庫・装備支持は同一部品のミラーで構成する。動く光点の位相は構造の非対称とは区別する。
- 接地判定は足先の見た目だけでは完了しない。エンティティ当たり判定、障害物回避、Dock進入・退出、隣接機との干渉も検査する。

## 状態別の機構

| 状態 | 脚 | 装備 |
| --- | --- | --- |
| 着艦済み・補給 | 展開・接地 | アーム収納、フック固定、荷室閉鎖、兵装安全化、ローター停止 |
| 発艦 | 初期は展開、離床後に収納 | 装備収納のまま。ドックからの十分な離隔後に任務装備を展開 |
| 巡航 | 収納 | アーム・ケーブル・扉を収納。スキャンは必要時のみ |
| 作業ホバリング | 原則収納 | 必要な装備だけ展開。脚の可動空間と共用しない |
| 帰還・着陸進入 | 装備収納確認後に展開 | 収納未完なら通常着陸へ進まず、離隔位置で保留して理由表示 |
| POWER LOST | 通常着陸シーケンスを要求しない | 通電演出停止。重力落下や残存姿勢は既存故障仕様に従い、脚を出すために浮遊させない |

Cargoの扉、Engineerの腕、Salvageのフックには収納中・収納完了・展開中・展開完了を区別する。描画側だけで任務状態を変更しない。収納失敗で無期限に給電を消費する動作にせず、故障通知と既存の回収手順へ接続する設計が必要。

Salvageは荷物を吊ったまま通常着陸しない。荷下ろし・切離し・ケーブル収納後に着陸する。荷下ろし不可なら対象を消したりDockへめり込ませたりせず、回収任務の例外状態として扱う。

## Scoutの全周走査

多数のカメラは廃止。前方は左右1組の小型カメラに整理する。側面外周には細い埋込式の光学走査帯を設け、前面から左右側面、後面まで閉じた経路にする。空中の輪や太い発光チューブにはしない。

- 走査中は明るい点1個と短い残光が経路上を一定方向へ進む。全周の帯は点より暗くし、常時まぶしく点灯しない。
- 初期演出案は1周2秒。経路の頂点数ではなく弧長で進め、翼端だけ速くなる現象を避ける。
- 位相は走査開始時刻と補間時刻から算出し、機体のローカル座標から描画する。世界座標に固定せず、ロール・ヨーにも追従する。
- 機体自身や地形の裏側の点は透過表示しない。前面で見えなくなり、側面から再び見えることが正しい挙動。
- 通常巡航で走査要求がなければ点は消灯。走査中だけ巡回し、POWER LOST・格納時は消灯。表示のために実際の走査処理を増やさない。
- 実走査は既存の調査・データリンク結果に従う。光点が向いていない方角を検知不能にしたり、点の通過をデータ共有の条件にしない。
- 外へ放つ演出を追加する場合も短い低輝度の走査光に限定し、攻撃レーザーと同じ太さ・配色・着弾演出は使わない。

## Securityと装着情報

現行SecurityLoadoutにはUNARMED、AUTO、AUTOCANNON、LASER、MISSILEがある。描画は役割だけでなく装着情報から決める。飛行形状は旧Fieldの均整の取れた翼を共通として維持する。

| 装着情報 | 外観・可動 | 表示しないもの |
| --- | --- | --- |
| UNARMED | 閉じた装備庫とカバー | 全兵器の銃身・照射口・ミサイル |
| AUTOCANNON | 左右の専用下面ポッドと前向き銃身 | レーザー照射装置、ミサイル |
| LASER | 中央下面の照射装置、冷却部、左右装備庫は閉鎖 | 銃身、ミサイル |
| MISSILE | 左右対称の専用格納庫、発射時に扉を開く | 銃身、レーザー照射装置 |
| AUTO | 既存動作を確認した上で複合格納構成を定義。使用兵器だけ展開 | 非選択兵器の発射・充填演出 |

AUTOを「機関砲の見た目のままレーザー発射」としない。一方で概念画を理由に既存AUTOの武器選択や弾薬容量を変更しない。複合格納の容積・排他機構は未検証であり、モデル作成時の必須課題として残す。

レーザーの原点・照準軸・充填光は実モデルの照射口アンカーに統一する。機関砲は銃口アンカー、ミサイルは各レールから発射し、閉じた扉や吸気口から発射しない。左右交互の発射と左右対称な機体構造は両立させる。見た目の搭載本数は実弾薬数に合わせ、追加弾倉を描くなら収納構造も定義する。

## モデル承認前の確認項目

1. 全6役割とSecurity全5装着状態の着陸・巡航・展開状態を同一モデルから出力する。
2. 脚の最低面、非接地部の最低面、格納容積、扉と装備の全可動域を数値検査する。
3. 正面・上面・下面・左右・後面で吸排気と装備支持が交差しないことを確認する。
4. 着陸、離陸、装備交換、低電力帰還、着艦中の装備変更、POWER LOSTの前後で破綻しないことを確認する。
5. 全周走査を1周期以上観察し、前後・上下から見た遮蔽、停止・再開、遠距離表示を確認する。
6. 全兵装で攻撃開始・中断・冷却・再補給・AUTO切替時の装備とエフェクト原点を確認する。
7. 従来のDock着艦、Salvageの荷物最低面、編隊間隔、当たり判定に対する回帰確認をする。

このリストは今後実施する検証条件であり、PASS済みの報告ではない。
