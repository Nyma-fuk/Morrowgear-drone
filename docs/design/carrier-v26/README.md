# V26：攻撃空母の船型・機能配置案

**未承認の形状・配置提案。材質・底面の細部・可動機構の仕上げ前。ゲームには反映していない。**

V25の丸く短い船体を廃し、幅46・長さ68・高さ11の前後に長い船型を仮採用した。艦首から中央、分離双発後部まで、連続した断面loftで外面をつないでいる。小型X47の拡大ではない。

## 大形状の確認点

- 鋭い中央艦首とchine、斜め肩、後退した台形の外周。
- 中央から後方へ約42ブロック続く実甲板。操縦席は設けない。
- 船体両側に長い格納庫開口と発艦面。中間の構造壁で上下を接続する。
- 中央が分かれた双発後部、低く外へ傾いた艦船フィン。
- 中央機腹に一体化した照射口。上面に丸穴2個を並べない。

## 座標と差分

Blender前方-Y・上方+Z、ゲーム前方-Z・上方+Y。機腹原点0を維持する。V25から幅48→46、長さ32→68、高さ14→11の変更提案。バックエンドは変更していない。

4受入点は `(-7.15,2.4,-5.2)`、`(7.15,2.4,-5.2)`、`(-3.6,2.4,7.8)`、`(3.6,2.4,7.8)` のまま。側面の長い格納庫は船型の機能表現であり、追加のバックエンド受入slotを提案するものではない。

寸法46×68×11、左右反転の頂点照合最大誤差0。4受入部それぞれ169本の検査線では遮蔽なし。これは任意の姿勢・進入経路の安全を保証するものではない。GLB読み戻しでは欠落部品なし、部品境界とマーカーの最大誤差0。親タスクで俯瞰・7方向図・腹部図を目視した。

母艦単体19,602三角形。見本機を含む交換データは1,787,642三角形であり、そのままゲームへ持ち込まない。可動機構、全経路の衝突、描画性能、実ゲームの動作は未検証。runtime・installed資産・補給品は未変更。V24/V25は却下履歴として保存する。
