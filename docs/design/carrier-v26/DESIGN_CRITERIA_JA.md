# V26 攻撃空母の設計判断

## 最新要求と失敗の原因

ユーザーが求めるのは、スタイリッシュさ・機能性・攻撃性・圧倒感を兼ね備えた空飛ぶ空母。F-22は輪郭の参考だが、そのまま巨大化した飛行機にはしない。左右対称を維持する。

V24は小型機の流線型に寄りすぎ、母艦の威厳が不足した。V25は重厚感を厚く短い塊へ置き換え、膨らんだ形に見えた。このため、厚さだけの中間値を探すのではなく、長い甲板と格納庫を持つ別の船型を構成する。

## 参考と独自の解釈

- [米空軍のF-22写真掲載ページ](https://www.jber.jb.mil/News/Articles/Display/Article/2294345/3rd-wing-airmen-continue-to-set-new-records/)を画像検索で確認。ページ・原画像への直接アクセスは403で取得できていないため、厳密な寸法計測の根拠にはしない。
- [米海軍撮影の空母上面写真と出典情報](https://commons.wikimedia.org/wiki/File:Overhead_view_of_USS_Gerald_R._Ford_(CVN_78)_transiting_the_Atlantic_Ocean,_March_19,_2023.jpg)。連続した甲板と小さく見える艦載機を、母艦の大きさを伝える構成の参考にする。

以下は実機の仕様を転記したものではなく、このMod用の独自の設計判断である。航空力学・構造強度・実際の飛行能力を検証したという主張はしない。

| 要素 | 採用する考え方 | 避ける表現 |
| --- | --- | --- |
| 艦首 | 前へ絞るくさびと連続した斜面 | 操縦席の付いた長い戦闘機の機首 |
| 外周 | 斜めの肩、後縁の切り戻し、薄い外縁 | 一様に厚い菱形の一枚板 |
| 中央 | 発着と整備が想像できる長い甲板 | 意味のない巨大な丸穴、装飾線だけの平面 |
| 側面 | 格納庫の奥行き、支持壁、発艦面 | 黒い模様だけで表した格納庫 |
| 後部 | 双発の推進器、低く長い機関区画 | 深すぎるU字の切欠、巨大な戦闘機尾翼 |
| 腹部 | 船体に埋め込んだ主照射口と受入部 | 薄い船体への大型兵装の後付け |
| 表面 | 装甲・作業甲板・排熱口の材質差 | 全面を発光線や細かな溝で埋めること |
| 大きさ | 既存3ブロック級ドローンを原寸の見本として配置 | 遠近だけで巨大に見せること |

## 確認の順序

1. 正面・上面・側面で寸法比と輪郭を確認する。
2. 斜めから、甲板・格納庫・機関部が別の役割として読めるかを見る。
3. 同じ正本から後面・底面・左右を描画し、隠れた面を確認する。
4. 対称性と寸法を数値で検査する。外観が魅力的かどうかの判断とは分ける。
5. ユーザー承認後、受入経路・当たり判定・乗降場所・描画負荷を新寸法で再検証してゲーム用資産へ進む。

## 提案と実装の境界

提案寸法は長さ68・幅46・高さ11ブロック。既存バックエンドの寸法を変更したものではない。甲板上の見本機は縮尺確認用であり、補給ベイの増設や収容数の実装を意味しない。

専用船内空間の承認は維持する。外観内に現実の船室がすべて実体化しているという意味ではない。見本の位置と実際の受入予約・搭乗・照射口は、ゲーム接続時に別途照合する。
