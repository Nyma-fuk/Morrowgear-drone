# Morrowgear Drone v0.7.0 検証結果

## 対象

- 役割モジュールを追加するための機体役割モデル
- Wing間で航路・脅威・目的地情報を共有する任務データリンク
- 既存ワールドの役割未設定機を失わずに移行すること

## 実装結果

- `FIELD / SCOUT / CARGO / ENGINEER / SECURITY`を安定した文字列IDで定義した。
- 役割IDを機体へ同期し、NBT互換の保存対象へ追加した。
- 役割未設定または未知の役割IDは`FIELD`へ移行する。
- データリンクを所有者、Dimension、任務IDごとに分離した。
- Scout報告は航路状態、脅威、目的地準備、信頼度、観測時刻、発信Wingを持つ。
- 複数報告は危険側を優先して統合し、200tick経過した情報は失効する。
- UIへ役割とデータリンク状態を表示する。

## 自動検証

- 全97テスト成功
- 失敗0、エラー0
- 全役割IDの往復変換と未知IDのFIELD移行を確認
- 複数Scout報告の統合、危険側優先、平均信頼度を確認
- 200tickを超えた報告の失効を確認
- 所有者、Dimension、任務IDをまたいだ情報漏洩がないことを確認
- Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2向けビルド成功

## 非変更領域

- 既存の最高速度、巡航速度、CATCH-UP、Recovery、隊形、リーダー制御は変更していない。
- 役割モジュールのアイテムとアイコンは、デザイン承認後に追加する。
