# Morrowgear Drone v0.5.2 検証結果

## 修正した問題

収束中またはRecovery中の機体が1機でも残ると、目的地へ到着済みのコホートが地点哨戒へ遷移できなかった。

## 新しい遷移規則

- 完成編隊が到着した場合は全参加機をまとめて地点哨戒へ移す。
- 到着済みコホートが参加機の60%以上に達した場合、未合流機を待たず地点哨戒を開始する。
- 未合流機がRecovery状態の場合、到着済みコホートの規模にかかわらず地点哨戒を開始する。
- 地点哨戒開始後も遅延機は同一任務・同一コホートを維持し、哨戒隊形へ後着合流する。
- 航行途中では従来どおり全参加機の合流と完成隊形を優先する。

## 自動検証

- Gradle `clean test build`: 成功
- 完成編隊、過半数到着、Recovery機残留、過半数未満、未到着の各遷移条件を検証した。
