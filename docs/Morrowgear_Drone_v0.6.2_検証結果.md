# Morrowgear Drone v0.6.2 検証結果

## 対象

- 合流後もリーダーが加減速を繰り返す問題
- 数十機で追従、集合、隊列形成、地点哨戒が成立しない問題

## 原因と修正

- 大編隊の実幅を分断と誤認していたため、隊形実寸を分断閾値へ反映した。
- 所属コホートの参加数と任務全体の機数を比較していたため、速度判定を最大8機のウイング内へ限定した。
- 全コホートの後続機を1人のリーダーへ集めていたため、コホートIDごとの同期合流へ変更した。
- 13機以上を最大8機のウイングへ分割し、任務意図は全体共有、合流と隊形維持はウイング単位とした。
- 地点哨戒は予定総数分の固定円周スロットを使い、後着ウイング単位で参加する。
- 追従の多重リングを各リングの円周全体へ均等配置した。
- server tick内の所有機検索結果を共有し、大編隊時の重複検索を削減した。

## 自動検証

- 全82テスト成功
- 失敗0、エラー0
- 30機編隊のウイング分割、最終6機ウイング、隊形実寸判定、多重追従リングを追加検証
- Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2向けビルド成功

## 実機確認項目

- 多数機ワールドでウイングごとのリーダーとコホートIDが形成されること
- 合流完了後にリーダーと後続が同時に最高編隊速度へ移ること
- 追従時に同心リングへ均等展開すること
- 地点到着後に後着ウイングが予約済み円周スロットへ参加すること
- 大隊形を分断と誤認して`CONVERGING`へ戻さないこと
