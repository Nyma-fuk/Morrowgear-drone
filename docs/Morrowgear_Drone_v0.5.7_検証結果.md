# Morrowgear Drone v0.5.7 検証結果

## 対応内容

- 隊形移動から旋回へ入る前の縦隊整列処理を撤去した。
- コホートリーダーの到着方向を共有旋回開始角として保存するようにした。
- リーダーを先頭に、後続機が参加順位どおり同じ円弧を追う`MISSION_ORBIT_ENTRY`を追加した。
- 120tickかけて短い追尾位相から均等な円周配置へ展開し、通常哨戒へ連続接続する。
- 追従開始にも同じ旋回進入を適用した。Recovery機を除いた実働順位は従来どおり連続化する。
- 通常速度、追いつき速度、旋回速度、隊形間隔を拡大し、リーダーの先行距離を抑えた。
- 旋回進入時刻と位相は機体の保存データへ追加し、旧ワールドでは未設定値から安全に読み込む。

## 自動検証

- リーダー、後続1、後続2が同じ回転方向へ順位どおり並ぶこと
- 進入完了時の座標が通常の均等円周スロットと一致すること
- 追従旋回と地点哨戒の両方で位相オフセットが維持されること
- デルタ隊形の左右対称性と縦方向位置
- 拡大後の隊形スロット間隔
- 長距離追いつき速度上限0.82 block/tick
- 全69件、失敗0、エラー0

## ゲーム内確認項目

Minecraft起動後、複数機へ同一地点を指示し、次を目視確認する。

1. 移動隊形のまま旋回地点へ進入し、縦隊への事前整列が発生しない。
2. リーダーが最初に円軌道へ入り、後続機が同じ円弧を順番に追う。
3. 約6秒後、参加機数に応じた均等な円周配置へ広がる。
4. デルタ、縦列、星型の形状が旧版より判別しやすい。
5. Recovery機がある場合、実働機だけで間隔を詰め、復帰機は後着参加する。

ゲーム内の目視確認は、v0.5.7を読み込んだクライアントで実施する。
