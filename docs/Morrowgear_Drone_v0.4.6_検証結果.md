# Morrowgear: Drone Command v0.4.6 検証結果

## 対象

- Minecraft Java Edition 26.2
- Morrowgear: Drone Command v0.4.6
- 検証日: 2026年8月18日

## 原因

各機が離れた監視地点にいる状態でも、任務再割り当て直後から通常のリーダー基準隊列を適用していた。さらに担当スロットから11ブロック以上遅れた機体があると、先導機の操舵目標を1.2ブロック先へ縮めていたため、要求速度が大幅に低下していた。この組み合わせが、遅い機体、伸びた隊列、途中の隊列崩れとして見えていた。

## 修正内容

- 散開状態専用の`MISSION_CONVERGING`を追加
- 各機へ目的地周辺の固有進入スロットを割り当てて独立巡航
- 機体間の最大距離で分散状態を判定
- 収束開始と完了に異なる閾値を使用して状態の往復を防止
- 通常隊列における先導機の追従待ち目標を1.2ブロック先から5ブロック先へ変更
- 管理UIへ`分散収束 / RENDEZVOUS`状態を追加

## 自動テスト

- `clean test build`: 成功
- テスト総数: 41件
- 失敗: 0件
- 分散判定、最大機体間距離、収束ヒステリシス、7機分の進入スロット分離を検証

## Minecraft実機確認

1. ログで`morrowgear_drone 0.4.6`の読込みを確認した。
2. 7機が離れた地点で監視している既存ワールド状態を読み込んだ。
3. 全7機を選択し、地図の反対側にある同一地点へ移動を指示した。
4. 全機の表示が即座に`分散収束`へ切り替わり、個別航路で目的地周辺の各進入スロットへ移動することを確認した。
5. 先導機が遅い機体を待って極端に減速する挙動、および出発地点へ戻って隊列を作り直す挙動は確認されなかった。
6. 約6秒で7機すべてが目的地へ到達し、全機が`地点哨戒`へ切り替わった。
7. 任務停止、機体消失、ログ上の例外は確認されなかった。

## 判定

合格。散開状態からの一点集合を通常隊列形成から分離したことで、各機が自身の位置と経路に応じて安定して巡航し、目的地付近で自然に収束する挙動になった。
