# Morrowgear Drone v0.6.0 検証結果

## 対象

- 地点哨戒および生物追跡の旋回中に、障害物回避と高度補正が競合して上下動を繰り返す問題

## 実装結果

- 任務単位の共有旋回面を追加した。
- 旋回円周と内外0.9ブロックを16～32方向で走査し、機体下端を含む安全高度を算出する。
- 高度評価を20tick保持し、追跡対象の小さな移動による再計算の揺れを抑制する。
- 上昇は即時、下降は連続4回の安全確認後に0.35ブロックずつ行うヒステリシスを追加した。
- 旋回中の経路回避は同一高度での横回避を優先する。

## 自動検証

- 全78テスト成功
- 失敗0、エラー0
- 新規テスト: 即時上昇、小変動の無視、下降確認時間と下降量、下降確認の中断
- Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2向けビルド成功

## 実機確認項目

- 樹冠、崖、建築物が旋回円周にかかる地点で、不必要な上下往復が収まること
- 障害物へ近づいた場合は先に上昇し、通過後は急降下しないこと
- 複数機が同じ旋回面を維持すること
- 移動する追跡対象でも`TARGET WATCH`を維持できること

実機上の見た目と操作感は、v0.6.0を読み込んだ検証ワールドで最終確認する。
