# Morrowgear Drone v0.5.6 検証結果

## 修正した問題

コホートリーダーを削除すると機体本体は消えるが、残存機が削除済みリーダーIDを保持する場合があった。

## 修正内容

- 削除命令を`権限移譲 → 順位再編 → 光源除去 → 機体破棄`の順に変更した。
- リーダー削除時はRecovery待ち時間を適用せず、即時に後継を決定する。
- 健全機がなければRecovery段階が最も低い残存機を暫定リーダーにする。
- 僚機削除時も残存機の順位を連続値へ詰め直す。
- コホートID末尾と全残存機のリーダーIDを新リーダーへ同時更新する。

## 自動検証

- 健全な後継機の選出を検証
- 全残存機がRecovery中でも後継を選出することを検証
- Recovery段階、距離、バッテリー、機体IDの優先順を検証
- 既存の長期Recovery権限移譲テストを含め成功
