# Morrowgear Drone v0.5.4 検証結果

## 修正した問題

5機のプレイヤー追従コホートで1機がRecovery状態になると、残る4機が5分割された旋回スロットの4か所を使用し、Recovery機の位置に不自然な空白が残っていた。

## 修正内容

- Recovery中ではない追従機だけを実働隊形として抽出する。
- 実働機へ連続した一時ランクを付け、実働機数で旋回位相を均等分割する。
- Recovery機は実働隊形の外側にある暫定再合流スロットへ向かう。
- 復旧して`RECOVERY_LEVEL=0`になると、固定ランク順の通常追従隊形へ復帰する。
- 地点哨戒の旋回処理には変更を加えない。

## 自動検証

- 5機中中央ランクの1機がRecoveryでも、残る4機へ`0/4`から`3/4`の連続スロットが割り当てられることを検証する。
- Recovery機が`4/5`の暫定再合流スロットを受けることを検証する。
