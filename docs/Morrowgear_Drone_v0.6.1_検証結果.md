# Morrowgear Drone v0.6.1 検証結果

## 対象

- 後続機がリーダーへ追いつくたびにリーダーが段階加速し、再び距離が開く問題

## 実装結果

- 正常な後続機全員の予約スロット到着を同期条件にした。
- 個別機の到着順では`MISSION_MOVING`へ昇格しない。
- 全機が2.8ブロック以内へ入った同じserver tickで一斉昇格する。
- 同期成立前はリーダーの合流速度を維持し、成立後は全機が最高編隊速度へ移行する。
- Recovery機は同期成立を妨げず、復旧後に再合流する。

## 自動検証

- 全79テスト成功
- 失敗0、エラー0
- 新規回帰テスト: 全後続機が範囲内の場合のみ同期解放し、1機でも範囲外なら解放しない
- Minecraft 26.2 / Fabric Loader 0.19.3 / Fabric API 0.156.0+26.2向けビルド成功

## 実機確認項目

- 先着した後続機がいてもリーダーが先行加速しないこと
- 最後の正常機がスロットへ入った直後、全機が同時に加速すること
- 加速後にデルタ、縦列、星型の予約順位が維持されること
- Recovery機が残っていても正常編隊が停止し続けないこと

起動中のMinecraftはv0.5.9のため、v0.6.1の見た目は次回の計画的な再起動後に確認する。
