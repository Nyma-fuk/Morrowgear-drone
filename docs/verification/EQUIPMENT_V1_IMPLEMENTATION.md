# Morrowgear 装備デザインV1 実装・検証記録

**対象バージョン:** Minecraft Java Edition 26.2  
**Modバージョン:** 0.11.4  
**実施日:** 2026-08-22

## 反映内容

### 機体

- `DroneRole`を描画状態へ渡し、役割別装備とランディングギアを切り替えるようにした。
- Scoutは外側へ展開する軽量スキッドと上面センサーを持つ。
- Cargoは大型サイドポッド、下面ベイ、長い荷重分散スキッドを持つ。
- Engineerは上面電力カウル、下面作業機構、補強付き四点脚を持つ。
- Securityは前方装甲、上面センサー、太い装甲四点脚を持つ。
- Fieldは標準型の長い平行スキッドを持つ。
- Scoutを含むすべての脚は中心線から外側へ展開し、接地部は水平とした。

### アイテム

- `field_drone_unit`、4種モジュール、`dock_item`、`controller`のアイコンを64x64へ更新した。
- 役割差は色だけでなく、アンテナ、積載セル、作業エミッター、装甲センサーの形で表現した。
- Controllerは平面モデルを廃止し、画面、操作盤、アンテナ、グリップを持つ立体アイテムモデルへ変更した。
- 一人称、三人称、左手、右手、GUI、地面、額縁の表示Transformを定義した。

### Dock

- 既存の`dock_part_0`から`dock_part_8`までのIDを維持した。
- 四隅、四辺、中央を別モデルへ分離し、全体を低床3x3プラットフォームとして構成した。
- 支柱を置かず、四辺と上面からの進入経路を開放した。
- 中央に十字充電接点、四辺に進入灯、中央周囲に整備ロックを配置した。
- 表示上面と当たり判定を8/16ブロックへ統一した。
- 着艦Y座標を`0.52`へ更新し、新しいDock上面へ合わせた。

## 更新互換性

- アイテムIDは変更していない。
- `morrowgear_drone:field_drone`は変更していない。
- Dockを構成する9ブロックIDは変更していない。
- 既存ワールドのアイテム、機体、Dockは保存上の同一性を維持し、リソース再読込後に新しい表示へ切り替わる。
