# Morrowgear Drone v0.5.8 検証結果

## 修正した問題

- 分散収束中は機体がリーダー後方へ密集し、合流判定後に初めて本来の隊形へ並び直していた。
- 収束機のスロットがリーダーへの距離順で変化し、接近中に機体同士の目標が入れ替わる可能性があった。
- 円軌道への展開に6秒かかり、後続機の円弧参加が緩慢だった。

## 修正内容

- 未合流機へ完成隊形の固定スロットを事前予約した。
- 固定順位は任務インデックスとリーダーインデックスから決め、収束中から合流後まで維持する。
- 合流済み機も予定総数を基準に隊形を計算し、途中参加による形状変更を防いだ。
- 開放空間では最初からデルタ・縦列・星型へ収束し、地下・狭所だけコンパクト列へ縮退する。
- 円軌道進入を50tickへ短縮し、前半を速く展開する補間へ変更した。
- 地点旋回速度を0.038 rad/tickへ変更した。

## 自動検証

- 予定総数を使う隊形スロットの分離
- デルタ隊形の左右対称性
- リーダーが固定順位0になること
- 進入前半で円弧間隔差の60%以上を解消すること
- 進入完了位置と通常円軌道位置の一致
- 欠員がある場合も任務インデックスに対応する予約スロット数を維持すること
- 既存の群制御、Recovery、追従、防御、Dock制御を含む全71件

結果: 失敗0、エラー0、ビルド成功。

## ゲーム内確認項目

1. 分散した複数機へ同じ地点を指示する。
2. `分散収束`表示中から、各機が完成隊形の異なるスロットへ向かうことを確認する。
3. `隊形移動`への切り替わりで目標位置が飛ばず、そのまま整った隊形で加速することを確認する。
4. 地点到着時はリーダーから順に円弧へ入り、約2.5秒で均等な円周配置になることを確認する。
